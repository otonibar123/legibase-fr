# Chapitre II : Médiation dans un cadre juridictionnel

Code des relations entre le public et l'administration › Livre IV : LE RÈGLEMENT DES DIFFÉRENDS AVEC L'ADMINISTRATION › Titre II : LES AUTRES MODES NON JURIDICTIONNELS DE RÉSOLUTION DES DIFFÉRENDS

### Article L422-1
- Identifiant : LEGIARTI000033458736
- État : en vigueur depuis le 20/11/2016
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000033458736
- Renvoie à : [art. L213-5 du Code de justice administrative](../../../code-de-justice-administrative/partie-legislative/livre-ii/titre-ier/chapitre-iii.md#article-l213-5)

Ainsi qu'il est dit à l'article L. 213-5 du code de justice administrative, une mission de médiation peut être organisée par les chefs de juridiction dans les tribunaux administratifs et les cours administratives d'appel.

### Article L422-2
- Identifiant : LEGIARTI000033458731
- État : en vigueur depuis le 20/11/2016
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000033458731
- Renvoie à : [art. L213-7 du Code de justice administrative](../../../code-de-justice-administrative/partie-legislative/livre-ii/titre-ier/chapitre-iii.md#article-l213-7)

Ainsi qu'il est dit aux articles L. 213-7 à L. 213-10 du code de justice administrative, les juridictions régies par ce code peuvent ordonner une médiation en vue de parvenir au règlement de certains différends.
