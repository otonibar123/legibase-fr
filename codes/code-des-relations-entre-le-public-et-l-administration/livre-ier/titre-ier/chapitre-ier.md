# Chapitre Ier : Règles générales

### Article L111-1
- Identifiant : LEGIARTI000031367318
- État : en vigueur depuis le 01/01/2016
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000031367318
- Cité par : [Arrêté du 12 juillet 2019](https://www.legifrance.gouv.fr/loda/id/LEGITEXT000038774190) ; [Arrêté du 27 mai 2019](https://www.legifrance.gouv.fr/loda/id/LEGITEXT000039383528)

L'usage de la langue française est prescrit dans les échanges entre le public et l'administration, conformément aux dispositions de la loi n° 94-665 du 4 août 1994 relative à l'emploi de la langue française.

### Article L111-2
- Identifiant : LEGIARTI000031367321
- État : en vigueur depuis le 01/01/2016
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000031367321
- Cité par : [art. L861-1 du Code de la sécurité intérieure](../../../code-de-la-securite-interieure/partie-legislative/livre-viii/titre-vi/chapitre-ier.md#article-l861-1) ; [art. L552-3 du Code des relations entre le public et l'administration](../../livre-v/titre-v/chapitre-ii.md#article-l552-3) ; [art. L1617-5 du Code général des collectivités territoriales](../../../code-general-des-collectivites-territoriales/partie-legislative/premiere-partie/livre-vi/titre-ier/chapitre-vii.md#article-l1617-5) ; [art. L2333-87 du Code général des collectivités territoriales](../../../code-general-des-collectivites-territoriales/partie-legislative/deuxieme-partie/livre-iii/titre-iii/chapitre-iii.md#article-l2333-87) ; [art. L113-3-1 du Code pénitentiaire](https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000052849984) ; [art. L224-10 du Code pénitentiaire](https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000052850098)

Toute personne a le droit de connaître le prénom, le nom, la qualité et l'adresse administratives de l'agent chargé d'instruire sa demande ou de traiter l'affaire qui la concerne ; ces éléments figurent sur les correspondances qui lui sont adressées. Si des motifs intéressant la sécurité publique ou la sécurité des personnes le justifient, l'anonymat de l'agent est respecté.

### Article L111-3
- Identifiant : LEGIARTI000031367323
- État : en vigueur depuis le 01/01/2016
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000031367323
- Cité par : [art. L552-3 du Code des relations entre le public et l'administration](../../livre-v/titre-v/chapitre-ii.md#article-l552-3)

Les correspondances de l'administration sont adressées aux personnes concernées sous leur nom de famille, sauf demande expresse de ces dernières de voir figurer leur nom d'usage sur les correspondances qui leur sont adressées.
