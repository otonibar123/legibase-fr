# Chapitre IV : Infractions relatives aux entreprises de marché et aux chambres de compensation

Code monétaire et financier › Partie législative › Livre IV : Les marchés › Titre VI : Dispositions pénales

### Article L464-1
- Identifiant : LEGIARTI000006654275
- État : en vigueur depuis le 01/11/2007
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006654275
- Renvoie à : [art. L440-4 du Code monétaire et financier](../titre-iv/chapitre-ier.md#article-l440-4) ; [art. 226-13 du Code pénal](../../../../code-penal/partie-legislative/livre-ii/titre-ii/chapitre-vi.md#article-226-13) ; [art. 226-14 du Code pénal](https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006417946)
- Cité par : [art. L762-12 du Code monétaire et financier](../../livre-vii/titre-vi/chapitre-ii.md#article-l762-12) ; [art. L763-12 du Code monétaire et financier](../../livre-vii/titre-vi/chapitre-iii.md#article-l763-12) ; [art. L764-12 du Code monétaire et financier](../../livre-vii/titre-vi/chapitre-iv.md#article-l764-12) ; [Ordonnance n°2007-1490 du 18 octobre 2007, art. 12](https://www.legifrance.gouv.fr/loda/article_lc/LEGIARTI000020639274)

Est puni des peines prévues à l'article 226-13 du code pénal, le fait, pour tout dirigeant, salarié ou préposé des chambres de compensation, de violer le secret professionnel institué à l'article L. 440-4, sous réserve des dispositions de l'article 226-14 du code pénal.

### Article L464-2
- Identifiant : LEGIARTI000006654277
- État : en vigueur depuis le 01/11/2007
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006654277
- Renvoie à : [art. L421-8 du Code monétaire et financier](../titre-ii/chapitre-ier.md#article-l421-8) ; [art. 226-13 du Code pénal](../../../../code-penal/partie-legislative/livre-ii/titre-ii/chapitre-vi.md#article-226-13) ; [art. 226-14 du Code pénal](https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006417946)
- Cité par : [art. L734-3 du Code monétaire et financier](../../livre-vii/titre-iii/chapitre-iv.md#article-l734-3) ; [art. L762-12 du Code monétaire et financier](../../livre-vii/titre-vi/chapitre-ii.md#article-l762-12) ; [art. L763-12 du Code monétaire et financier](../../livre-vii/titre-vi/chapitre-iii.md#article-l763-12) ; [art. L764-12 du Code monétaire et financier](../../livre-vii/titre-vi/chapitre-iv.md#article-l764-12)

Est puni des peines prévues à l'article 226-13 du code pénal le fait pour les membres des organes d'administration, de direction et de surveillance, les dirigeants, salariés et préposés des entreprises de marché de violer le secret professionnel institué à l'article L. 421-8, sous réserve des dispositions de l'article 226-14 du code pénal.
