# Chapitre II : Infractions relatives aux marchés réglementés

Code monétaire et financier › Partie législative › Livre IV : Les marchés › Titre VI : Dispositions pénales

### Article L462-2
- Identifiant : LEGIARTI000006654271
- État : en vigueur depuis le 01/01/2001
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006654271
- Renvoie à : art. L245-2 du Code de commerce

Les sanctions relatives à la publicité pour la souscription de valeurs mobilières sont fixées par l'article L. 245-2 du code de commerce.

> Nota : L'article L. 245-2 du code de commerce a été abrogé par l'article 122 2° de la loi n° 2001-420 du 15 mai 2001.
