# Chapitre IV : Infractions concernant la Banque de France

Code monétaire et financier › Partie législative › Livre Ier : La monnaie › Titre VI : Dispositions pénales

### Article L164-1
- Identifiant : LEGIARTI000019306196
- État : en vigueur depuis le 06/08/2008
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000019306196
- Renvoie à : [art. L142-3 du Code monétaire et financier](../titre-iv/chapitre-ii.md#article-l142-3) ; [art. 226-13 du Code pénal](../../../../code-penal/partie-legislative/livre-ii/titre-ii/chapitre-vi.md#article-226-13) ; art. 226-14 du Code pénal

Est puni des peines prévues à l'article 226-13 du code pénal, le fait, pour les membres du conseil général, de violer le secret professionnel institué à l'article L. 142-3, sous réserve des dérogations prévues à l'article 226-14 du code pénal.

### Article L164-2
- Identifiant : LEGIARTI000006646359
- État : en vigueur depuis le 01/01/2001
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006646359
- Renvoie à : [art. L142-9 du Code monétaire et financier](../titre-iv/chapitre-ii.md#article-l142-9) ; [art. 226-13 du Code pénal](../../../../code-penal/partie-legislative/livre-ii/titre-ii/chapitre-vi.md#article-226-13) ; [art. 226-14 du Code pénal](https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006417946)

Est puni des peines prévues à l'article 226-13 du code pénal, le fait, pour tout agent de la Banque de France, de violer le secret professionnel institué au premier alinéa de l'article L. 142-9, sous réserve des dérogations prévues à l'article 226-14 du code pénal.
