# Chapitre unique : Taxe générale sur les activités polluantes

Code de l'environnement › Partie législative › Livre Ier : Dispositions communes › Titre V : Dispositions financières

### Article L151-1
- Identifiant : LEGIARTI000053190300
- État : en vigueur depuis le 31/03/2026
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000053190300
- Renvoie à : [art. L541-10-1 du Code de l'environnement](../../livre-v/titre-iv/chapitre-ier.md#article-l541-10-1)
- Cité par : [art. L651-4 du Code de l'environnement](../../livre-vi/titre-v/chapitre-ier.md#article-l651-4) ; [art. R151-1 du Code de l'environnement](../../../partie-reglementaire/livre-ier/titre-v/chapitre-unique.md#article-r151-1)

La taxe générale sur les activités polluantes est déclarée, acquittée, recouvrée et contrôlée conformément aux articles 299 à 266 terdecies du code des douanes.

> Nota : Conformément au IV de l'article 21 de l'ordonnance n° 2025-1247 du 17 décembre 2025, ces dispositions, dans leur rédaction issue de ladite ordonnance, entrent en vigueur le 31 mars 2026.
