# Titre XIII : Le ministère public. : articles rattachés directement

### Article 421
- Identifiant : LEGIARTI000006410654
- État : en vigueur depuis le 01/01/1976
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006410654

Le ministère public peut agir comme partie principale ou intervenir comme partie jointe. Il représente autrui dans les cas que la loi détermine.
