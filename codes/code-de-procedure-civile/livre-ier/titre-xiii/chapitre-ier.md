# Chapitre Ier : Le ministère public partie principale.

Code de procédure civile › Livre Ier : Dispositions communes à toutes les juridictions › Titre XIII : Le ministère public.

### Article 422
- Identifiant : LEGIARTI000006410656
- État : en vigueur depuis le 01/01/1976
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006410656

Le ministère public agit d'office dans les cas spécifiés par la loi.

### Article 423
- Identifiant : LEGIARTI000006410657
- État : en vigueur depuis le 01/01/1976
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006410657

En dehors de ces cas, il peut agir pour la défense de l'ordre public à l'occasion des faits qui portent atteinte à celui-ci.
