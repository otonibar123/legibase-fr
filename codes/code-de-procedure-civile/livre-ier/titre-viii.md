# Titre VIII : La pluralité des parties.

Code de procédure civile › Livre Ier : Dispositions communes à toutes les juridictions

### Article 323
- Identifiant : LEGIARTI000006410480
- État : en vigueur depuis le 01/01/1976
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006410480

Lorsque la demande est formée par ou contre plusieurs cointéressés, chacun d'eux exerce et supporte pour ce qui le concerne les droits et obligations des parties à l'instance.

### Article 324
- Identifiant : LEGIARTI000025191450
- État : en vigueur depuis le 23/01/2012
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000025191450
- Renvoie à : [art. 475 du Code de procédure civile](titre-xiv/chapitre-ier.md#article-475) ; [art. 529 du Code de procédure civile](titre-xvi/sous-titre-ier.md#article-529) ; [art. 552 du Code de procédure civile](titre-xvi/sous-titre-ii/chapitre-ier.md#article-552) ; [art. 615 du Code de procédure civile](titre-xvi/sous-titre-iii/chapitre-iii.md#article-615)

Les actes accomplis par ou contre l'un des cointéressés ne profitent ni ne nuisent aux autres, sous réserve de ce qui est dit aux articles 475, 529, 552, 553 et 615.
