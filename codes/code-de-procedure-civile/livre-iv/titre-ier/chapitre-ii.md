# Chapitre II : Le tribunal arbitral

Code de procédure civile › Livre IV : L'arbitrage. › Titre Ier : L'arbitrage interne.

### Article 1451
- Identifiant : LEGIARTI000023450928
- État : en vigueur depuis le 01/05/2011
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000023450928
- Renvoie à : [art. 1459 du Code de procédure civile](chapitre-ii.md#article-1459)
- Cité par : [art. 1444 du Code de procédure civile](chapitre-ier.md#article-1444) ; [art. 1459 du Code de procédure civile](chapitre-ii.md#article-1459) ; [art. 20 du Code de déontologie des professionnels de l'exp...](https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006861790) ; [Décret n°2012-432 du 30 mars 2012, art. 160](https://www.legifrance.gouv.fr/loda/article_lc/LEGIARTI000025599781)

Le tribunal arbitral est composé d'un ou de plusieurs arbitres en nombre impair.

Il est complété si la convention d'arbitrage prévoit la désignation d'arbitres en nombre pair.

Si les parties ne s'accordent pas sur la désignation d'un arbitre complémentaire, le tribunal arbitral est complété dans un délai d'un mois à compter de l'acceptation de leur désignation par les arbitres choisis ou, à défaut, par le juge d'appui mentionné à l'article 1459.

### Article 1455
- Identifiant : LEGIARTI000023450915
- État : en vigueur depuis le 01/05/2011
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000023450915
- Cité par : [art. 1459 du Code de procédure civile](chapitre-ii.md#article-1459) ; [art. 1460 du Code de procédure civile](chapitre-ii.md#article-1460)

Si la convention d'arbitrage est manifestement nulle ou manifestement inapplicable, le juge d'appui déclare n'y avoir lieu à désignation.

### Article 1458
- Identifiant : LEGIARTI000023450842
- État : en vigueur depuis le 01/05/2011
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000023450842
- Renvoie à : [art. 1456 du Code de procédure civile](https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006412643)

L'arbitre ne peut être révoqué que du consentement unanime des parties. A défaut d'unanimité, il est procédé conformément aux dispositions du dernier alinéa de l'article 1456.

> Nota : Décret n° 2011-48 du 13 janvier 2011 article 3 2°: Ces dispositions s'appliquent lorsque le tribunal a été constitué postérieurement au 1er mai 2011.

### Article 1459
- Identifiant : LEGIARTI000039386127
- État : en vigueur depuis le 01/01/2020
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000039386127
- Renvoie à : [art. 1451 du Code de procédure civile](chapitre-ii.md#article-1451) ; [art. 1455 du Code de procédure civile](chapitre-ii.md#article-1455)
- Cité par : [art. 1451 du Code de procédure civile](chapitre-ii.md#article-1451)

Le juge d'appui compétent est le président du tribunal judiciaire.

Toutefois, si la convention d'arbitrage le prévoit expressément, le président du tribunal de commerce est compétent pour connaître des demandes formées en application des articles 1451 à 1454. Dans ce cas, il peut faire application de l'article 1455.

Le juge territorialement compétent est celui désigné par la convention d'arbitrage ou, à défaut, celui dans le ressort duquel le siège du tribunal arbitral a été fixé. En l'absence de toute stipulation de la convention d'arbitrage, le juge territorialement compétent est celui du lieu où demeure le ou l'un des défendeurs à l'incident ou, si le défendeur ne demeure pas en France, du lieu où demeure le demandeur.

> Nota : Conformément à l’article 9 du décret n° 2019-966 du 18 septembre 2019, les présentes dispositions entrent en vigueur le 1er janvier 2020.

### Article 1460
- Identifiant : LEGIARTI000039725931
- État : en vigueur depuis le 01/01/2020
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000039725931
- Renvoie à : [art. 1455 du Code de procédure civile](chapitre-ii.md#article-1455)
- Cité par : [art. 1506 du Code de procédure civile](https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000054637921)

Le juge d'appui est saisi soit par une partie, soit par le tribunal arbitral ou l'un de ses membres.

Le juge statue selon la procédure accélérée au fond.

Le juge d'appui statue par jugement non susceptible de recours. Toutefois, ce jugement peut être frappé d'appel lorsque le juge déclare n'y avoir lieu à désignation pour une des causes prévues à l'article 1455.

> Nota : Conformément à l'article 24 du décret n° 2019-1419 du 20 décembre 2019, les dispositions qui résultent du décret précité s'appliquent aux demandes introduites à compter du 1er janvier 2020.

### Article 1461
- Identifiant : LEGIARTI000023450832
- État : en vigueur depuis le 01/05/2011
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000023450832
