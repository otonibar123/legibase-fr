# Chapitre III : Les baux passés par les usufruitiers avec autorisation de justice.

Code de procédure civile › Livre III : Dispositions particulières à certaines matières › Titre II : Les biens.

### Article 1270
- Identifiant : LEGIARTI000025191519
- État : en vigueur depuis le 23/01/2012
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000025191519
- Renvoie à : [art. 595 du Code civil](../../../code-civil/livre-ii/titre-iii/chapitre-ier.md#article-595)

La demande de l'usufruitier tendant à être autorisé à conclure seul un bail en application de l'article 595 du code civil est formée, instruite et jugée suivant la procédure à jour fixe.
