# Chapitre II : Du groupement européen d'intérêt économique.

Code de commerce › Partie réglementaire › LIVRE II : Des sociétés commerciales et des groupements d'intérêt économique. › TITRE V : Des groupements d'intérêt économique.

### Article R252-1
- Identifiant : LEGIARTI000039346060
- État : en vigueur depuis le 01/01/2020
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000039346060
- Cité par : [art. R910-1 du Code de commerce](../../livre-ix/titre-ier/articles-directs.md#article-r910-1) ; [art. R920-1 du Code de commerce](../../livre-ix/titre-ii/articles-directs.md#article-r920-1) ; [art. R930-1 du Code de commerce](../../livre-ix/titre-iii/articles-directs.md#article-r930-1)

Le procureur de la République est compétent pour saisir le tribunal judiciaire ou le tribunal de commerce, selon le cas, en application de l'article 32-1 du règlement (CEE) n° 2137/85 du Conseil des Communautés européennes du 25 juillet 1985 relatif à l'institution d'un groupement européen d'intérêt économique.

> Nota : Conformément à l’article 9 du décret n° 2019-966 du 18 septembre 2019, les présentes dispositions entrent en vigueur le 1er janvier 2020.
