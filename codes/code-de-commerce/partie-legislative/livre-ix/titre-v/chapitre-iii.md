# Chapitre III : Dispositions d'adaptation du livre III.

Code de commerce › Partie législative › LIVRE IX : Dispositions relatives à l'outre-mer. › TITRE V : Dispositions applicables dans les îles Wallis et Futuna.

### Article L953-1
- Identifiant : LEGIARTI000006245402
- État : en vigueur depuis le 27/03/2004
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006245402
- Renvoie à : [art. L310-2 du Code de commerce](../../livre-iii/titre-ier.md#article-l310-2) ; [art. L310-5 du Code de commerce](https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006231308)

Le III de l'article L. 310-2 et le 6° de l'article L. 310-5 sont supprimés.

### Article L953-2
- Identifiant : LEGIARTI000042330341
- État : en vigueur depuis le 01/06/2012
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000042330341
- Renvoie à : [art. L322-1 du Code de commerce](../../livre-iii/titre-ii/chapitre-ii.md#article-l322-1) ; art. L221-4 du Code des procédures civiles d'exécution

A l'article L. 322-1, les mots : " aux articles L. 221-4 du code des procédures civiles d'exécution et 945 du code de procédure civile " sont remplacés par les mots : " aux dispositions de procédure civile applicables dans le territoire relatives à la vente de meubles dépendant d'une succession ".

### Article L953-3
- Identifiant : LEGIARTI000024385581
- État : en vigueur depuis le 01/09/2011
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000024385581
- Renvoie à : [art. L322-9 du Code de commerce](../../livre-iii/titre-ii/chapitre-ii.md#article-l322-9)

L'article L. 322-9 est ainsi rédigé :

" Les courtiers de marchandises assermentés se conforment aux dispositions prescrites par le code des impôts applicable dans le territoire relatives aux ventes publiques et par enchères. "
