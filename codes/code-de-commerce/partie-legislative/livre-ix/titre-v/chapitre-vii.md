# Chapitre VII : Dispositions d'adaptation du livre VII.

Code de commerce › Partie législative › LIVRE IX : Dispositions relatives à l'outre-mer. › TITRE V : Dispositions applicables dans les îles Wallis et Futuna.

### Article L957-1
- Identifiant : LEGIARTI000006245636
- État : en vigueur depuis le 21/09/2000
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006245636
- Renvoie à : [art. L711-2 du Code de commerce](../../livre-vii/titre-ier/chapitre-ier.md#article-l711-2) ; [art. L711-4 du Code de commerce](../../livre-vii/titre-ier/chapitre-ier.md#article-l711-4)

Aux articles L. 711-2 et L. 711-4, le mot : " Gouvernement " est remplacé par les mots : " représentant de l'Etat dans le territoire ".

### Article L957-2
- Identifiant : LEGIARTI000006245655
- État : en vigueur depuis le 21/09/2000
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006245655
- Renvoie à : [art. L711-6 du Code de commerce](../../livre-vii/titre-ier/chapitre-ier.md#article-l711-6)

Au troisième alinéa de l'article L. 711-6, les mots : " ou la commune " sont remplacés par les mots : " ou le territoire ".

### Article L957-3
- Identifiant : LEGIARTI000006245656
- État : en vigueur depuis le 21/09/2000
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006245656
- Renvoie à : [art. L712-1 du Code de commerce](../../livre-vii/titre-ier/chapitre-ii.md#article-l712-1)

A l'article L. 712-1, les mots : " au moyen d'une taxe additionnelle à la taxe professionnelle " sont remplacés par les mots : " comme il est dit dans les dispositions du code des impôts applicable dans les îles Wallis et Futuna ".
