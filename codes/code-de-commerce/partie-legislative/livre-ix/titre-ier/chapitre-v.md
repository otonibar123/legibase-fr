# Chapitre V : Dispositions d'adaptation du livre V.

Code de commerce › Partie législative › LIVRE IX : Dispositions relatives à l'outre-mer. › TITRE Ier : Dispositions spécifiques à Saint-Pierre-et-Miquelon.

### Article L915-1
- Identifiant : LEGIARTI000006243138
- État : en vigueur depuis le 21/09/2000
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006243138
- Renvoie à : [art. L511-45 du Code de commerce](../../livre-v/titre-ier/chapitre-ier.md#article-l511-45) ; [art. L511-62 du Code de commerce](../../livre-v/titre-ier/chapitre-ier.md#article-l511-62)

Le deuxième alinéa de l'article L. 511-62 est ainsi rédigé :  

" La retraite comprend les sommes indiquées dans les articles L. 511-45 et L. 511-46, outre les droits de courtage et de timbre éventuellement prévus par les dispositions du code des impôts applicable localement. "
