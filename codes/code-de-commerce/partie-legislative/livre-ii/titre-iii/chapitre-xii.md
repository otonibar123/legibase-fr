# Chapitre XII : De la mixité dans les instances dirigeantes des sociétés commerciales

Code de commerce › Partie législative › LIVRE II : Des sociétés commerciales et des groupements d'intérêt économique. › TITRE III : Dispositions communes aux diverses sociétés commerciales.

### Article L23-12-1
- Identifiant : LEGIARTI000044566715
- État : en vigueur depuis le 27/12/2021
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000044566715
- Cité par : [art. L2312-18 du Code du travail](../../../../code-du-travail/partie-legislative/deuxieme-partie/livre-iii/titre-ier/chapitre-ii.md#article-l2312-18) ; [art. R2312-7 du Code du travail](../../../../code-du-travail/partie-reglementaire/deuxieme-partie/livre-iii/titre-ier/chapitre-ii.md#article-r2312-7) ; [Arrêté du 27 octobre 2022, art. 1](https://www.legifrance.gouv.fr/loda/article_lc/LEGIARTI000046522088) ; [art. D1142-15 du Code du travail](https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000047548240)

Est considérée comme instance dirigeante toute instance mise en place au sein de la société, par tout acte ou toute pratique sociétaire, aux fins d'assister régulièrement les organes chargés de la direction générale dans l'exercice de leurs missions.
