# Chapitre unique : Subventions aux exploitants d'établissements de spectacles cinématographiques

Code du cinéma et de l'image animée › Partie législative › Livre III : Financement et fiscalité › Titre II : Aides des collectivités territoriales

### Article L321-1
- Identifiant : LEGIARTI000020908469
- État : en vigueur depuis le 26/07/2009
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000020908469
- Renvoie à : [art. L2251-4 du Code général des collectivités territoriales](https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006390490)

Les règles relatives aux subventions attribuées par les communes aux exploitants d'établissements de spectacles cinématographiques sont fixées par l'article L. 2251-4 du code général des collectivités territoriales.

### Article L321-2
- Identifiant : LEGIARTI000020908467
- État : en vigueur depuis le 26/07/2009
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000020908467
- Renvoie à : [art. L3232-4 du Code général des collectivités territoriales](https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006391778)

Les règles relatives aux subventions attribuées par les départements aux exploitants d'établissements de spectacles cinématographiques sont fixées par l'article L. 3232-4 du code général des collectivités territoriales.

### Article L321-3
- Identifiant : LEGIARTI000020908465
- État : en vigueur depuis le 26/07/2009
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000020908465
- Renvoie à : [art. L4211-1 du Code général des collectivités territoriales](../../../../code-general-des-collectivites-territoriales/partie-legislative/quatrieme-partie/livre-ii/titre-ier/chapitre-unique.md#article-l4211-1)

Les régions peuvent, conformément au 6° de l'article L. 4211-1 du code général des collectivités territoriales, attribuer des subventions aux exploitants d'établissements de spectacles cinématographiques dans les mêmes conditions et limites que les départements.
