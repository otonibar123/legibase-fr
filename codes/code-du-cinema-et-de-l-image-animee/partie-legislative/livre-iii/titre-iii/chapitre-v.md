# Chapitre V : Contribution économique territoriale

Code du cinéma et de l'image animée › Partie législative › Livre III : Financement et fiscalité › Titre III : Incitations fiscales

### Article L335-1
- Identifiant : LEGIARTI000021658254
- État : en vigueur depuis le 01/01/2010
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000021658254
- Renvoie à : [art. 1464 du Code général des impôts](../../../../code-general-des-impots/livre-premier/deuxieme-partie/titre-premier/chapitre-premier.md#article-1464) ; [art. 1464 A du Code général des impôts](https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006311640)

L'exonération de cotisation foncière des entreprises, applicable aux exploitants d'établissements de spectacles cinématographiques, est régie par les 3° à 4° de l'article 1464 A du code général des impôts.
