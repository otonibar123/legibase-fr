# CHAPITRE IV : Action sociale

Code général des collectivités territoriales › Partie législative › TROISIEME PARTIE : LE DÉPARTEMENT › LIVRE II : ADMINISTRATION ET SERVICES DÉPARTEMENTAUX › TITRE Ier : COMPÉTENCES DU CONSEIL DEPARTEMENTAL

### Article L3214-1
- Identifiant : LEGIARTI000027573855
- État : en vigueur depuis le 22/03/2015
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000027573855
- Renvoie à : [art. L132-15 du Code de la sécurité intérieure](../../../../../code-de-la-securite-interieure/partie-legislative/livre-ier/titre-iii/chapitre-ii.md#article-l132-15) ; [art. L5211-59 du Code général des collectivités territoriales](../../../cinquieme-partie/livre-ii/titre-ier/chapitre-ier.md#article-l5211-59)

Le conseil départemental adopte le règlement départemental d'aide sociale définissant les règles selon lesquelles sont accordées les prestations d'aide sociale relevant du département.

Le conseil départemental concourt aux actions de prévention de la délinquance dans les conditions prévues à l'article L. 132-15 du code de la sécurité intérieure.

### Article L3214-2
- Identifiant : LEGIARTI000038902286
- État : en vigueur depuis le 02/09/2019
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000038902286
- Renvoie à : [art. L3211-2 du Code général des collectivités territoriales](chapitre-ier.md#article-l3211-2)
- Cité par : [art. L533-2 du Code de l'éducation](../../../../../code-de-l-education/partie-legislative/deuxieme-partie/livre-v/titre-iii/chapitre-iii.md#article-l533-2) ; [art. L561-2 du Code de l'éducation](../../../../../code-de-l-education/partie-legislative/deuxieme-partie/livre-v/titre-vi/chapitre-ier.md#article-l561-2) ; [art. L561-3 du Code de l'éducation](../../../../../code-de-l-education/partie-legislative/deuxieme-partie/livre-v/titre-vi/chapitre-ier.md#article-l561-3) ; [art. L3551-6 du Code général des collectivités territoriales](https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006392017)

Le conseil départemental, sauf s'il a délégué sa compétence au président, en application de l'article L. 3211-2, attribue et retire les bourses entretenues sur les fonds départementaux, sur l'avis motivé :

1° Du chef d'établissement et du conseil d'administration, pour les établissements publics d'enseignement ;

2° Du responsable d'établissement, pour les établissements d'enseignement privé.

L'autorité compétente peut prononcer le retrait dans les cas d'urgence ; elle en donne avis immédiatement au président du conseil départemental et en fait connaître les motifs.

> Nota : Conformément à l'article 63 de la loi n° 2019-791 du 26 juillet 2019, ces dispositions entrent en vigueur à la rentrée scolaire 2019.
