# CHAPITRE II : Concessions et affermages

Code général des collectivités territoriales › Partie législative › DEUXIÈME PARTIE : LA COMMUNE › LIVRE II : ADMINISTRATION ET SERVICES COMMUNAUX › TITRE II : SERVICES COMMUNAUX

### Article L2222-1
- Identifiant : LEGIARTI000006390269
- État : en vigueur depuis le 24/02/1996
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006390269
- Cité par : [art. L2222-2 du Code général des collectivités territoriales](chapitre-ii.md#article-l2222-2) ; [art. L2564-25 du Code général des collectivités territoriales](../../livre-v/titre-vi/chapitre-iv.md#article-l2564-25) ; [art. L2572-24 du Code général des collectivités territoriales](https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006391479)

Dans les contrats portant concession de service public, les communes ainsi que les établissements publics communaux ne peuvent pas insérer de clauses par lesquelles le concessionnaire prend à sa charge l'exécution de travaux étrangers à l'objet de la concession.

### Article L2222-2
- Identifiant : LEGIARTI000006390270
- État : en vigueur depuis le 24/02/1996
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006390270
- Renvoie à : [art. L2222-1 du Code général des collectivités territoriales](chapitre-ii.md#article-l2222-1)

Les contrats de travaux publics conclus par les collectivités mentionnées à l'article L. 2222-1 ne doivent pas contenir de clauses portant affermage d'une recette publique.
