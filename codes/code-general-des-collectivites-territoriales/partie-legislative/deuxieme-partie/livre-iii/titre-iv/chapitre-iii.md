# CHAPITRE III : Comptabilité du comptable

Code général des collectivités territoriales › Partie législative › DEUXIÈME PARTIE : LA COMMUNE › LIVRE III : FINANCES COMMUNALES › TITRE IV : COMPTABILITÉ

### Article L2343-1
- Identifiant : LEGIARTI000051732009
- État : en vigueur depuis le 01/01/2026
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000051732009
- Cité par : [art. L2221-12 du Code général des collectivités territoriales](../../livre-ii/titre-ii/chapitre-ier.md#article-l2221-12) ; [art. L2543-1 du Code général des collectivités territoriales](../../livre-v/titre-iv/chapitre-iii.md#article-l2543-1) ; [art. L2573-57 du Code général des collectivités territoriales](../../livre-v/titre-vii/chapitre-iii.md#article-l2573-57) ; [Arrêté du 17 septembre 2026](https://www.legifrance.gouv.fr/loda/id/LEGITEXT000054889647) ; [art. L2572-67 du Code général des collectivités territoriales](https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006391529)

Les dispositions de l'article L. 1612-39 s'appliquent, pour le comptable de la commune, sous réserve des dispositions de l'article 201 de la loi n° 2018-1317 du 28 décembre 2018 de finances pour 2019.

Tous les rôles de taxe, de sous-répartition et de prestations locales sont remis à ce comptable.

> Nota : Conformément à l'article 12 de l'ordonnance n° 2025-526 du 12 juin 2025, les dispositions de ladite ordonnance s'appliquent à compter de l'exercice budgétaire 2026.
