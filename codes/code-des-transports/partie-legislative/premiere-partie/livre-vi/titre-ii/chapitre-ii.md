# Chapitre II : Sanctions relatives à l'enquête technique

Code des transports › PARTIE LÉGISLATIVE › PREMIÈRE PARTIE : DISPOSITIONS COMMUNES › LIVRE VI : SÛRETÉ ET SÉCURITÉ DES TRANSPORTS › TITRE II : DISPOSITIONS COMMUNES RELATIVES À L'ENQUÊTE TECHNIQUE ET À L'ENQUÊTE DE SÉCURITÉ APRÈS UN ACCIDENT OU UN INCIDENT DE TRANSPORT

### Article L1622-1
- Identifiant : LEGIARTI000026178557
- État : en vigueur depuis le 14/07/2012
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000026178557
- Renvoie à : [art. L1621-6 du Code des transports](chapitre-ier.md#article-l1621-6) ; [art. L1621-10 du Code des transports](chapitre-ier.md#article-l1621-10)
- Cité par : [art. L1622-2 du Code des transports](chapitre-ii.md#article-l1622-2) ; [art. L6232-11 du Code des transports](../../../sixieme-partie/livre-ii/titre-iii/chapitre-ii.md#article-l6232-11)

Est puni d'un an d'emprisonnement et de 15 000 € d'amende le fait d'entraver l'action des enquêteurs techniques et des enquêteurs de sécurité mentionnés aux articles L. 1621-6 et L. 1621-10 :

1° Soit en s'opposant à l'exercice des fonctions dont ils sont chargés ;

2° Soit en refusant de leur communiquer les enregistrements, les matériels, les informations et les documents utiles, en les dissimulant, en les altérant ou en les faisant disparaître.

### Article L1622-2
- Identifiant : LEGIARTI000023085102
- État : en vigueur depuis le 01/12/2010
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000023085102
- Renvoie à : [art. L1622-1 du Code des transports](chapitre-ii.md#article-l1622-1) ; [art. 121-2 du Code pénal](../../../../../code-penal/partie-legislative/livre-ier/titre-ii/chapitre-ier.md#article-121-2) ; [art. 131-38 du Code pénal](../../../../../code-penal/partie-legislative/livre-ier/titre-iii/chapitre-ier.md#article-131-38) ; [art. 131-39 du Code pénal](../../../../../code-penal/partie-legislative/livre-ier/titre-iii/chapitre-ier.md#article-131-39)
- Cité par : [art. L6232-11 du Code des transports](../../../sixieme-partie/livre-ii/titre-iii/chapitre-ii.md#article-l6232-11)

Les personnes morales reconnues pénalement responsables, dans les conditions prévues par l'article 121-2 du code pénal, des infractions définies par l'article L. 1622-1 encourent, outre l'amende selon les modalités prévues par l'article 131-38 du code pénal, les peines mentionnées à l'article 131-39 du même code.  
L'interdiction mentionnée au 2° de l'article 131-39 du même code porte sur l'activité dans l'exercice ou à l'occasion de l'exercice de laquelle l'infraction a été commise.
