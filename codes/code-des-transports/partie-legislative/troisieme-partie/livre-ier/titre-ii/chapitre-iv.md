## Section 1 : Dispositions relatives aux taxis › Sous-section 1 : Sanctions administratives

### Article L3124-1
- Identifiant : LEGIARTI000028534381
- État : en vigueur depuis le 29/01/2014
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000028534381
- Cité par : [art. R3121-11 du Code des transports](../../../../partie-reglementaire/troisieme-partie/livre-ier/titre-ii/chapitre-ier.md#article-r3121-11) ; [art. R3121-15 du Code des transports](../../../../partie-reglementaire/troisieme-partie/livre-ier/titre-ii/chapitre-ier.md#article-r3121-15) ; [art. R3124-1 du Code des transports](../../../../partie-reglementaire/troisieme-partie/livre-ier/titre-ii/chapitre-iv.md#article-r3124-1) ; [Arrêté du 28 juillet 2023, art. 4](https://www.legifrance.gouv.fr/loda/article_lc/LEGIARTI000047942038) ; [Décret n°2023-683 du 28 juillet 2023, art. 8](https://www.legifrance.gouv.fr/loda/article_lc/LEGIARTI000047905730)

Lorsque l'autorisation de stationnement n'est pas exploitée de façon effective ou continue, ou en cas de violation grave ou répétée par son titulaire du contenu de cette autorisation ou de la réglementation applicable à la profession, l'autorité administrative compétente pour la délivrer peut donner un avertissement au titulaire de cette autorisation de stationnement ou procéder à son retrait temporaire ou définitif.

## Section 1 : Dispositions relatives aux taxis › Sous-section 2 : Sanctions pénales

### Article L3124-5
- Identifiant : LEGIARTI000023083860
- État : en vigueur depuis le 01/12/2010
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000023083860
- Renvoie à : [art. 121-2 du Code pénal](../../../../../code-penal/partie-legislative/livre-ier/titre-ii/chapitre-ier.md#article-121-2) ; [art. 131-38 du Code pénal](../../../../../code-penal/partie-legislative/livre-ier/titre-iii/chapitre-ier.md#article-131-38) ; [art. 131-39 du Code pénal](../../../../../code-penal/partie-legislative/livre-ier/titre-iii/chapitre-ier.md#article-131-39) ; [art. L3124-4 du Code des transports](https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000023071117)
- Cité par : [art. L3531-1 du Code des transports](../../livre-v/titre-iii/chapitre-unique.md#article-l3531-1) ; [art. L3541-1 du Code des transports](../../livre-v/titre-iv/chapitre-unique.md#article-l3541-1)

Les personnes morales déclarées responsables pénalement, dans les conditions prévues par l'article 121-2 du code pénal, de l'infraction définie par le I de l'article L. 3124-4 encourent, outre l'amende, suivant les modalités prévues par l'article 131-38 du code pénal, les peines prévues par les 8° et 9° de l'article 131-39 du même code.

En cas de violation de la réglementation applicable à la profession par le conducteur d'un véhicule de transport public particulier de personnes, l'autorité administrative peut lui donner un avertissement ou procéder au retrait temporaire ou définitif de sa carte professionnelle.

### Article L3124-13
- Identifiant : LEGIARTI000054336093
- État : en vigueur depuis le 27/06/2026
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000054336093
- Renvoie à : [art. L3120-1 du Code des transports](chapitre-preliminaire.md#article-l3120-1) ; [art. 131-38 du Code pénal](../../../../../code-penal/partie-legislative/livre-ier/titre-iii/chapitre-ier.md#article-131-38) ; [art. 131-39 du Code pénal](../../../../../code-penal/partie-legislative/livre-ier/titre-iii/chapitre-ier.md#article-131-39)

Lorsque l'établissement de la preuve d'un des délits définis au présent chapitre en dépend, les agents habilités à constater des infractions au titre du présent code peuvent ne décliner leur qualité qu'au moment où ils informent la personne contrôlée de la constatation de l'infraction.
