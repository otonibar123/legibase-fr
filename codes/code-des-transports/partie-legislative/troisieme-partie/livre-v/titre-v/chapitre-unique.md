### Article L3551-4
- Identifiant : LEGIARTI000023083496
- État : en vigueur depuis le 01/12/2010
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000023083496
- Renvoie à : [art. L3411-1 du Code des transports](../../livre-iv/titre-ier/chapitre-unique.md#article-l3411-1)

Pour son application à Saint-Pierre-et-Miquelon, l'article L. 3411-1 est ainsi modifié :  
1° Au premier aliéna, les mots : " d'une licence communautaire ou " sont supprimés ;  
2° Le deuxième alinéa n'est pas applicable ;  
3° Au troisième alinéa, les mots : " et qui n'ont pas l'obligation de détenir une licence communautaire " sont supprimés.

### Article L3551-5
- Identifiant : LEGIARTI000031966445
- État : en vigueur depuis le 01/02/2016
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000031966445
- Renvoie à : [art. L3452-6 du Code des transports](../../livre-iv/titre-v/chapitre-ii.md#article-l3452-6) ; [art. L3452-7 du Code des transports](../../livre-iv/titre-v/chapitre-ii.md#article-l3452-7) ; [art. L3452-8 du Code des transports](../../livre-iv/titre-v/chapitre-ii.md#article-l3452-8)
