# Chapitre III : Navigation des bateaux motorisés

Code des transports › PARTIE LÉGISLATIVE › QUATRIÈME PARTIE : NAVIGATION INTÉRIEURE ET TRANSPORT FLUVIAL › LIVRE II : NAVIGATION INTÉRIEURE › TITRE IV : POLICE DE LA NAVIGATION INTÉRIEURE

### Article L4243-1
- Identifiant : LEGIARTI000023083231
- État : en vigueur depuis le 01/12/2010
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000023083231
- Cité par : [art. A4241-59-2 du Code des transports](../../../../partie-reglementaire-arretes/quatrieme-partie/livre-ii/titre-iv/chapitre-ier.md#article-a4241-59-2) ; [art. L4271-1 du Code des transports](../titre-vii/chapitre-ier.md#article-l4271-1)

La circulation des bateaux motorisés sur un cours d'eau non domanial, ou sur une section de ce cours d'eau, peut être interdite ou réglementée par arrêté préfectoral, sur avis du service chargé de la police de ce cours d'eau, soit pour un motif de sécurité ou de salubrité, soit à la demande du riverain lorsque cette circulation entraîne un trouble grave dans la jouissance de ses droits.
