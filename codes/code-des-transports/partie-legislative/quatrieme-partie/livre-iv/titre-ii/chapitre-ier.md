# Chapitre Ier : Entreprises de transport fluvial de marchandises

Code des transports › PARTIE LÉGISLATIVE › QUATRIÈME PARTIE : NAVIGATION INTÉRIEURE ET TRANSPORT FLUVIAL › LIVRE IV : LE TRANSPORT FLUVIAL › TITRE II : ENTREPRISES DE TRANSPORT FLUVIAL

### Article L4421-1
- Identifiant : LEGIARTI000023082782
- État : en vigueur depuis le 01/12/2010
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000023082782
- Cité par : [art. L1422-6 du Code des transports](../../../premiere-partie/livre-iv/titre-ii/chapitre-ii.md#article-l1422-6) ; [art. L4463-9 du Code des transports](../titre-vi/chapitre-iii.md#article-l4463-9) ; [art. R4421-16 du Code des transports](../../../../partie-reglementaire/quatrieme-partie/livre-iv/titre-ii/chapitre-ier.md#article-r4421-16)

L'exercice de la profession de transporteur fluvial de marchandises peut être subordonné à des conditions d'honorabilité professionnelle, de capacité financière et de capacité professionnelle, selon des modalités fixées par décret en Conseil d'Etat.

### Article L4421-2
- Identifiant : LEGIARTI000023082780
- État : en vigueur depuis le 01/12/2010
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000023082780
- Cité par : [art. L4611-2 du Code des transports](../../livre-vi/titre-ier/chapitre-unique.md#article-l4611-2) ; [art. L4621-2 du Code des transports](../../livre-vi/titre-ii/chapitre-unique.md#article-l4621-2) ; [art. L4631-2 du Code des transports](../../livre-vi/titre-iii/chapitre-unique.md#article-l4631-2) ; [art. L4641-2 du Code des transports](../../livre-vi/titre-iv/chapitre-unique.md#article-l4641-2) ; [art. L4651-2 du Code des transports](../../livre-vi/titre-v/chapitre-unique.md#article-l4651-2)

Toute entreprise établie en France et utilisant des bateaux pour le transport de marchandises est tenue de faire inscrire ces bateaux dans un fichier tenu par Voies navigables de France.  
Les modalités de cette inscription sont fixées par voie réglementaire.
