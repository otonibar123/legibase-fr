# Chapitre II : Entreprises de transport fluvial de personnes

### Article L4422-1
- Identifiant : LEGIARTI000043343361
- État : en vigueur depuis le 10/04/2021
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000043343361
- Renvoie à : [art. L1421-1 du Code des transports](../../../premiere-partie/livre-iv/titre-ii/chapitre-ier.md#article-l1421-1)
- Cité par : [art. L1421-5 du Code des transports](../../../premiere-partie/livre-iv/titre-ii/chapitre-ier.md#article-l1421-5) ; [art. L4463-9 du Code des transports](../titre-vi/chapitre-iii.md#article-l4463-9) ; [art. R4422-16 du Code des transports](../../../../partie-reglementaire/quatrieme-partie/livre-iv/titre-ii/chapitre-ii.md#article-r4422-16)

L'exercice de la profession de transporteur fluvial de personnes peut être subordonné à des conditions d'honorabilité professionnelle, de capacité financière et de capacité professionnelle, selon des modalités fixées par décret en Conseil d'Etat.
