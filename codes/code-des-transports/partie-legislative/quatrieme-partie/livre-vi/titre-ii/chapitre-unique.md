### Article L4621-2
- Identifiant : LEGIARTI000023082109
- État : en vigueur depuis le 01/12/2010
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000023082109
- Renvoie à : [art. L4412-1 du Code des transports](../../livre-iv/titre-ier/chapitre-ii.md#article-l4412-1) ; [art. L4421-2 du Code des transports](../../livre-iv/titre-ii/chapitre-ier.md#article-l4421-2) ; [art. L4462-3 du Code des transports](../../livre-iv/titre-vi/chapitre-ii.md#article-l4462-3) ; [art. L4462-4 du Code des transports](../../livre-iv/titre-vi/chapitre-ii.md#article-l4462-4) ; [art. L4462-5 du Code des transports](https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000023072178)

Pour l'application du livre IV à Mayotte :  
1° L'article L. 4412-1 n'est pas applicable ;  
2° A l'article L. 4421-2, les mots : " tenu par Voies navigables de France " sont remplacés par les mots : " tenu par l'autorité compétente de l'Etat " ;  
3° A l'article L. 4462-3, il est ajouté, après les mots : " au niveau national ", les mots : " ou au niveau local " ;  
4° A l'article L. 4462-4, le 1° est supprimé ;  
5° A l'article L. 4462-5, les mots : " le conseil d'administration de Voies navigables de France ou, par dérogation, son directeur général, " sont supprimés.
