# Chapitre II : Infractions relatives à l'identification du bateau

Code des transports › PARTIE LÉGISLATIVE › QUATRIÈME PARTIE : NAVIGATION INTÉRIEURE ET TRANSPORT FLUVIAL › LIVRE IER : LE BATEAU › TITRE IV : SANCTIONS PÉNALES

### Article L4142-1
- Identifiant : LEGIARTI000023083309
- État : en vigueur depuis le 01/12/2010
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000023083309
- Cité par : [art. R4421-12 du Code des transports](../../../../partie-reglementaire/quatrieme-partie/livre-iv/titre-ii/chapitre-ier.md#article-r4421-12) ; [art. R4422-12 du Code des transports](../../../../partie-reglementaire/quatrieme-partie/livre-iv/titre-ii/chapitre-ii.md#article-r4422-12)

Est puni de trois ans d'emprisonnement et de 45 000 € d'amende le fait d'appliquer à un bateau un certificat d'immatriculation autre que celui qui a été établi pour ce bateau.

### Article L4142-2
- Identifiant : LEGIARTI000023083307
- État : en vigueur depuis le 01/12/2010
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000023083307
- Renvoie à : [art. L4111-1 du Code des transports](../titre-ier/chapitre-ier.md#article-l4111-1)

Sont punies de 9 000 € d'amende les infractions à l'interdiction d'immatriculations multiples prévue par l'article L. 4111-1.

### Article L4142-3
- Identifiant : LEGIARTI000023083305
- État : en vigueur depuis le 01/12/2010
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000023083305
- Renvoie à : [art. L4111-1 du Code des transports](../titre-ier/chapitre-ier.md#article-l4111-1) ; [art. L4111-6 du Code des transports](../titre-ier/chapitre-ier.md#article-l4111-6) ; [art. L4111-7 du Code des transports](../titre-ier/chapitre-ier.md#article-l4111-7) ; [art. L4112-3 du Code des transports](../titre-ier/chapitre-ii.md#article-l4112-3) ; [art. L4113-1 du Code des transports](../titre-ier/chapitre-iii.md#article-l4113-1) ; [art. L4121-3 du Code des transports](../titre-ii/chapitre-ier.md#article-l4121-3)

Sont punies de 3 750 € d'amende les infractions :  

1° A l'obligation d'immatriculation prévue par l'article L. 4111-1 ;  

2° Aux prescriptions des articles L. 4111-6, L. 4112-3, L. 4113-1 et L. 4121-3, l'amende étant, dans ce cas, à la charge solidaire du conducteur et du propriétaire ;  

3° Aux prescriptions de l'article L. 4111-7.
