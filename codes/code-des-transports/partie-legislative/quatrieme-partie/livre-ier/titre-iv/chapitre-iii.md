# Chapitre III : Infractions relatives aux hypothèques

Code des transports › PARTIE LÉGISLATIVE › QUATRIÈME PARTIE : NAVIGATION INTÉRIEURE ET TRANSPORT FLUVIAL › LIVRE IER : LE BATEAU › TITRE IV : SANCTIONS PÉNALES

### Article L4143-1
- Identifiant : LEGIARTI000023083299
- État : en vigueur depuis le 01/12/2010
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000023083299
- Renvoie à : [art. 314-1 du Code pénal](../../../../../code-penal/partie-legislative/livre-iii/titre-ier/chapitre-iv.md#article-314-1) ; [art. 314-10 du Code pénal](../../../../../code-penal/partie-legislative/livre-iii/titre-ier/chapitre-iv.md#article-314-10)
- Cité par : [art. R4421-12 du Code des transports](../../../../partie-reglementaire/quatrieme-partie/livre-iv/titre-ii/chapitre-ier.md#article-r4421-12) ; [art. R4422-12 du Code des transports](../../../../partie-reglementaire/quatrieme-partie/livre-iv/titre-ii/chapitre-ii.md#article-r4422-12)

Est puni des peines de l'abus de confiance prévues par les articles 314-1 et 314-10 du code pénal le fait de détourner un bateau grevé d'une hypothèque régulièrement inscrite.
