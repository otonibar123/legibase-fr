# Chapitre Ier : Le transport de personnes

Code des transports › PARTIE RÉGLEMENTAIRE › CINQUIÈME PARTIE : TRANSPORT ET NAVIGATION MARITIMES › LIVRE IV : LE TRANSPORT MARITIME › TITRE II : LES CONTRATS RELATIFS À L'EXPLOITATION DU NAVIRE

### Article R5421-1
- Identifiant : LEGIARTI000033744345
- État : en vigueur depuis le 30/12/2016
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000033744345
- Cité par : [art. R5784-1 du Code des transports](../../livre-vii/titre-viii/chapitre-iv.md#article-r5784-1) ; [art. R5794-1 du Code des transports](../../livre-vii/titre-ix/chapitre-iv.md#article-r5794-1)

Les actions nées du contrat de transport de passagers sont portées soit devant les juridictions compétentes selon les règles du droit commun, soit devant le tribunal du port d'embarquement ou devant le tribunal du port de débarquement, s'il est situé sur le territoire de la République française.
