# Chapitre III : Constatation des infractions et sanctions

Code des transports › PARTIE RÉGLEMENTAIRE › TROISIÈME PARTIE : TRANSPORT ROUTIER › LIVRE IER : LE TRANSPORT ROUTIER DE PERSONNES › TITRE IV : LES ACTIVITÉS DE MISE EN RELATION

## Section 1 : Contrôles

### Article R3143-1
- Identifiant : LEGIARTI000037661880
- État : en vigueur depuis le 01/01/2019
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000037661880
- Renvoie à : [art. L3141-1 du Code des transports](../../../../partie-legislative/troisieme-partie/livre-ier/titre-iv/chapitre-ier.md#article-l3141-1)
- Cité par : [art. R3143-4 du Code des transports](chapitre-iii.md#article-r3143-4)

L'opérateur de mise en relation mentionné à l'article L. 3141-1 tient à la disposition des services chargés des contrôles les preuves des vérifications qu'il a effectuées en application du chapitre Ier du présent titre pendant trois ans.

## Section 2 : Sanctions

### Article R3143-2
- Identifiant : LEGIARTI000037661876
- État : en vigueur depuis le 01/01/2019
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000037661876
- Renvoie à : [art. L1241-1 du Code des transports](../../../../partie-legislative/premiere-partie/livre-ii/titre-iv/chapitre-ier.md#article-l1241-1) ; [art. L3143-4 du Code des transports](../../../../partie-legislative/troisieme-partie/livre-ier/titre-iv/chapitre-iii.md#article-l3143-4) ; [art. R3141-1 du Code des transports](chapitre-ier.md#article-r3141-1) ; [art. R3141-6 du Code des transports](chapitre-ier.md#article-r3141-6)

Hors le cas prévu par l'article L. 3143-4, est puni de l'amende prévue pour les contraventions de la cinquième classe, pour chaque mise en relation assurée en méconnaissance de ces obligations, le fait, pour le professionnel mentionné à l'article L. 3141-1, de contrevenir aux obligations prévues aux articles R. 3141-1 à R. 3141-4 et R. 3141-6.

### Article R3143-3
- Identifiant : LEGIARTI000037661874
- État : en vigueur depuis le 01/01/2019
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000037661874
- Renvoie à : [art. L3141-1 du Code des transports](../../../../partie-legislative/troisieme-partie/livre-ier/titre-iv/chapitre-ier.md#article-l3141-1) ; [art. R3141-5 du Code des transports](chapitre-ier.md#article-r3141-5)

Est puni de l'amende prévue pour les contraventions de la troisième classe, pour chaque mise en relation assurée en méconnaissance de cette obligation, le fait, pour le professionnel mentionné à l'article L. 3141-1, de contrevenir à l'obligation prévue à l'article R. 3141-5.

### Article R3143-4
- Identifiant : LEGIARTI000037661872
- État : en vigueur depuis le 01/01/2019
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000037661872
- Renvoie à : [art. L3141-1 du Code des transports](../../../../partie-legislative/troisieme-partie/livre-ier/titre-iv/chapitre-ier.md#article-l3141-1) ; [art. R3143-1 du Code des transports](chapitre-iii.md#article-r3143-1)

Est puni de l'amende prévue pour les contraventions de la quatrième classe, pour chaque conducteur ou pour chaque exploitant mis en relation avec des passagers en méconnaissance de cette obligation, le fait pour le professionnel mentionné à l'article L. 3141-1 de ne pas produire les preuves requises par l'article R. 3143-1.
