# Chapitre Ier : Durée du travail, travail de nuit et repos des salariés des entreprises de transport

Code des transports › PARTIE RÉGLEMENTAIRE › PREMIÈRE PARTIE : DISPOSITIONS COMMUNES › LIVRE III : RÉGLEMENTATION SOCIALE DU TRANSPORT › TITRE II : DISPOSITIONS PARTICULIÈRES AUX ENTREPRISES DE TRANSPORT

## Section 1 : Travail de nuit du personnel roulant ou navigant

### Article R1321-1
- Identifiant : LEGIARTI000028996670
- État : en vigueur depuis le 28/05/2014
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000028996670
- Renvoie à : [art. L1321-8 du Code des transports](../../../../partie-legislative/premiere-partie/livre-iii/titre-ii/chapitre-ier.md#article-l1321-8)

En l'absence de convention ou d'accord collectif étendu définissant la période de référence mentionnée à l'article L. 1321-8, cette période est de deux semaines, sauf pour le personnel roulant des entreprises exploitant les places couchées dans les trains pour lequel cette période est de quatre semaines.

## Section 2 : Dispositions pénales

### Article R1321-2
- Identifiant : LEGIARTI000033467045
- État : en vigueur depuis le 01/01/2017
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000033467045
- Renvoie à : [art. L1321-6 du Code des transports](../../../../partie-legislative/premiere-partie/livre-iii/titre-ii/chapitre-ier.md#article-l1321-6) ; [art. L1321-8 du Code des transports](../../../../partie-legislative/premiere-partie/livre-iii/titre-ii/chapitre-ier.md#article-l1321-8) ; [art. L3312-1 du Code des transports](../../../../partie-legislative/troisieme-partie/livre-iii/titre-unique/chapitre-ii.md#article-l3312-1) ; [art. 132-11 du Code pénal](../../../../../code-penal/partie-legislative/livre-ier/titre-iii/chapitre-ii.md#article-132-11) ; [art. 132-15 du Code pénal](../../../../../code-penal/partie-legislative/livre-ier/titre-iii/chapitre-ii.md#article-132-15)

Sont punies de l'amende prévue pour les contraventions de la cinquième classe les infractions aux dispositions relatives au travail de nuit prévues par l'article L. 1321-8.  

L'amende est prononcée autant de fois qu'il y a de salariés concernés par l'infraction.  

La récidive de la contravention prévue au présent article est réprimée conformément aux articles 132-11 et 132-15 du code pénal.
