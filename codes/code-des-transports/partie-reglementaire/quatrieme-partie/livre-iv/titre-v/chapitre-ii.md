# Chapitre II : Contrats de sous-traitance

### Article D4452-1
- Identifiant : LEGIARTI000027233979
- État : en vigueur depuis le 28/03/2013
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000027233979
- Renvoie à : [art. L4451-1 du Code des transports](../../../../partie-legislative/quatrieme-partie/livre-iv/titre-v/chapitre-ier.md#article-l4451-1) ; [art. L4452-1 du Code des transports](../../../../partie-legislative/quatrieme-partie/livre-iv/titre-v/chapitre-ii.md#article-l4452-1)
- Cité par : [art. Annexe à l'article D4452-2 du Code des transports](../annexes-au-livre-iv.md#article-annexe-à-larticle-d4452-2) ; [art. D4452-2 du Code des transports](chapitre-ii.md#article-d4452-2)

Le contrat ayant pour objet de sous-traiter un transport fluvial de marchandises, dit " contrat de sous-traitance ", mentionné à l'article L. 4452-1, prend obligatoirement la forme d'un des contrats de transport mentionnés à l'article L. 4451-1.

### Article D4452-2
- Identifiant : LEGIARTI000027233981
- État : en vigueur depuis le 28/03/2013
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000027233981
