# TITRE II : BIBLIOTHÈQUES MUNICIPALES ET INTERCOMMUNALES

Code du patrimoine › Partie réglementaire › LIVRE III : BIBLIOTHÈQUES

### Article D320-1
- Identifiant : LEGIARTI000041687901
- État : en vigueur depuis le 06/03/2020
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000041687901
- Renvoie à : [art. L320-1 du Code du patrimoine](../../partie-legislative/livre-iii/titre-ii.md#article-l320-1)
- Cité par : [art. D1421-5 du Code général des collectivités territoriales](../../../code-general-des-collectivites-territoriales/partie-reglementaire/premiere-partie/livre-iv/titre-ii/chapitre-ier.md#article-d1421-5)

En application de l'article L. 320-1, les bibliothèques municipales et intercommunales classées sont :

1° Les bibliothèques municipales dont le siège est situé dans les communes suivantes :

-Aix-en-Provence, Angers, Avignon ;

-Besançon, Bordeaux, Boulogne-sur-Mer, Bourges, Brest ;

-Carpentras, Châlons-en-Champagne, Chalon-sur-Saône, Chambéry, Colmar, Compiègne ;

-Dijon, Douai ;

-Grenoble ;

-Le Havre, Le Mans, Lille, Limoges, Lyon ;

-Marseille, Metz, Mulhouse ;

-Nancy, Nantes, Nice, Nîmes ;

-Orléans ;

-Périgueux ;

-Reims, Roubaix, Rouen ;

-Saint-Etienne ;

-Toulouse, Tours ;

-Valenciennes, Versailles ;

2° Les bibliothèques intercommunales dont le siège est situé dans les communes suivantes :

-Albi, Amiens, Autun ;

-Caen, Cambrai, Clermont-Ferrand ;

-Dole ;

-La Rochelle ;

-Montpellier, Moulins ;

-Pau, Poitiers ;

-Rennes ;

-Troyes ;

-Valence.
