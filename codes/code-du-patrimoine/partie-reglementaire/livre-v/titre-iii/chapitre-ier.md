## Section 1 : Autorisation de fouilles par l'Etat

### Article R531-1
- Identifiant : LEGIARTI000034023414
- État : en vigueur depuis le 11/02/2017
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000034023414

- Cité par : [art. R531-3 du Code du patrimoine](chapitre-ier.md#article-r531-3) ; [art. R545-17 du Code du patrimoine](../titre-iv/chapitre-v.md#article-r545-17) ; [art. R141-38-1 du Code forestier (nouveau)](../../../../code-forestier-nouveau/partie-reglementaire/livre-ier/titre-iv/chapitre-ier.md#article-r141-38-1) ; [art. R141-38-2 du Code forestier (nouveau)](../../../../code-forestier-nouveau/partie-reglementaire/livre-ier/titre-iv/chapitre-ier.md#article-r141-38-2) ; [art. R141-38-4 du Code forestier (nouveau)](../../../../code-forestier-nouveau/partie-reglementaire/livre-ier/titre-iv/chapitre-ier.md#article-r141-38-4)

Le préfet de région délivre les autorisations de fouilles ou de sondages prévues à l'article L. 531-1, dans un délai de deux mois suivant le dépôt de la demande.

Il recueille l'avis de la commission territoriale de la recherche archéologique.

### Article R531-2
- Identifiant : LEGIARTI000043775072
- État : en vigueur depuis le 10/07/2021
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000043775072
- Cité par : [art. R141-38-1 du Code forestier (nouveau)](../../../../code-forestier-nouveau/partie-reglementaire/livre-ier/titre-iv/chapitre-ier.md#article-r141-38-1) ; [art. R141-38-2 du Code forestier (nouveau)](../../../../code-forestier-nouveau/partie-reglementaire/livre-ier/titre-iv/chapitre-ier.md#article-r141-38-2) ; [art. R141-38-4 du Code forestier (nouveau)](../../../../code-forestier-nouveau/partie-reglementaire/livre-ier/titre-iv/chapitre-ier.md#article-r141-38-4)

Le préfet de région délivre les autorisations de sondages limitées à un mois. Il autorise les prospections systématiques ne comportant ni fouilles ni sondages ainsi que les programmes collectifs de recherche.

### Article R531-2-1
- Identifiant : LEGIARTI000036781093
- État : en vigueur depuis le 09/04/2018
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000036781093
- Renvoie à : [art. L141-1 du Code forestier (nouveau)](../../../../code-forestier-nouveau/partie-legislative/livre-ier/titre-iv/chapitre-ier.md#article-l141-1) ; [art. R141-38-2 du Code forestier (nouveau)](../../../../code-forestier-nouveau/partie-reglementaire/livre-ier/titre-iv/chapitre-ier.md#article-r141-38-2)

Lorsque les fouilles ou sondages se situent dans le périmètre d'une forêt de protection classée en application de l'article L. 141-1 du code forestier, la demande d'autorisation comporte les pièces mentionnées aux 1° à 5° de l'article R. 141-38-2 du même code.

### Article R531-3
- Identifiant : LEGIARTI000024241488
- État : en vigueur depuis le 27/05/2011
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000024241488
- Renvoie à : [art. R531-1 du Code du patrimoine](chapitre-ier.md#article-r531-1)

Les fouilles, sondages et prospections autorisés en application des articles R. 531-1 et R. 531-2 s'exécutent sous le contrôle du préfet de région dans le respect des prescriptions qui assortissent l'autorisation.

## Section 2 : Exécution de fouilles par l'Etat

### Article R531-5
- Identifiant : LEGIARTI000042006916
- État : en vigueur depuis le 18/06/2020
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000042006916
- Renvoie à : [art. L531-9 du Code du patrimoine](../../../partie-legislative/livre-v/titre-iii/chapitre-1er.md#article-l531-9)
- Cité par : [art. R141-38-1 du Code forestier (nouveau)](../../../../code-forestier-nouveau/partie-reglementaire/livre-ier/titre-iv/chapitre-ier.md#article-r141-38-1) ; [art. R141-38-2 du Code forestier (nouveau)](../../../../code-forestier-nouveau/partie-reglementaire/livre-ier/titre-iv/chapitre-ier.md#article-r141-38-2) ; [art. R141-38-4 du Code forestier (nouveau)](../../../../code-forestier-nouveau/partie-reglementaire/livre-ier/titre-iv/chapitre-ier.md#article-r141-38-4)

Les décisions d'exécution de fouilles ou de sondages prévues à l'article L. 531-9 sont prises par le préfet de région.

A défaut d'accord amiable avec le propriétaire du terrain, les fouilles sont déclarées d'utilité publique par décision du préfet de région, qui autorise l'occupation temporaire des terrains à moins que le ministre n'ait décidé d'évoquer le dossier. L'occupation temporaire est ordonnée par arrêté du préfet.

### Article R531-6
- Identifiant : LEGIARTI000024241497
- État : en vigueur depuis le 27/05/2011
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000024241497
- Renvoie à : [art. L531-10 du Code du patrimoine](../../../partie-legislative/livre-v/titre-iii/chapitre-1er.md#article-l531-10)

En application de l'article L. 531-10, l'autorité administrative compétente pour poursuivre le classement des terrains au titre des monuments historiques ou leur acquisition est le ministre chargé de la culture.

### Article R531-7
- Identifiant : LEGIARTI000024241500
- État : en vigueur depuis le 27/05/2011
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000024241500
- Renvoie à : [art. L531-13 du Code du patrimoine](../../../partie-legislative/livre-v/titre-iii/chapitre-1er.md#article-l531-13)

Lorsqu'il est fait application de l'article L. 531-13, le ministre chargé de la culture notifie au propriétaire d'un immeuble son intention d'en poursuivre l'expropriation.

Après la déclaration d'utilité publique, l'immeuble peut être classé au titre des monuments historiques sans formalité par arrêté du ministre chargé de la culture.

## Section 3 : Découvertes fortuites

### Article R531-8
- Identifiant : LEGIARTI000024241509
- État : en vigueur depuis le 27/05/2011
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000024241509
- Renvoie à : [art. L531-14 du Code du patrimoine](../../../partie-legislative/livre-v/titre-iii/chapitre-1er.md#article-l531-14)

En cas de découverte fortuite, le préfet de région doit être avisé, en application de l'article L. 531-14. Il peut faire visiter les lieux.

### Article R531-9
- Identifiant : LEGIARTI000024241514
- État : en vigueur depuis le 27/05/2011
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000024241514
- Renvoie à : [art. L531-15 du Code du patrimoine](../../../partie-legislative/livre-v/titre-iii/chapitre-1er.md#article-l531-15)

Le préfet de région peut, à titre provisoire, prononcer la suspension des recherches prévues à l'article L. 531-15 et prescrire toute mesure utile pour l'étude et la conservation des vestiges découverts.
