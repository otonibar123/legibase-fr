# Chapitre IV : Dispositions pénales

### Article R624-1
- Identifiant : LEGIARTI000024242344
- État : en vigueur depuis le 27/05/2011
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000024242344
- Renvoie à : [art. L621-16 du Code du patrimoine](../../../partie-legislative/livre-vi/titre-ii/chapitre-1er.md#article-l621-16) ; [art. 132-11 du Code pénal](../../../../code-penal/partie-legislative/livre-ier/titre-iii/chapitre-ii.md#article-132-11) ; [art. 132-15 du Code pénal](../../../../code-penal/partie-legislative/livre-ier/titre-iii/chapitre-ii.md#article-132-15)

Est puni de l'amende prévue pour les contraventions de cinquième classe le fait de ne pas afficher sur le terrain l'autorisation de travaux sur un immeuble classé, en méconnaissance de l'article R. 621-16.

La récidive de cette contravention est punie conformément aux dispositions des articles 132-11 et 132-15 du code pénal.

### Article R624-2
- Identifiant : LEGIARTI000024242346
- État : en vigueur depuis le 27/05/2011
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000024242346
- Renvoie à : [art. R621-86 du Code du patrimoine](chapitre-ier.md#article-r621-86)

Est puni de l'amende prévue pour les contraventions de cinquième classe le fait de procéder à un affichage non conforme à l'autorisation d'affichage accordée en application des articles R. 621-86, R. 621-87, R. 621-88, R. 621-89 et R. 621-90.
