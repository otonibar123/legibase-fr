# Chapitre Ier : Dispositions pénales

Code du patrimoine › Partie réglementaire › LIVRE VI : MONUMENTS HISTORIQUES, SITES PATRIMONIAUX REMARQUABLES ET QUALITÉ ARCHITECTURALE › TITRE IV : DISPOSITIONS PÉNALES ET SANCTIONS ADMINISTRATIVES

### Article R641-1
- Identifiant : LEGIARTI000034326747
- État : en vigueur depuis le 01/04/2017
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000034326747
- Renvoie à : [art. R621-98 du Code du patrimoine](../titre-ii/chapitre-ier.md#article-r621-98) ; [art. 132-11 du Code pénal](../../../../code-penal/partie-legislative/livre-ier/titre-iii/chapitre-ii.md#article-132-11) ; [art. 132-15 du Code pénal](../../../../code-penal/partie-legislative/livre-ier/titre-iii/chapitre-ii.md#article-132-15)

Le fait pour toute personne autre que l'Etat ou l'un de ses établissements publics, d'aliéner un immeuble situé dans le périmètre d'un domaine national sans la déclaration préalable prévue à l'article R. 621-98 est puni de l'amende prévue pour les contraventions de la cinquième classe.

La récidive de la contravention prévue au présent article est réprimée conformément aux articles 132-11 et 132-15 du code pénal.

### Article R641-2
- Identifiant : LEGIARTI000043854797
- État : en vigueur depuis le 26/07/2021
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000043854797
- Renvoie à : [art. L641-1 du Code du patrimoine](../../../partie-legislative/livre-vi/titre-iv/chapitre-1er.md#article-l641-1) ; [art. L641-3 du Code du patrimoine](../../../partie-legislative/livre-vi/titre-iv/chapitre-1er.md#article-l641-3)

L'autorité administrative compétente pour commissionner les agents publics, mentionnée aux 1° et 4° du II de l'article L. 641-1 et à l'article L. 641-3, est le préfet de région.
