# Chapitre 2 : Utilisation de détecteurs de métaux.

Code du patrimoine › Partie législative › LIVRE V : ARCHÉOLOGIE › TITRE IV : DISPOSITIONS DIVERSES

### Article L542-1
- Identifiant : LEGIARTI000006845775
- État : en vigueur depuis le 24/02/2004
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006845775
- Cité par : [art. L542-2 du Code du patrimoine](chapitre-2.md#article-l542-2) ; [art. L544-12 du Code du patrimoine](chapitre-4.md#article-l544-12) ; [art. L730-1 du Code du patrimoine](../../livre-vii/titre-iii.md#article-l730-1) ; [art. R542-1 du Code du patrimoine](../../../partie-reglementaire/livre-v/titre-iv/chapitre-ii.md#article-r542-1) ; [art. R544-3 du Code du patrimoine](../../../partie-reglementaire/livre-v/titre-iv/chapitre-iv.md#article-r544-3)

Nul ne peut utiliser du matériel permettant la détection d'objets métalliques, à l'effet de recherches de monuments et d'objets pouvant intéresser la préhistoire, l'histoire, l'art ou l'archéologie, sans avoir, au préalable, obtenu une autorisation administrative délivrée en fonction de la qualification du demandeur ainsi que de la nature et des modalités de la recherche.

### Article L542-2
- Identifiant : LEGIARTI000006845776
- État : en vigueur depuis le 24/02/2004
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006845776
- Renvoie à : [art. L542-1 du Code du patrimoine](chapitre-2.md#article-l542-1)
- Cité par : [art. R544-4 du Code du patrimoine](../../../partie-reglementaire/livre-v/titre-iv/chapitre-iv.md#article-r544-4)

Toute publicité ou notice d'utilisation concernant les détecteurs de métaux doit comporter le rappel de l'interdiction mentionnée à l'article L. 542-1, des sanctions pénales encourues ainsi que des motifs de cette réglementation.

### Article L542-3
- Identifiant : LEGIARTI000006845777
- État : en vigueur depuis le 24/02/2004
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006845777

Un décret en Conseil d'Etat fixe les conditions d'application du présent chapitre.
