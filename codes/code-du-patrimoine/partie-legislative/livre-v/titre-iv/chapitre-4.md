# Chapitre 4 : Dispositions pénales

Code du patrimoine › Partie législative › LIVRE V : ARCHÉOLOGIE › TITRE IV : DISPOSITIONS DIVERSES

## Section 1 : Dispositions relatives à l'archéologie terrestre et subaquatique.

### Article L544-1
- Identifiant : LEGIARTI000006845780
- État : en vigueur depuis le 24/02/2004
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006845780
- Renvoie à : [art. L531-1 du Code du patrimoine](../titre-iii/chapitre-1er.md#article-l531-1) ; [art. L531-6 du Code du patrimoine](../titre-iii/chapitre-1er.md#article-l531-6) ; [art. L531-15 du Code du patrimoine](../titre-iii/chapitre-1er.md#article-l531-15)
- Cité par : [art. L331-18 du Code de l'environnement](../../../../code-de-l-environnement/partie-legislative/livre-iii/titre-iii/chapitre-ier.md#article-l331-18) ; [art. L730-1 du Code du patrimoine](../../livre-vii/titre-iii.md#article-l730-1)

Est puni d'une amende de 7 500 euros le fait, pour toute personne, de réaliser, sur un terrain lui appartenant ou appartenant à autrui, des fouilles ou des sondages à l'effet de recherches de monument ou d'objet pouvant intéresser la préhistoire, l'histoire, l'art ou l'archéologie :  

a) Sans avoir obtenu l'autorisation prévue aux articles L. 531-1 ou L. 531-15 ;  

b) Sans se conformer aux prescriptions de cette autorisation ;  

c) Malgré le retrait de l'autorisation de fouille en application des dispositions de l'article L. 531-6.

### Article L544-2
- Identifiant : LEGIARTI000006845781
- État : en vigueur depuis le 24/02/2004
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006845781
- Renvoie à : [art. L531-3 du Code du patrimoine](../titre-iii/chapitre-1er.md#article-l531-3)

Est puni d'une amende de 7 500 Euros le fait, pour toute personne ayant demandé et obtenu l'autorisation de réaliser des fouilles ou des sondages, de ne pas les réaliser elle-même en violation de l'article L. 531-3 ou d'enfreindre l'obligation de déclaration et de conservation prévue à ce même article.

### Article L544-3
- Identifiant : LEGIARTI000006845782
- État : en vigueur depuis le 24/02/2004
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006845782
- Renvoie à : [art. L531-14 du Code du patrimoine](../titre-iii/chapitre-1er.md#article-l531-14)

Le fait, pour toute personne, d'enfreindre l'obligation de déclaration prévue à l'article L. 531-14 ou de faire une fausse déclaration est puni d'une amende de 3 750 euros.

### Article L544-4
- Identifiant : LEGIARTI000006845783
- État : en vigueur depuis le 24/02/2004
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006845783
- Renvoie à : [art. L531-1 du Code du patrimoine](../titre-iii/chapitre-1er.md#article-l531-1) ; [art. L531-3 du Code du patrimoine](../titre-iii/chapitre-1er.md#article-l531-3) ; [art. L531-6 du Code du patrimoine](../titre-iii/chapitre-1er.md#article-l531-6) ; [art. L531-14 du Code du patrimoine](../titre-iii/chapitre-1er.md#article-l531-14) ; [art. L531-15 du Code du patrimoine](../titre-iii/chapitre-1er.md#article-l531-15) ; [art. 131-35 du Code pénal](../../../../code-penal/partie-legislative/livre-ier/titre-iii/chapitre-ier.md#article-131-35)

Le fait, pour toute personne, d'aliéner ou d'acquérir tout objet découvert en violation des articles L. 531-1, L. 531-6 et L. 531-15 ou dissimulé en violation des articles L. 531-3 et L. 531-14 est puni d'un emprisonnement de deux ans et d'une amende de 4 500 euros. Le montant de l'amende peut être porté au double du prix de la vente du bien.  

La juridiction peut, en outre, ordonner la diffusion de sa décision dans les conditions prévues par l'article 131-35 du code pénal.

### Article L544-4-1
- Identifiant : LEGIARTI000032857674
- État : en vigueur depuis le 09/07/2016
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000032857674
- Renvoie à : [art. L541-6 du Code du patrimoine](chapitre-1er.md#article-l541-6)

Est puni de 3 750 € d'amende le fait, pour toute personne, d'aliéner un bien archéologique mobilier ou de diviser ou aliéner par lot ou pièce un ensemble de biens archéologiques mobiliers reconnu comme cohérent sur le plan scientifique sans avoir préalablement établi la déclaration mentionnée à l'article L. 541-6.

## Section 2 : Dispositions relatives aux biens culturels maritimes.

### Article L544-5
- Identifiant : LEGIARTI000006845784
- État : en vigueur depuis le 24/02/2004
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006845784
- Renvoie à : [art. L532-3 du Code du patrimoine](../titre-iii/chapitre-2.md#article-l532-3) ; [art. L532-4 du Code du patrimoine](../titre-iii/chapitre-2.md#article-l532-4)
- Cité par : [art. L331-19 du Code de l'environnement](../../../../code-de-l-environnement/partie-legislative/livre-iii/titre-iii/chapitre-ier.md#article-l331-19) ; [art. L332-22 du Code de l'environnement](../../../../code-de-l-environnement/partie-legislative/livre-iii/titre-iii/chapitre-ii.md#article-l332-22) ; [art. L334-2-1 du Code de l'environnement](../../../../code-de-l-environnement/partie-legislative/livre-iii/titre-iii/chapitre-iv.md#article-l334-2-1) ; [art. L740-3 du Code du patrimoine](../../livre-vii/titre-iv.md#article-l740-3) ; [art. L750-2 du Code du patrimoine](../../livre-vii/titre-v.md#article-l750-2) ; [art. L760-4 du Code du patrimoine](../../livre-vii/titre-vi.md#article-l760-4) ; [art. L770-1 du Code du patrimoine](../../livre-vii/titre-vii.md#article-l770-1)

Le fait, pour toute personne, d'enfreindre les obligations de déclaration prévues au deuxième alinéa de l'article L. 532-3 ou à l'article L. 532-4 est puni d'une amende de 3 750 euros.  

Est puni de la même peine le fait, pour toute personne, d'avoir fait auprès de l'autorité publique une fausse déclaration quant au lieu et à la composition du gisement sur lequel l'objet déclaré a été découvert.

### Article L544-6
- Identifiant : LEGIARTI000006845785
- État : en vigueur depuis le 24/02/2004
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006845785
- Renvoie à : [art. L532-3 du Code du patrimoine](../titre-iii/chapitre-2.md#article-l532-3) ; [art. L532-7 du Code du patrimoine](../titre-iii/chapitre-2.md#article-l532-7)

Le fait, pour toute personne, d'avoir fait des prospections, des sondages, des prélèvements ou des fouilles sur des biens culturels maritimes ou d'avoir procédé à un déplacement de ces biens ou à un prélèvement sur ceux-ci en infraction aux dispositions du premier alinéa de l'article L. 532-3 ou des articles L. 532-7 et L. 532-8 est puni d'une amende de 7 500 euros.

### Article L544-7
- Identifiant : LEGIARTI000006845786
- État : en vigueur depuis le 24/02/2004
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006845786
- Renvoie à : [art. L532-3 du Code du patrimoine](../titre-iii/chapitre-2.md#article-l532-3) ; [art. L532-7 du Code du patrimoine](../titre-iii/chapitre-2.md#article-l532-7) ; [art. 131-35 du Code pénal](../../../../code-penal/partie-legislative/livre-ier/titre-iii/chapitre-ier.md#article-131-35)

Le fait, pour toute personne, d'aliéner ou d'acquérir un bien culturel maritime enlevé du domaine public maritime ou du fond de la mer dans la zone contiguë en infraction aux dispositions des articles L. 532-3, L. 532-4, L. 532-7 et L. 532-8 est puni d'un emprisonnement de deux ans et d'une amende de 4 500 euros. Le montant de l'amende peut être porté au double du prix de la vente du bien.  

La juridiction peut, en outre, ordonner la diffusion de sa décision dans les conditions prévues par l'article 131-35 du code pénal.

### Article L544-8
- Identifiant : LEGIARTI000027474162
- État : en vigueur depuis le 30/05/2013
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000027474162
- Cité par : [art. L544-9 du Code du patrimoine](chapitre-4.md#article-l544-9) ; [art. R544-1 du Code du patrimoine](../../../partie-reglementaire/livre-v/titre-iv/chapitre-iv.md#article-r544-1)

Les infractions mentionnées à la présente section sont recherchées et constatées par les officiers et agents de police judiciaire, les agents de police judiciaire adjoints, les administrateurs des affaires maritimes, les fonctionnaires affectés dans les services exerçant des missions de contrôle dans le domaine des affaires maritimes sous l'autorité ou à la disposition du ministre chargé de la mer, les officiers du corps technique et administratif des affaires maritimes, les agents des douanes, les agents du ministre chargé de la culture spécialement assermentés et commissionnés à cet effet dans des conditions fixées par décret en Conseil d'Etat, les commandants, commandants en second ou officiers en second des bâtiments de la marine nationale, les guetteurs sémaphoriques et, en outre, dans les ports, les officiers de port et les officiers de port adjoints.

### Article L544-9
- Identifiant : LEGIARTI000006845788
- État : en vigueur depuis le 24/02/2004
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006845788
- Renvoie à : [art. L544-8 du Code du patrimoine](chapitre-4.md#article-l544-8)

Les procès-verbaux dressés par les agents verbalisateurs désignés à l'article L. 544-8 font foi jusqu'à preuve contraire. Ils sont transmis sans délai au procureur de la République.

### Article L544-11
- Identifiant : LEGIARTI000006845791
- État : en vigueur depuis le 24/02/2004
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006845791

## Section 3 : Dispositions communes.

### Article L544-12
- Identifiant : LEGIARTI000006845792
- État : en vigueur depuis le 24/02/2004
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006845792
- Renvoie à : [art. L542-1 du Code du patrimoine](chapitre-2.md#article-l542-1) ; [art. L114-4 du Code du patrimoine](https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006845490)
- Cité par : [art. L544-13 du Code du patrimoine](chapitre-4.md#article-l544-13)

Toute infraction aux dispositions des articles L. 542-1 et L. 542-2 et des textes pris pour leur application est constatée par les officiers, agents de police judiciaire et agents de police judiciaire adjoints, ainsi que par les fonctionnaires, agents et gardiens mentionnés à l'article L. 114-4.

### Article L544-13
- Identifiant : LEGIARTI000006845793
- État : en vigueur depuis le 24/02/2004
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006845793
- Renvoie à : [art. L544-12 du Code du patrimoine](chapitre-4.md#article-l544-12)

Les procès-verbaux dressés par les diverses personnes désignées à l'article L. 544-12 font foi jusqu'à preuve contraire et sont remis ou envoyés sans délai au procureur de la République près le tribunal dans le ressort duquel l'infraction a été commise.
