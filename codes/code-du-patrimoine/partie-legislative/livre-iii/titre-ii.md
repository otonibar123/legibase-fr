# TITRE II : BIBLIOTHÈQUES MUNICIPALES ET INTERCOMMUNALES

Code du patrimoine › Partie législative › LIVRE III : BIBLIOTHÈQUES

### Article L320-1
- Identifiant : LEGIARTI000034505649
- État : en vigueur depuis le 29/04/2017
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000034505649
- Cité par : [art. R133-1 du Code de la propriété intellectuelle](../../../code-de-la-propriete-intellectuelle/partie-reglementaire/livre-ier/titre-iii/chapitre-iii.md#article-r133-1) ; [art. D320-1 du Code du patrimoine](../../partie-reglementaire/livre-iii/titre-ii.md#article-d320-1) ; [art. L310-2 du Code du patrimoine](titre-ier.md#article-l310-2) ; [art. L320-2 du Code du patrimoine](titre-ii.md#article-l320-2) ; [art. L730-1 du Code du patrimoine](../livre-vii/titre-iii.md#article-l730-1) ; [art. L1421-5 du Code général des collectivités territoriales](../../../code-general-des-collectivites-territoriales/partie-legislative/premiere-partie/livre-iv/titre-ii/chapitre-ier.md#article-l1421-5)

Les bibliothèques municipales et intercommunales classées, dont la liste est fixée par décret après consultation des communes ou des groupements de communes intéressés, peuvent bénéficier de la mise à disposition de conservateurs généraux et de conservateurs des bibliothèques qui ont la qualité de fonctionnaires de l'Etat.

### Article L320-2
- Identifiant : LEGIARTI000051772174
- État : en vigueur depuis le 01/03/2022
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000051772174
- Renvoie à : [art. L320-1 du Code du patrimoine](titre-ii.md#article-l320-1) ; [art. L512-11 du Code général de la fonction publique](../../../code-general-de-la-fonction-publique/partie-legislative/livre-v/titre-ier/chapitre-ii.md#article-l512-11)

Par dérogation à l'article L. 512-11 du code général de la fonction publique, la mise à disposition des personnels mentionnés à l'article L. 320-1 auprès des communes ou des groupements de communes n'est pas soumise à l'obligation de remboursement.

### Article L320-3
- Identifiant : LEGIARTI000044542334
- État : en vigueur depuis le 23/12/2021
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000044542334

L'accès aux bibliothèques municipales et intercommunales est libre.

### Article L320-4
- Identifiant : LEGIARTI000044542337
- État : en vigueur depuis le 23/12/2021
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000044542337

L'accès aux bibliothèques municipales et intercommunales et la consultation sur place de leurs collections sont gratuits
