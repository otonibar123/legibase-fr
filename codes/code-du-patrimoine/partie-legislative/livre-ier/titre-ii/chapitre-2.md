# Chapitre 2 : Dispositions fiscales

Code du patrimoine › Partie législative › LIVRE Ier : DISPOSITIONS COMMUNES À L'ENSEMBLE DU PATRIMOINE CULTUREL › TITRE II : ACQUISITION DE BIENS CULTURELS

## Section 1 : Dation en paiement.

### Article L122-1
- Identifiant : LEGIARTI000006845498
- État : en vigueur depuis le 24/02/2004
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006845498
- Renvoie à : [art. 1716 bis du Code général des impôts](../../../../code-general-des-impots/livre-ii/chapitre-premier.md#article-1716-bis)
- Cité par : [art. L480-1 du Code de l'urbanisme](../../../../code-de-l-urbanisme/partie-legislative/livre-iv/titre-viii/chapitre-preliminaire.md#article-l480-1) ; [art. L720-1 du Code du patrimoine](../../livre-vii/titre-ii.md#article-l720-1)

Les règles relatives au paiement des droits de mutation à titre gratuit ou du droit de partage par la remise d'œuvres d'art, de livres ou d'objets de collection, de documents de haute valeur artistique ou historique sont fixées à l'article 1716 bis du code général des impôts.

## Section 2 : Donation.

### Article L122-2
- Identifiant : LEGIARTI000006845499
- État : en vigueur depuis le 24/02/2004
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006845499
- Renvoie à : [art. 794 du Code général des impôts](../../../../code-general-des-impots/livre-premier/premiere-partie/titre-iv/chapitre-premier.md#article-794) ; [art. 795 du Code général des impôts](../../../../code-general-des-impots/livre-premier/premiere-partie/titre-iv/chapitre-premier.md#article-795)

Les règles fiscales applicables aux dons et legs d'œuvres d'art, de monuments ou d'objets ayant un caractère historique, de livres, d'imprimés ou de manuscrits, destinés à figurer dans une collection publique et consentis aux établissements pourvus de la personnalité morale, autres que ceux mentionnés au I de l'article 794 du code général des impôts, sont fixées au 1° de l'article 795 du code général des impôts.

### Article L122-3
- Identifiant : LEGIARTI000006845500
- État : en vigueur depuis le 24/02/2004
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006845500
- Renvoie à : [art. 1131 du Code général des impôts](../../../../code-general-des-impots/livre-premier/premiere-partie/titre-iv/chapitre-iv.md#article-1131)

Les règles fiscales applicables à un don consenti à l'Etat par l'acquéreur, le donataire, l'héritier ou le légataire d'une œuvre d'art, de livres, d'objets de collection ou de documents de haute valeur artistique ou historique sont fixées à l'article 1131 du code général des impôts.

## Section 3 : Mécénat.

### Article L122-8
- Identifiant : LEGIARTI000006845506
