# Chapitre III : Dispositions particulières aux départements du Bas-Rhin, du Haut-Rhin et de la Moselle

Code de l'organisation judiciaire › Partie législative › LIVRE III : JURIDICTIONS DU SECOND DEGRÉ › TITRE Ier : LA COUR D'APPEL

### Article L313-1
- Identifiant : LEGIARTI000006572192
- État : en vigueur depuis le 09/06/2006
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006572192
- Cité par : [art. L4261-3 du Code des transports](../../../../code-des-transports/partie-legislative/quatrieme-partie/livre-ii/titre-vi/chapitre-ier.md#article-l4261-3) ; [art. L4261-4 du Code des transports](../../../../code-des-transports/partie-legislative/quatrieme-partie/livre-ii/titre-vi/chapitre-ier.md#article-l4261-4)

Une cour d'appel spécialement désignée exerce les fonctions de tribunal d'appel pour la navigation du Rhin et connaît des recours contre les décisions du tribunal pour la navigation du Rhin.

### Article L313-2
- Identifiant : LEGIARTI000006572193
- État : en vigueur depuis le 09/06/2006
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006572193
- Cité par : [art. L4262-3 du Code des transports](../../../../code-des-transports/partie-legislative/quatrieme-partie/livre-ii/titre-vi/chapitre-ii.md#article-l4262-3) ; [art. L4262-4 du Code des transports](../../../../code-des-transports/partie-legislative/quatrieme-partie/livre-ii/titre-vi/chapitre-ii.md#article-l4262-4)

Une cour d'appel spécialement désignée exerce les fonctions de tribunal d'appel pour la navigation de la Moselle et connaît des recours contre les décisions du tribunal de première instance pour la navigation de la Moselle.
