# Chapitre III : Le greffe

Code de l'organisation judiciaire › Partie législative › LIVRE Ier : DISPOSITIONS COMMUNES AUX JURIDICTIONS JUDICIAIRES › TITRE II : RÈGLES GÉNÉRALES D'ORGANISATION ET DE FONCTIONNEMENT

### Article L123-1
- Identifiant : LEGIARTI000053223948
- État : en vigueur depuis le 01/01/2026
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000053223948
- Cité par : [art. R1423-36 du Code du travail](../../../../code-du-travail/partie-reglementaire/premiere-partie/livre-iv/titre-ii/chapitre-iii.md#article-r1423-36) ; [art. R1423-37 du Code du travail](../../../../code-du-travail/partie-reglementaire/premiere-partie/livre-iv/titre-ii/chapitre-iii.md#article-r1423-37) ; [art. R1423-38 du Code du travail](../../../../code-du-travail/partie-reglementaire/premiere-partie/livre-iv/titre-ii/chapitre-iii.md#article-r1423-38) ; [Décret n°2025-1356 du 26 décembre 2025](https://www.legifrance.gouv.fr/loda/id/LEGITEXT000053198243)

La Cour de cassation, les cours d'appel, les tribunaux judiciaires et les conseils de prud'hommes comprennent un greffe composé de fonctionnaires de l'Etat.

> Nota : Conformément à l'article 9 du décret n° 2025-1356 du 26 décembre 2025, ces dispositions, dans leur rédaction résultant du décret précité, entrent en vigueur le 1er janvier 2026.

### Article L123-2
- Identifiant : LEGIARTI000006572079
- État : en vigueur depuis le 09/06/2006
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006572079
- Renvoie à : [art. L261-1 du Code de l'organisation judiciaire](../../livre-ii/titre-vi/chapitre-unique.md#article-l261-1)
- Cité par : [Décret n°2025-1356 du 26 décembre 2025](https://www.legifrance.gouv.fr/loda/id/LEGITEXT000053198243)

Les dispositions particulières applicables au greffe des autres juridictions sont fixées par les textes sur l'organisation et le fonctionnement de ces juridictions, mentionnés à l'article L. 261-1.

### Article L123-3
- Identifiant : LEGIARTI000033423986
- État : en vigueur depuis le 20/11/2016
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000033423986
- Cité par : [art. R15-33-66-8 du Code de procédure pénale](../../../../code-de-procedure-penale/partie-reglementaire-decrets-en-conseil-d-etat/livre-ier/titre-ier/chapitre-ii.md#article-r15-33-66-8) ; [art. R1423-50-1 du Code du travail](../../../../code-du-travail/partie-reglementaire/premiere-partie/livre-iv/titre-ii/chapitre-iii.md#article-r1423-50-1) ; [Arrêté du 31 janvier 2025, art. 3](https://www.legifrance.gouv.fr/loda/article_lc/LEGIARTI000051135279) ; [Décret n°2026-188 du 18 mars 2026](https://www.legifrance.gouv.fr/loda/id/LEGITEXT000053701712)

Il est institué un service d'accueil unique du justiciable dont la compétence s'étend au delà de celle de la juridiction où il est implanté. Le service informe les personnes sur les procédures qui les concernent et reçoit de leur part des actes afférents à ces procédures.
