# Chapitre IV : La cour d'assises des mineurs

Code de l'organisation judiciaire › Partie législative › LIVRE II : JURIDICTIONS DU PREMIER DEGRÉ › TITRE V : LES JURIDICTIONS DES MINEURS

### Article L254-1
- Identifiant : LEGIARTI000045081615
- État : en vigueur depuis le 30/09/2021
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000045081615
- Renvoie à : art. 706-17 du Code de procédure pénale ; [Ordonnance n°45-174 du 2 février 1945](https://www.legifrance.gouv.fr/loda/id/JORFTEXT000000517521)

Les règles concernant la compétence, l'organisation et le fonctionnement de la cour d'assises des mineurs sont fixées par le code de la justice pénale des mineurs et, en matière de terrorisme, par l'article 706-17 du code de procédure pénale.
