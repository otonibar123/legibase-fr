# Titre IX bis : Des conventions relatives à l'exercice des droits indivis : articles rattachés directement

Code civil › Livre III : Des différentes manières dont on acquiert la propriété › Titre IX bis : Des conventions relatives à l'exercice des droits indivis

### Article 1873-1
- Identifiant : LEGIARTI000006444494
- État : en vigueur depuis le 01/07/1977
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006444494
- Cité par : [art. 515-5-3 du Code civil](../../livre-ier/titre-xiii/chapitre-ier.md#article-515-5-3) ; [art. 815-1 du Code civil](../titre-ier/chapitre-vii.md#article-815-1) ; [art. L613-30 du Code de la propriété intellectuelle](https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006279516) ; [art. L214-162-14 du Code monétaire et financier](https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000049872482)

Ceux qui ont des droits à exercer sur des biens indivis, à titre de propriétaires, de nus-propriétaires ou d'usufruitiers peuvent passer des conventions relatives à l'exercice de ces droits.
