# Titre X : Du prêt : articles rattachés directement

Code civil › Livre III : Des différentes manières dont on acquiert la propriété › Titre X : Du prêt

### Article 1874
- Identifiant : LEGIARTI000020616175
- État : en vigueur depuis le 14/05/2009
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000020616175

Il y a deux sortes de prêt :

Celui des choses dont on peut user sans les détruire ;

Et celui des choses qui se consomment par l'usage qu'on en fait.

La première espèce s'appelle " prêt à usage ".

La deuxième s'appelle " prêt de consommation ", ou simplement " prêt ".
