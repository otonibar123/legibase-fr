# Chapitre III : Les actions ouvertes au créancier

Code civil › Livre III : Des différentes manières dont on acquiert la propriété › Titre IV : Du régime général des obligations

### Article 1341
- Identifiant : LEGIARTI000032042185
- État : en vigueur depuis le 01/10/2016
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000032042185
- Cité par : [art. 1343 du Code civil](chapitre-iv.md#article-1343) ; [art. 1344 du Code civil](chapitre-iv.md#article-1344) ; [art. 1345 du Code civil](chapitre-iv.md#article-1345) ; [art. 1924 du Code civil](../titre-xi/chapitre-ii.md#article-1924) ; [art. 1950 du Code civil](../titre-xi/chapitre-ii.md#article-1950)

Le créancier a droit à l'exécution de l'obligation ; il peut y contraindre le débiteur dans les conditions prévues par la loi.

### Article 1341-1
- Identifiant : LEGIARTI000032035225
- État : en vigueur depuis le 01/10/2016
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000032035225
- Cité par : [art. L666-3 du Code rural (nouveau)](../../../code-rural-nouveau/partie-legislative/livre-vi/titre-vi/chapitre-vi.md#article-l666-3)

Lorsque la carence du débiteur dans l'exercice de ses droits et actions à caractère patrimonial compromet les droits de son créancier, celui-ci peut les exercer pour le compte de son débiteur, à l'exception de ceux qui sont exclusivement rattachés à sa personne.

### Article 1341-2
- Identifiant : LEGIARTI000032035227
- État : en vigueur depuis le 01/10/2016
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000032035227
- Cité par : [art. 794 du Code civil](../titre-ier/chapitre-iv.md#article-794) ; [art. 1397 du Code civil](../titre-v/chapitre-ier.md#article-1397) ; [art. 1578 du Code civil](../titre-v/chapitre-iv.md#article-1578) ; [art. L223-15 du Code de la mutualité](../../../code-de-la-mutualite/partie-legislative/livre-ii/titre-ii/chapitre-iii.md#article-l223-15) ; [art. L132-14 du Code des assurances](../../../code-des-assurances/partie-legislative/livre-ier/titre-iii/chapitre-ii.md#article-l132-14)

Le créancier peut aussi agir en son nom personnel pour faire déclarer inopposables à son égard les actes faits par son débiteur en fraude de ses droits, à charge d'établir, s'il s'agit d'un acte à titre onéreux, que le tiers cocontractant avait connaissance de la fraude.

### Article 1341-3
- Identifiant : LEGIARTI000032035229
- État : en vigueur depuis le 01/10/2016
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000032035229

Dans les cas déterminés par la loi, le créancier peut agir directement en paiement de sa créance contre un débiteur de son débiteur.
