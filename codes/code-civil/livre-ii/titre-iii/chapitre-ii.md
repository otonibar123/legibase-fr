# Chapitre II : De l'usage et de l'habitation

Code civil › Livre II : Des biens et des différentes modifications de la propriété › Titre III : De l'usufruit, de l'usage et de l'habitation

### Article 625
- Identifiant : LEGIARTI000006429693
- État : en vigueur depuis le 21/03/1804
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006429693
- Cité par : [Décret n°2020-1186 du 29 septembre 2020, art. 4](https://www.legifrance.gouv.fr/loda/article_lc/LEGIARTI000042377932)

Les droits d'usage et d'habitation s'établissent et se perdent de la même manière que l'usufruit.

### Article 626
- Identifiant : LEGIARTI000006429703
- État : en vigueur depuis le 21/03/1804
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006429703

On ne peut en jouir, comme dans le cas de l'usufruit, sans donner préalablement caution et sans faire des états et inventaires.

### Article 627
- Identifiant : LEGIARTI000029336838
- État : en vigueur depuis le 06/08/2014
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000029336838
- Cité par : [art. 764 du Code civil](../../livre-iii/titre-ier/chapitre-iii.md#article-764)

L'usager, et celui qui a un droit d'habitation, doivent jouir raisonnablement.

### Article 628
- Identifiant : LEGIARTI000006429720
- État : en vigueur depuis le 21/03/1804
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006429720

Les droits d'usage et d'habitation se règlent par le titre qui les a établis et reçoivent, d'après ses dispositions, plus ou moins d'étendue.

### Article 629
- Identifiant : LEGIARTI000006429729
- État : en vigueur depuis le 21/03/1804
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006429729
- Renvoie à : [art. 630 du Code civil](chapitre-ii.md#article-630) ; [art. 631 du Code civil](chapitre-ii.md#article-631) ; [art. 632 du Code civil](chapitre-ii.md#article-632) ; [art. 633 du Code civil](chapitre-ii.md#article-633) ; [art. 634 du Code civil](chapitre-ii.md#article-634) ; [art. 635 du Code civil](chapitre-ii.md#article-635)

Si le titre ne s'explique pas sur l'étendue de ces droits ils sont réglés ainsi qu'il suit.

### Article 630
- Identifiant : LEGIARTI000006429738
- État : en vigueur depuis le 21/03/1804
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006429738
- Cité par : [art. 629 du Code civil](chapitre-ii.md#article-629)

Celui qui a l'usage des fruits d'un fonds ne peut en exiger qu'autant qu'il lui en faut pour ses besoins et ceux de sa famille.  

Il peut en exiger pour les besoins même des enfants qui lui sont survenus depuis la concession de l'usage.

### Article 631
- Identifiant : LEGIARTI000006429748
- État : en vigueur depuis le 21/03/1804
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006429748
- Cité par : [art. 629 du Code civil](chapitre-ii.md#article-629) ; [art. 764 du Code civil](../../livre-iii/titre-ier/chapitre-iii.md#article-764)

L'usager ne peut céder ni louer son droit à un autre.

### Article 632
- Identifiant : LEGIARTI000006429757
- État : en vigueur depuis le 21/03/1804
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006429757
- Cité par : [art. 629 du Code civil](chapitre-ii.md#article-629)

Celui qui a un droit d'habitation dans une maison peut y demeurer avec sa famille, quand même il n'aurait pas été marié à l'époque où ce droit lui a été donné.

### Article 633
- Identifiant : LEGIARTI000006429766
- État : en vigueur depuis le 21/03/1804
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006429766
- Cité par : [art. 629 du Code civil](chapitre-ii.md#article-629)

Le droit d'habitation se restreint à ce qui est nécessaire pour l'habitation de celui à qui ce droit est concédé et de sa famille.

### Article 634
- Identifiant : LEGIARTI000006429773
- État : en vigueur depuis le 21/03/1804
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006429773
- Cité par : [art. 629 du Code civil](chapitre-ii.md#article-629) ; [art. 764 du Code civil](../../livre-iii/titre-ier/chapitre-iii.md#article-764)

Le droit d'habitation ne peut être ni cédé ni loué.

### Article 635
- Identifiant : LEGIARTI000006429783
- État : en vigueur depuis le 21/03/1804
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006429783
- Cité par : [art. 629 du Code civil](chapitre-ii.md#article-629) ; [art. 764 du Code civil](../../livre-iii/titre-ier/chapitre-iii.md#article-764)

Si l'usager absorbe tous les fruits du fonds ou s'il occupe la totalité de la maison, il est assujetti aux frais de culture, aux réparations d'entretien et au paiement des contributions, comme l'usufruitier.  

S'il ne prend qu'une partie des fruits ou s'il n'occupe qu'une partie de la maison, il contribue au prorata de ce dont il jouit.

### Article 636
- Identifiant : LEGIARTI000006429793
- État : en vigueur depuis le 21/03/1804
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006429793

L'usage des bois et forêts est réglé par des lois particulières.
