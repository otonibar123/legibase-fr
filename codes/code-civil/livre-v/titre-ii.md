# Titre II : Dispositions relatives au livre II

Code civil › Livre V : Dispositions applicables à Mayotte

### Article 2500
- Identifiant : LEGIARTI000030253977
- État : en vigueur depuis le 18/02/2015
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000030253977
- Renvoie à : [art. 515-14 du Code civil](../livre-ii/articles-directs.md#article-515-14) ; [art. 642 du Code civil](../livre-ii/titre-iv/chapitre-ier.md#article-642) ; [art. 643 du Code civil](../livre-ii/titre-iv/chapitre-ier.md#article-643) ; [art. 2501 du Code civil](titre-ii.md#article-2501) ; [art. 2502 du Code civil](titre-ii.md#article-2502)

Les articles 515-14 à 710, à l'exception des articles 642 et 643, sont applicables à Mayotte sous réserve des adaptations prévues aux articles 2501 et 2502.

Les dispositions intéressant les immeubles ne s'appliquent que sous réserve des dispositions du titre IV du présent livre.

### Article 2501
- Identifiant : LEGIARTI000030253962
- État : en vigueur depuis le 18/02/2015
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000030253962
- Renvoie à : [art. 524 du Code civil](../livre-ii/titre-ier/chapitre-ier.md#article-524)
- Cité par : [art. 2500 du Code civil](titre-ii.md#article-2500)

Pour l'application de l'article 524, sont soumis au régime des immeubles par destination, quand ils ont été placés par le propriétaire pour le service et l'exploitation du fonds, les poissons des plans d'eau n'ayant aucune communication avec les cours d'eau, canaux et ruisseaux et les poissons des piscicultures et enclos piscicoles.

### Article 2502
- Identifiant : LEGIARTI000006450645
- État : en vigueur depuis le 24/03/2006
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006450645
- Renvoie à : [art. 564 du Code civil](../livre-ii/titre-ii/chapitre-ii.md#article-564)
- Cité par : [art. 2500 du Code civil](titre-ii.md#article-2500)

Pour l'application de l'article 564, les mots : " ou plan d'eau visé aux articles 432 et 433 du code rural " sont remplacés par les mots : " pisciculture ou enclos piscicoles ".
