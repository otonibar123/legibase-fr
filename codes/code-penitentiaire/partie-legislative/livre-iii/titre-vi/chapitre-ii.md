# Chapitre II : INSCRIPTION SUR LES LISTES ÉLECTORALES

Code pénitentiaire › PARTIE LÉGISLATIVE › Livre III : DROITS ET OBLIGATIONS DES PERSONNES DÉTENUES › Titre VI : EXERCICE DU DROIT DE VOTE

### Article L362-1
- Identifiant : LEGIARTI000045479992
- État : en vigueur depuis le 01/05/2022
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000045479992
- Renvoie à : [art. L312-2 du Code pénitentiaire](../titre-ier/chapitre-ii.md#article-l312-2)

Conformément aux dispositions de l'article L. 312-2, les personnes détenues qui ne disposent pas d'un domicile personnel peuvent élire domicile auprès de l'établissement pénitentiaire pour l'exercice de leurs droits civiques.

### Article L362-2
- Identifiant : LEGIARTI000045479990
- État : en vigueur depuis le 01/05/2022
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000045479990
- Renvoie à : [art. L12-1 du Code électoral](../../../../code-electoral/partie-legislative/livre-ier/titre-ier/chapitre-ii.md#article-l12-1)

Les personnes détenues sont inscrites sur la liste électorale de la commune déterminée selon les dispositions de l'article L. 12-1 du code électoral.

### Article L362-3
- Identifiant : LEGIARTI000045479988
- État : en vigueur depuis le 01/05/2022
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000045479988
- Renvoie à : [art. L18-1 du Code électoral](../../../../code-electoral/partie-legislative/livre-ier/titre-ier/chapitre-ii.md#article-l18-1)

La demande d'inscription sur la liste électorale formée par une personne détenue est transmise au maire de la commune par le chef de l'établissement pénitentiaire, dans les conditions prévues par les dispositions de l'article L. 18-1 du code électoral.
