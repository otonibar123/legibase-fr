# Chapitre Ier : DISPOSITIONS GÉNÉRALES

### Article L111-1
- Identifiant : LEGIARTI000045480612
- État : en vigueur depuis le 01/05/2022
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000045480612
- Cité par : [art. L111-2 du Code pénitentiaire](chapitre-ier.md#article-l111-2) ; [art. L762-2 du Code pénitentiaire](../../livre-vii/titre-vi/chapitre-ii.md#article-l762-2) ; [art. L772-2 du Code pénitentiaire](../../livre-vii/titre-vii/chapitre-ii.md#article-l772-2) ; [art. L772-3 du Code pénitentiaire](../../livre-vii/titre-vii/chapitre-ii.md#article-l772-3)

Le service public pénitentiaire est assuré par l'administration pénitentiaire sous l'autorité du garde des sceaux, ministre de la justice, avec le concours des autres services de l'Etat, des collectivités territoriales, des associations et d'autres personnes publiques ou privées.  
Chacune de ces autorités et de ces personnes veille, en ce qui la concerne, à ce que les personnes condamnées accèdent aux droits et dispositifs de droit commun de nature à faciliter leur insertion ou leur réinsertion.

### Article L111-2
- Identifiant : LEGIARTI000045480610
- État : en vigueur depuis le 01/05/2022
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000045480610
- Renvoie à : [art. L111-1 du Code pénitentiaire](chapitre-ier.md#article-l111-1)
- Cité par : [art. L752-2 du Code pénitentiaire](../../livre-vii/titre-v/chapitre-ii.md#article-l752-2) ; [art. L762-2 du Code pénitentiaire](../../livre-vii/titre-vi/chapitre-ii.md#article-l762-2) ; [art. L772-2 du Code pénitentiaire](../../livre-vii/titre-vii/chapitre-ii.md#article-l772-2) ; [art. L772-3 du Code pénitentiaire](../../livre-vii/titre-vii/chapitre-ii.md#article-l772-3)

Des conventions entre l'administration pénitentiaire et les autres services de l'Etat, les collectivités territoriales, les associations et d'autres personnes publiques ou privées définissent les conditions et modalités d'accès, pendant leur détention, des personnes condamnées aux droits et dispositifs mentionnés par les dispositions de l'article L. 111-1.  
Ces conventions comportent des objectifs précis, définis en fonction de la finalité d'intérêt général mentionnée au même article, ainsi que des résultats attendus, et faisant l'objet d'une évaluation régulière.

### Article L111-3
- Identifiant : LEGIARTI000045480608
- État : en vigueur depuis le 01/05/2022
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000045480608
- Renvoie à : [art. L2171-4 du Code de la commande publique](../../../../code-de-la-commande-publique/partie-legislative/deuxieme-partie/livre-ier/titre-vii/chapitre-ier.md#article-l2171-4)
- Cité par : [art. 318 E du Code général des impôts, annexe II](../../../../code-general-des-impots-annexe-ii/livre-premier/deuxieme-partie/titre-iii-bis/chapitre-unique.md#article-318-e) ; [art. L120-1 du Code pénitentiaire](../titre-ii/articles-directs.md#article-l120-1) ; [art. R112-9 du Code pénitentiaire](../../../partie-reglementaire/livre-ier/titre-ier/chapitre-ii.md#article-r112-9)

Les fonctions de direction, de surveillance et de greffe des établissements pénitentiaires sont assurées par l'administration pénitentiaire. Les autres fonctions peuvent être confiées à des personnes de droit public ou privé bénéficiant d'une habilitation dans des conditions définies par décret en Conseil d'Etat.  
Ces personnes peuvent être choisies dans le cadre d'un marché public prévu par les dispositions du 3° de l'article L. 2171-4 du code de la commande publique.
