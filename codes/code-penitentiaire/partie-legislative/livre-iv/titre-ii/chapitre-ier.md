# Chapitre Ier : DISPOSITIONS GÉNÉRALES

Code pénitentiaire › PARTIE LÉGISLATIVE › Livre IV : AIDE À LA RÉINSERTION DES PERSONNES DÉTENUES › Titre II : PRÉPARATION DE LA SORTIE DE DÉTENTION

### Article L421-2
- Identifiant : LEGIARTI000051873047
- État : en vigueur depuis le 11/07/2025
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000051873047
- Cité par : [art. L755-1 du Code pénitentiaire](../../livre-vii/titre-v/chapitre-v.md#article-l755-1) ; [art. L765-1 du Code pénitentiaire](../../livre-vii/titre-vi/chapitre-v.md#article-l765-1) ; [art. L775-1 du Code pénitentiaire](../../livre-vii/titre-vii/chapitre-v.md#article-l775-1)

Lorsque la personne a été condamnée pour un des délits prévus au chapitre I er ter du titre II du livre II du code pénal, le service pénitentiaire d'insertion et de probation met en place des actions visant à prévenir la récidive des violences routières et, le cas échéant, des actions visant à prévenir la consommation de stupéfiants ou de substances psychotropes.
