### Article L754-2
- Identifiant : LEGIARTI000045479517
- État : en vigueur depuis le 01/05/2022
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000045479517
- Renvoie à : [art. L6141-5 du Code de la santé publique](../../../../code-de-la-sante-publique/partie-legislative/sixieme-partie/livre-ier/titre-iv/chapitre-ier.md#article-l6141-5) ; [art. L322-3 du Code pénitentiaire](../../livre-iii/titre-ii/chapitre-ii.md#article-l322-3)

Pour son application dans les îles Wallis et Futuna, à l'article L. 322-3, les mots : " dans le respect des conditions prévues par les dispositions de l'article L. 6141-5 du code de la santé publique " sont supprimés.
