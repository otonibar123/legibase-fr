# Chapitre III : DISPOSITIONS PARTICULIÈRES À MAYOTTE

Code pénitentiaire › PARTIE LÉGISLATIVE › Livre VII : DISPOSITIONS RELATIVES À L'OUTRE-MER › Titre Ier : DISPOSITIONS PARTICULIÈRES AUX COLLECTIVITÉS RÉGIES PAR L'ARTICLE 73 DE LA CONSTITUTION

### Article L713-1
- Identifiant : LEGIARTI000045479657
- État : en vigueur depuis le 01/05/2022
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000045479657
- Renvoie à : [art. L216-1 du Code pénitentiaire](../../livre-ii/titre-ier/chapitre-vi.md#article-l216-1)

Pour son application à Mayotte, l'article L. 216-1 est ainsi rédigé :

" Art. L. 216-1.-La contrainte judiciaire est exécutée dans un établissement pénitentiaire. "

### Article L713-3
- Identifiant : LEGIARTI000046451387
- État : en vigueur depuis le 01/12/2024
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000046451387
- Renvoie à : [art. L5524-3 du Code du travail](../../../../code-du-travail/partie-legislative/cinquieme-partie/livre-v/titre-ii/chapitre-iv.md#article-l5524-3) ; [art. L324-12 du Code pénitentiaire](../../livre-iii/titre-ii/chapitre-iv.md#article-l324-12)

Pour son application à Mayotte, l'article L. 324-12 est ainsi rédigé :  

“ Art. 324-12.-Les mesures d'application de la section 3 sont définies par l'accord mentionné à l'article L. 5524-3 du code du travail, qui peut prévoir des aménagements pour les personnes ayant exercé une activité de travail dans le cadre d'un contrat d'emploi pénitentiaire. ”

> Nota : Conformément à l’article 27 de l’ordonnance n° 2022-1336 du 19 octobre 2022, ces dispositions entrent en vigueur à une date fixée par décret, et au plus tard le 1er décembre 2024.
