### Article L764-2
- Identifiant : LEGIARTI000045479469
- État : en vigueur depuis le 01/05/2022
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000045479469
- Renvoie à : [art. L115-4 du Code pénitentiaire](../../livre-ier/titre-ier/chapitre-v.md#article-l115-4) ; [art. L320-1 du Code pénitentiaire](../../livre-iii/titre-ii/articles-directs.md#article-l320-1) ; [art. L322-1 du Code pénitentiaire](../../livre-iii/titre-ii/chapitre-ii.md#article-l322-1)
- Cité par : [art. R762-3 du Code pénitentiaire](../../../partie-reglementaire/livre-vii/titre-vi/chapitre-ii.md#article-r762-3) ; [art. R762-4 du Code pénitentiaire](../../../partie-reglementaire/livre-vii/titre-vi/chapitre-ii.md#article-r762-4) ; [art. R763-2 du Code pénitentiaire](../../../partie-reglementaire/livre-vii/titre-vi/chapitre-iii.md#article-r763-2)

L'Etat peut conclure avec les autorités compétentes de la Polynésie française une convention afin de définir les modalités d'application des articles L. 115-4, L. 320-1 et L. 322-1.

### Article L764-3
- Identifiant : LEGIARTI000045479467
- État : en vigueur depuis le 01/05/2022
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000045479467
- Renvoie à : [art. L6141-5 du Code de la santé publique](../../../../code-de-la-sante-publique/partie-legislative/sixieme-partie/livre-ier/titre-iv/chapitre-ier.md#article-l6141-5) ; [art. L322-3 du Code pénitentiaire](../../livre-iii/titre-ii/chapitre-ii.md#article-l322-3)

Pour son application en Polynésie française, à l'article L. 322-3, les mots : " dans le respect des conditions prévues par les dispositions de l'article L. 6141-5 du code de la santé publique " sont supprimés.

### Article L764-4
- Identifiant : LEGIARTI000045479465
- État : en vigueur depuis le 01/05/2022
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000045479465
- Renvoie à : [art. L1110-11 du Code de la santé publique](../../../../code-de-la-sante-publique/partie-legislative/premiere-partie/livre-ier/titre-ier/chapitre-preliminaire.md#article-l1110-11) ; [art. L322-12 du Code pénitentiaire](../../livre-iii/titre-ii/chapitre-ii.md#article-l322-12)

Pour son application en Polynésie française, au 1° de l'article L. 322-12, les mots : ", en application des dispositions de l'article L. 1110-11 du code de la santé publique " sont supprimés.
