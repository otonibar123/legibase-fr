# Chapitre IV : DISPOSITIONS SPÉCIFIQUES RELATIVES AU LIVRE III

Code pénitentiaire › PARTIE LÉGISLATIVE › Livre VII : DISPOSITIONS RELATIVES À L'OUTRE-MER › Titre VII : DISPOSITIONS APPLICABLES EN NOUVELLE-CALÉDONIE

### Article L774-1
- Identifiant : LEGIARTI000051749856
- État : en vigueur depuis le 15/06/2025
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000051749856
- Renvoie à : [art. L311-1 du Code pénitentiaire](../../livre-iii/titre-ier/chapitre-ier.md#article-l311-1) ; [art. L381-1 du Code pénitentiaire](../../livre-iii/titre-viii/chapitre-ier.md#article-l381-1)

Sous réserve des adaptations prévues par le présent chapitre, les dispositions suivantes sont applicables en Nouvelle-Calédonie dans leur rédaction résultant de l'ordonnance n° 2022-478 du 30 mars 2022 sauf mention contraire dans le tableau ci-dessous :

| Articles applicables
| Dans leur rédaction résultant de

| L. 311-1 à L. 313-3
|

| L. 315-1
| la loi n° 2025-532 du 13 juin 2025 visant à sortir la France du piège du narcotrafic

| L. 315-2 à L. 322-13
|

| L. 331-1 à L. 381-1
|

### Article L774-2
- Identifiant : LEGIARTI000045479415
- État : en vigueur depuis le 01/05/2022
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000045479415
- Renvoie à : [art. L115-4 du Code pénitentiaire](../../livre-ier/titre-ier/chapitre-v.md#article-l115-4) ; [art. L320-1 du Code pénitentiaire](../../livre-iii/titre-ii/articles-directs.md#article-l320-1) ; [art. L322-1 du Code pénitentiaire](../../livre-iii/titre-ii/chapitre-ii.md#article-l322-1)
- Cité par : [art. R772-3 du Code pénitentiaire](../../../partie-reglementaire/livre-vii/titre-vii/chapitre-ii.md#article-r772-3) ; [art. R772-4 du Code pénitentiaire](../../../partie-reglementaire/livre-vii/titre-vii/chapitre-ii.md#article-r772-4) ; [art. R773-2 du Code pénitentiaire](../../../partie-reglementaire/livre-vii/titre-vii/chapitre-iii.md#article-r773-2)

L'Etat peut conclure avec les autorités compétentes de la Nouvelle-Calédonie une convention afin de définir les modalités d'application des articles L. 115-4, L. 320-1 et L. 322-1.

### Article L774-3
- Identifiant : LEGIARTI000045479413
- État : en vigueur depuis le 01/05/2022
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000045479413
- Renvoie à : [art. L6141-5 du Code de la santé publique](../../../../code-de-la-sante-publique/partie-legislative/sixieme-partie/livre-ier/titre-iv/chapitre-ier.md#article-l6141-5) ; [art. L322-3 du Code pénitentiaire](../../livre-iii/titre-ii/chapitre-ii.md#article-l322-3)

Pour son application en Nouvelle-Calédonie, à l'article L. 322-3, les mots : " dans le respect des conditions prévues par les dispositions de l'article L. 6141-5 du code de la santé publique " sont supprimés.

### Article L774-4
- Identifiant : LEGIARTI000045479411
- État : en vigueur depuis le 01/05/2022
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000045479411
- Renvoie à : [art. L1110-11 du Code de la santé publique](../../../../code-de-la-sante-publique/partie-legislative/premiere-partie/livre-ier/titre-ier/chapitre-preliminaire.md#article-l1110-11) ; [art. L322-12 du Code pénitentiaire](../../livre-iii/titre-ii/chapitre-ii.md#article-l322-12)

Pour son application en Nouvelle-Calédonie, au 1° de l'article L. 322-12, les mots : ", en application des dispositions de l'article L. 1110-11 du code de la santé publique " sont supprimés.
