# Chapitre Ier : DISPOSITIONS GÉNÉRALES

Code pénitentiaire › PARTIE RÉGLEMENTAIRE › Livre II : DÉTENTION EN ÉTABLISSEMENT PÉNITENTIAIRE › Titre III : RÉGIME DISCIPLINAIRE DES PERSONNES DÉTENUES

### Article R231-1
- Identifiant : LEGIARTI000045493204
- État : en vigueur depuis le 01/05/2022
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000045493204
- Renvoie à : [art. R112-22 du Code pénitentiaire](../../livre-ier/titre-ier/chapitre-ii.md#article-r112-22) ; [art. L212-4 du Code pénitentiaire](https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000045478333)
- Cité par : [art. R112-22 du Code pénitentiaire](../../livre-ier/titre-ier/chapitre-ii.md#article-r112-22)

Les personnes détenues doivent obéir aux fonctionnaires ou agents ayant autorité dans l'établissement pénitentiaire en tout ce qu'ils leur prescrivent pour l'exécution des dispositions législatives ou réglementaires, du règlement intérieur défini aux articles L. 112-4 et R. 112-22, ou de toute autre instruction de service.

### Article R231-2
- Identifiant : LEGIARTI000045493202
- État : en vigueur depuis le 01/05/2022
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000045493202
- Renvoie à : [art. L112-4 du Code pénitentiaire](../../../partie-legislative/livre-ier/titre-ier/chapitre-ii.md#article-l112-4) ; [art. R112-22 du Code pénitentiaire](../../livre-ier/titre-ier/chapitre-ii.md#article-r112-22)
- Cité par : [art. R112-22 du Code pénitentiaire](../../livre-ier/titre-ier/chapitre-ii.md#article-r112-22)

Les dispositions du règlement intérieur, défini aux articles L. 112-4 et R. 112-22, relatives à la discipline, ainsi que le tableau des avocats inscrits dans les barreaux du département sont affichées dans le quartier disciplinaire.

### Article D231-3
- Identifiant : LEGIARTI000045493200
- État : en vigueur depuis le 01/05/2022
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000045493200

Aucun moyen de contrainte ne doit être employé à titre de sanction disciplinaire.
