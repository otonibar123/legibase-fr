# Chapitre Ier : DISPOSITIONS COMMUNES

## Section 1 : Obligation d'exercer au moins une activité

### Article R411-1
- Identifiant : LEGIARTI000045492351
- État : en vigueur depuis le 01/05/2022
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000045492351
- Renvoie à : [art. L411-1 du Code pénitentiaire](../../../partie-legislative/livre-iv/titre-ier/chapitre-ier.md#article-l411-1)
- Cité par : [art. R411-2 du Code pénitentiaire](chapitre-ier.md#article-r411-2) ; [art. R755-1 du Code pénitentiaire](../../livre-vii/titre-v/chapitre-v.md#article-r755-1) ; [art. R765-1 du Code pénitentiaire](../../livre-vii/titre-vi/chapitre-v.md#article-r765-1) ; [art. R775-1 du Code pénitentiaire](../../livre-vii/titre-vii/chapitre-v.md#article-r775-1)

Une personne détenue condamnée remplit l'obligation prévue par les dispositions de l'article L. 411-1 lorsqu'elle exerce au moins l'une des activités relevant de l'un des domaines suivants : travail, formation professionnelle, insertion par l'activité économique, enseignement, activités éducatives, culturelles, socioculturelles, sportives et physiques.

## Section 2 : Consultation des personnes détenues

### Article R411-2
- Identifiant : LEGIARTI000045492347
- État : en vigueur depuis le 01/05/2022
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000045492347
- Renvoie à : [art. R411-1 du Code pénitentiaire](chapitre-ier.md#article-r411-1)

Les personnes détenues sont consultées au moins deux fois par an sur les activités proposées en application de l'article R. 411-1.

### Article R411-3
- Identifiant : LEGIARTI000045492345
- État : en vigueur depuis le 01/05/2022
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000045492345
- Cité par : [art. R745-1 du Code pénitentiaire](../../livre-vii/titre-iv/chapitre-v.md#article-r745-1)

Sont associés à ces consultations les membres du personnel pénitentiaire dont le directeur du service pénitentiaire d'insertion et de probation, et, le cas échéant, toute personne extérieure sur invitation du chef de l'établissement pénitentiaire.

### Article R411-4
- Identifiant : LEGIARTI000045492343
- État : en vigueur depuis le 01/05/2022
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000045492343

Le chef de l'établissement pénitentiaire informe les personnes détenues et les membres du personnel pénitentiaire des résultats des consultations et des décisions prises pour l'organisation des activités.

### Article R411-5
- Identifiant : LEGIARTI000045492341
- État : en vigueur depuis le 01/05/2022
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000045492341
- Renvoie à : [art. D136-2 du Code pénitentiaire](../../livre-ier/titre-iii/chapitre-vi.md#article-d136-2)

Le chef de l'établissement pénitentiaire communique chaque année au conseil d'évaluation mentionné par les dispositions de l'article D. 136-2 un rapport sur l'organisation et les résultats de ces consultations

### Article R411-6
- Identifiant : LEGIARTI000045492339
- État : en vigueur depuis le 01/05/2022
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000045492339
- Renvoie à : [art. L112-4 du Code pénitentiaire](../../../partie-legislative/livre-ier/titre-ier/chapitre-ii.md#article-l112-4) ; [art. R112-22 du Code pénitentiaire](../../livre-ier/titre-ier/chapitre-ii.md#article-r112-22)

Les modalités des consultations sont définies par le chef de l'établissement pénitentiaire dans le règlement intérieur de l'établissement, défini aux articles L. 112-4 et R. 112-22.

## Section 3 : Déroulement des activités

### Article R411-7
- Identifiant : LEGIARTI000045492335
- État : en vigueur depuis le 01/05/2022
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000045492335
- Cité par : [art. R112-22 du Code pénitentiaire](../../livre-ier/titre-ier/chapitre-ii.md#article-r112-22)

Aucune personne détenue ne peut occuper un emploi comportant autorité sur d'autres personnes détenues. Cette interdiction ne fait pas obstacle à ce que certaines responsabilités soient confiées à une personne détenue dans le cadre d'activités dirigées, sous le contrôle effectif du personnel de l'administration pénitentiaire.

### Article R411-8
- Identifiant : LEGIARTI000045492333
- État : en vigueur depuis le 01/05/2022
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000045492333
- Cité par : [art. R112-22 du Code pénitentiaire](../../livre-ier/titre-ier/chapitre-ii.md#article-r112-22) ; [art. R755-1 du Code pénitentiaire](../../livre-vii/titre-v/chapitre-v.md#article-r755-1) ; [art. R765-1 du Code pénitentiaire](../../livre-vii/titre-vi/chapitre-v.md#article-r765-1) ; [art. R775-1 du Code pénitentiaire](../../livre-vii/titre-vii/chapitre-v.md#article-r775-1)

Sous le contrôle d'un personnel pénitentiaire, les personnes détenues peuvent participer à des activités collectives ou à des jeux excluant toute idée de gain.
