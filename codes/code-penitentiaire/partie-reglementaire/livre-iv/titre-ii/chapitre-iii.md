# Chapitre III : DÉCISIONS RELATIVES AUX AMÉNAGEMENTS DE PEINE

Code pénitentiaire › PARTIE RÉGLEMENTAIRE › Livre IV : AIDE À LA RÉINSERTION DES PERSONNES DÉTENUES › Titre II : PRÉPARATION DE LA SORTIE DE DÉTENTION

## Section 1 : Audiences sur les aménagements de peine

### Article D423-1
- Identifiant : LEGIARTI000045492151
- État : en vigueur depuis le 01/05/2022
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000045492151
- Renvoie à : [art. D49-15 du Code de procédure pénale](../../../../code-de-procedure-penale/partie-reglementaire-decrets-simples/livre-v/titre-ier/chapitre-iii.md#article-d49-15)

Le greffe de l'établissement pénitentiaire informe la personne condamnée de la date du débat contradictoire dans le délai prévu par les dispositions de l'article D. 49-15 du code de procédure pénale.

### Article D423-2
- Identifiant : LEGIARTI000045492149
- État : en vigueur depuis le 01/05/2022
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000045492149
- Renvoie à : [art. D49-17 du Code de procédure pénale](../../../../code-de-procedure-penale/partie-reglementaire-decrets-simples/livre-v/titre-ier/chapitre-iii.md#article-d49-17)

Conformément aux dispositions de l'article D. 49-17 du code de procédure pénale, lors des débats contradictoires devant le juge de l'application des peines ou le tribunal de l'application des peines, le représentant de l'administration pénitentiaire peut être invité à développer oralement son avis, à la demande du juge ou du président du tribunal.

### Article D423-3
- Identifiant : LEGIARTI000045492147
- État : en vigueur depuis le 01/05/2022
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000045492147
- Renvoie à : [art. D49-29 du Code de procédure pénale](../../../../code-de-procedure-penale/partie-reglementaire-decrets-simples/livre-v/titre-ier/chapitre-iii.md#article-d49-29) ; [art. 712-6 du Code de procédure pénale](https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006577885) ; [art. 712-7 du Code de procédure pénale](https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006577886)

Conformément aux dispositions de l'article D. 49-29 du code de procédure pénale, l'avis du représentant de l'administration pénitentiaire lors des débats contradictoires prévus par les dispositions des articles 712-6 et 712-7 du même code est versé au dossier sous forme d'un rapport de synthèse des avis des différents services pénitentiaires compétents.

## Section 2 : Avis de la commission de l'application des peines

### Article D423-4
- Identifiant : LEGIARTI000045492143
- État : en vigueur depuis le 01/05/2022
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000045492143
- Renvoie à : [art. D49-28 du Code de procédure pénale](../../../../code-de-procedure-penale/partie-reglementaire-decrets-simples/livre-v/titre-ier/chapitre-iii.md#article-d49-28)
- Cité par : [Arrêté du 23 juillet 2026](https://www.legifrance.gouv.fr/loda/id/LEGITEXT000054586988)

Au sein de la commission de l'application des peines, les personnels de l'administration pénitentiaire apportent leur contribution et, le cas échéant, expriment leur vote dans les conditions et selon les modalités prévues par les dispositions de l'article D. 49-28 du code de procédure pénale.  
Conformément aux mêmes dispositions, le chef de l'établissement pénitentiaire peut être représenté au sein de la commission par un membre du personnel de direction.

## Section 3 : Notification des décisions

### Article D423-5
- Identifiant : LEGIARTI000045492139
- État : en vigueur depuis le 01/05/2022
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000045492139
- Renvoie à : [art. D49-18 du Code de procédure pénale](../../../../code-de-procedure-penale/partie-reglementaire-decrets-simples/livre-v/titre-ier/chapitre-iii.md#article-d49-18)

Conformément aux dispositions de l'article D. 49-18 du code de procédure pénale, si la décision de la juridiction de l'application des peines a été mise en délibéré, le jugement est notifié à la personne condamnée par le chef de l'établissement pénitentiaire qui lui en remet une copie contre émargement.

### Article D423-6
- Identifiant : LEGIARTI000045492137
- État : en vigueur depuis le 01/05/2022
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000045492137
- Renvoie à : [art. D49-21 du Code de procédure pénale](../../../../code-de-procedure-penale/partie-reglementaire-decrets-simples/livre-v/titre-ier/chapitre-iii.md#article-d49-21) ; [art. 712-5 du Code de procédure pénale](https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006577884) ; [art. 712-8 du Code de procédure pénale](https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006577888)

Conformément aux dispositions de l'article D. 49-21 du code de procédure pénale, les ordonnances prévues par les dispositions des articles 712-5 et 712-8 du même code sont notifiées à la personne détenue par le chef de l'établissement pénitentiaire qui lui en remet une copie contre émargement.

### Article D423-7
- Identifiant : LEGIARTI000045492135
- État : en vigueur depuis le 01/05/2022
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000045492135
- Renvoie à : [art. D49-44 du Code de procédure pénale](../../../../code-de-procedure-penale/partie-reglementaire-decrets-simples/livre-v/titre-ier/chapitre-iii.md#article-d49-44)

Conformément aux dispositions de l'article D. 49-44 du code de procédure pénale, les arrêts de la chambre de l'application des peines de la cour d'appel sont notifiés à la personne détenue par le chef de l'établissement pénitentiaire qui lui en remet une copie contre émargement.
