# Chapitre Ier : DISPOSITIONS GÉNÉRALES

Code pénitentiaire › PARTIE RÉGLEMENTAIRE › Livre VII : DISPOSITIONS RELATIVES À L'OUTRE-MER › Titre III : DISPOSITIONS APPLICABLES À SAINT-MARTIN

### Article R731-1
- Identifiant : LEGIARTI000045491451
- État : en vigueur depuis le 01/05/2022
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000045491451

Les dispositions du présent code sont applicables de plein droit à Saint-Martin, sous réserve des adaptations prévues au présent titre.

### Article R731-2
- Identifiant : LEGIARTI000045491449
- État : en vigueur depuis le 01/05/2022
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000045491449

Pour l'application des dispositions du présent code à Saint-Martin, les références au préfet de département sont remplacées par les références au représentant de l'Etat dans la collectivité.
