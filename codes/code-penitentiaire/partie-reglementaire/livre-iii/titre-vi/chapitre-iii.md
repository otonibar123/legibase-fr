# Chapitre III : MODALITÉS DU VOTE

Code pénitentiaire › PARTIE RÉGLEMENTAIRE › Livre III : DROITS ET OBLIGATIONS DES PERSONNES DÉTENUES › Titre VI : EXERCICE DU DROIT DE VOTE

## Section 1 : Accès au vote

### Article D363-1
- Identifiant : LEGIARTI000045492395
- État : en vigueur depuis le 01/05/2022
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000045492395
- Renvoie à : [art. D143-4 du Code de procédure pénale](../../../../code-de-procedure-penale/partie-reglementaire-decrets-simples/livre-v/titre-ii/chapitre-ii.md#article-d143-4)
- Cité par : [art. D754-6 du Code pénitentiaire](../../livre-vii/titre-v/chapitre-iv.md#article-d754-6) ; [art. D764-14 du Code pénitentiaire](../../livre-vii/titre-vi/chapitre-iv.md#article-d764-14) ; [art. D774-14 du Code pénitentiaire](../../livre-vii/titre-vii/chapitre-iv.md#article-d774-14)

Conformément aux dispositions de l'article D. 143-4 du code de procédure pénale, les personnes condamnées peuvent bénéficier d'une permission de sortir pour exercer leur droit de vote.

## Section 2 : Organisation du scrutin

### Article R363-2
- Identifiant : LEGIARTI000045492391
- État : en vigueur depuis le 01/05/2022
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000045492391
- Renvoie à : [art. R81 du Code électoral](../../../../code-electoral/partie-reglementaire/livre-ier/titre-ier/chapitre-vi.md#article-r81)

Le chef de l'établissement pénitentiaire est destinataire des listes des personnes détenues admises à voter par correspondance, dans les conditions prévues par les dispositions de l'article R. 81 du code électoral.

### Article R363-3
- Identifiant : LEGIARTI000045492389
- État : en vigueur depuis le 01/05/2022
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000045492389
- Renvoie à : [art. R82 du Code électoral](../../../../code-electoral/partie-reglementaire/livre-ier/titre-ier/chapitre-vi.md#article-r82)

Le chef de l'établissement pénitentiaire réceptionne les documents nécessaires à l'exercice du droit de vote par correspondance, dans les conditions prévues par les dispositions de l'article R. 82 du code électoral.

### Article R363-4
- Identifiant : LEGIARTI000045492387
- État : en vigueur depuis le 01/05/2022
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000045492387
- Renvoie à : [art. R83 du Code électoral](../../../../code-electoral/partie-reglementaire/livre-ier/titre-ier/chapitre-vi.md#article-r83)

Les opérations de vote par correspondance des personnes détenues sont organisées au sein de chaque établissement pénitentiaire avant le scrutin, dans le délai et selon les modalités prévus par les dispositions de l'article R. 83 du code électoral.

### Article R363-5
- Identifiant : LEGIARTI000045492385
- État : en vigueur depuis le 01/05/2022
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000045492385
- Renvoie à : [art. R84 du Code électoral](../../../../code-electoral/partie-reglementaire/livre-ier/titre-ier/chapitre-vi.md#article-r84)

Dans les conditions prévues à l'article R. 84 du code électoral, le chef de l'établissement pénitentiaire conserve les documents mentionnés à cet article et les remet, le jour du scrutin, au président du bureau de vote.
