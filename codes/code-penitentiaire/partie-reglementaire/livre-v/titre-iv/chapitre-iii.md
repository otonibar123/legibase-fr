# Chapitre III : CONTRÔLE DU RESPECT DES MESURES DE SURVEILLANCE JUDICIAIRE ET DE SURVEILLANCE DE SÛRETÉ

Code pénitentiaire › PARTIE RÉGLEMENTAIRE › Livre V : LIBÉRATION DES PERSONNES DÉTENUES › Titre IV : MESURES DE SURVEILLANCE DES PERSONNES LIBÉRÉES

### Article R543-1
- Identifiant : LEGIARTI000045491924
- État : en vigueur depuis le 01/05/2022
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000045491924
- Renvoie à : [art. R53-8-49 du Code de procédure pénale](../../../../code-de-procedure-penale/partie-reglementaire-decrets-en-conseil-d-etat/livre-iv/titre-xix/chapitre-iii.md#article-r53-8-49)

Conformément aux dispositions de l'article R. 53-8-49 du code de procédure pénale, le service pénitentiaire d'insertion et de probation assiste le juge de l'application des peines pour le contrôle des personnes placées sous surveillance de sûreté.

### Article D543-2
- Identifiant : LEGIARTI000045491922
- État : en vigueur depuis le 01/05/2022
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000045491922
- Renvoie à : [art. D147-32 du Code de procédure pénale](../../../../code-de-procedure-penale/partie-reglementaire-decrets-simples/livre-v/titre-ii/chapitre-ii.md#article-d147-32)

Dans les conditions prévues par les dispositions de l'article D. 147-32 du code de procédure pénale , le greffe de chaque établissement pénitentiaire transmet au procureur de la République et au juge de l'application des peines copie de la fiche pénale des personnes condamnées susceptibles de faire l'objet d'une surveillance judiciaire à leur libération.

### Article D543-3
- Identifiant : LEGIARTI000045491920
- État : en vigueur depuis le 01/05/2022
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000045491920
- Renvoie à : [art. D147-40-2 du Code de procédure pénale](../../../../code-de-procedure-penale/partie-reglementaire-decrets-simples/livre-v/titre-ii/chapitre-ii.md#article-d147-40-2)

Avant la libération de chaque personne soumise à une mesure de surveillance judiciaire, le chef de l'établissement pénitentiaire lui notifie sa convocation devant le juge de l'application des peines dans les conditions prévues par les dispositions de l'article D. 147-40-2 du code de procédure pénale.

### Article D543-4
- Identifiant : LEGIARTI000045491918
- État : en vigueur depuis le 01/05/2022
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000045491918
- Renvoie à : [art. D147-47 du Code de procédure pénale](../../../../code-de-procedure-penale/partie-reglementaire-decrets-simples/livre-v/titre-ii/chapitre-ii.md#article-d147-47) ; [art. 721-2 du Code de procédure pénale](https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006578022)

Conformément aux dispositions de l'article D. 147-47 du code de procédure pénale , le service pénitentiaire d'insertion et de probation assiste le juge de l'application des peines pour le contrôle du respect des obligations et interdictions auxquelles sont soumises des personnes faisant l'objet d'un suivi en application des dispositions de l'article 721-2 du même code.

### Article D543-5
- Identifiant : LEGIARTI000045491916
- État : en vigueur depuis le 01/05/2022
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000045491916
- Renvoie à : [art. D147-48 du Code de procédure pénale](../../../../code-de-procedure-penale/partie-reglementaire-decrets-simples/livre-v/titre-ii/chapitre-ii.md#article-d147-48) ; art. 721-2 du Code de procédure pénale

Lorsqu'il est fait application du I de l'article 721-2 du code de procédure pénale, le chef de l'établissement pénitentiaire notifie à la personne intéressée sa convocation devant le juge de l'application des peines, dans les conditions prévues par les dispositions de l'article D. 147-48 du même code.
