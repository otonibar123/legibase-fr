# Chapitre IV : PEINE DE STAGE

Code pénitentiaire › PARTIE RÉGLEMENTAIRE › Livre VI : INTERVENTION DE L'ADMINISTRATION PÉNITENTIAIRE AUPRÈS DE PERSONNES NON DÉTENUES › Titre II : INTERVENTION AUPRÈS DE PERSONNES CONDAMNÉES

### Article R624-1
- Identifiant : LEGIARTI000045491644
- État : en vigueur depuis le 01/05/2022
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000045491644
- Renvoie à : [art. R131-7 du Code pénal](../../../../code-penal/partie-reglementaire-decrets-en-conseil-d-etat/livre-ier/titre-iii/chapitre-ier.md#article-r131-7)

Dans les conditions prévues par les dispositions de l'article R. 131-7 du code pénal, le service pénitentiaire d'insertion et de probation peut contrôler la mise en œuvre de la peine de stage et en élaborer le contenu.

### Article R624-2
- Identifiant : LEGIARTI000045491642
- État : en vigueur depuis le 01/05/2022
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000045491642
- Renvoie à : [art. R131-38 du Code pénal](../../../../code-penal/partie-reglementaire-decrets-en-conseil-d-etat/livre-ier/titre-iii/chapitre-ier.md#article-r131-38)

Les modules de stage peuvent être élaborés avec le concours des personnes physiques ou morales mentionnées par les dispositions de l'article R. 131-38 du code pénal.

### Article R624-3
- Identifiant : LEGIARTI000045491640
- État : en vigueur depuis le 01/05/2022
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000045491640
- Renvoie à : [art. R131-39 du Code pénal](../../../../code-penal/partie-reglementaire-decrets-en-conseil-d-etat/livre-ier/titre-iii/chapitre-ier.md#article-r131-39)

Conformément aux dispositions de l'article R. 131-39 du code pénal, lorsque le stage est mis en œuvre sous le contrôle du service pénitentiaire d'insertion ou de probation, ce dernier reçoit la personne condamnée et lui délivre des informations relatives aux objectifs du stage et aux conséquences du non-respect des obligations résultant de ce stage.

### Article R624-4
- Identifiant : LEGIARTI000045491638
- État : en vigueur depuis le 01/05/2022
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000045491638
- Renvoie à : [art. R131-40 du Code pénal](../../../../code-penal/partie-reglementaire-decrets-en-conseil-d-etat/livre-ier/titre-iii/chapitre-ier.md#article-r131-40)

Conformément aux dispositions de l'article R. 131-40 du code pénal, lorsque le stage est mis en œuvre sous le contrôle du service pénitentiaire d'insertion ou de probation, la personne condamnée adresse au service l'attestation de fin de stage qui lui est délivrée.
