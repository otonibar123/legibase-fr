# Chapitre VI : SUIVI SOCIO-JUDICIAIRE

### Article R626-1
- Identifiant : LEGIARTI000045491626
- État : en vigueur depuis le 01/05/2022
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000045491626
- Renvoie à : [art. R61-4 du Code de procédure pénale](../../../../code-de-procedure-penale/partie-reglementaire-decrets-en-conseil-d-etat/livre-v/titre-vii-bis/chapitre-ii.md#article-r61-4) ; [art. 763-7-1 du Code de procédure pénale](https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000024460836)

Dans les conditions prévues par les dispositions de l'article R. 61-4 du code de procédure pénale, les personnes condamnées à un suivi socio-judiciaire sont informées de leur convocation à comparaître devant le service pénitentiaire d'insertion et de probation en application des dispositions de l'article 763-7-1 du même code.
