# Chapitre II : DE L'ACTION CIVILE

### Article D512-1
- Identifiant : LEGIARTI000043609791
- État : en vigueur depuis le 30/09/2021
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000043609791
- Renvoie à : [art. 1240 du Code civil](../../../../code-civil/livre-iii/titre-iii/sous-titre-ii/chapitre-ier.md#article-1240) ; [art. 1242 du Code civil](../../../../code-civil/livre-iii/titre-iii/sous-titre-ii/chapitre-ier.md#article-1242) ; [art. L512-3 du Code de la justice pénale des mineurs](https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000039088377)

La juridiction de jugement qui, après avoir déclaré que le mineur poursuivi a commis les faits qui lui sont reprochés, constate qu'il n'est pas pénalement responsable en raison de son absence de capacité de discernement, statue sur l'action civile conformément aux articles 1240 et 1242 du code civil. La juridiction peut décider de faire application des dispositions de l'article L. 512-3 du présent code.
