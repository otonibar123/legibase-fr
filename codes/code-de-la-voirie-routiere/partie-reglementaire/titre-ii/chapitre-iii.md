# Chapitre III : Routes nationales.

Code de la voirie routière › Partie réglementaire › TITRE II : Voirie nationale.

## Section 1 : Classement et déclassement.

### Article R*123-1
- Identifiant : LEGIARTI000006398738
- État : en vigueur depuis le 08/09/1989
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006398738

Le classement dans la voirie nationale d'une route nouvelle ou d'une route existante non classée dans la voirie d'une collectivité territoriale résulte soit de l'acte déclaratif d'utilité publique soit, s'il n'y a pas lieu à déclaration d'utilité publique, d'un arrêté du ministre chargé de la voirie routière nationale.

### Article R*123-2
- Identifiant : LEGIARTI000006398741
- État : en vigueur depuis le 06/12/2005
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006398741
- Renvoie à : [art. L123-3 du Code de la voirie routière](../../partie-legislative/titre-ii/chapitre-iii.md#article-l123-3)
- Cité par : [Arrêté du 14 octobre 2024](https://www.legifrance.gouv.fr/loda/id/LEGITEXT000050476679)

I.-Le déclassement d'une route ou d'une section de route nationale est prononcé par arrêté préfectoral.  

II.-Lorsqu'il n'a pas fait l'objet d'un avis défavorable de la collectivité intéressée dans le délai fixé à l'alinéa 1er de l'article L. 123-3, le reclassement dans la voirie départementale ou communale d'une route ou section de route nationale déclassée est prononcé par le préfet.

## Section 2 : Alignement.

### Article R*123-3
- Identifiant : LEGIARTI000030003623
- État : en vigueur depuis le 01/01/2015
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000030003623
- Renvoie à : [art. R131-1 du Code de l'expropriation pour cause d'utilité publique](../../../code-de-l-expropriation-pour-cause-d-utilite-publique/partie-reglementaire-nouvelle/livre-ier/titre-iii/chapitre-ier.md#article-r131-1) ; [art. R131-3 du Code de l'expropriation pour cause d'utilité publique](../../../code-de-l-expropriation-pour-cause-d-utilite-publique/partie-reglementaire-nouvelle/livre-ier/titre-iii/chapitre-ier.md#article-r131-3) ; [art. R131-14 du Code de l'expropriation pour cause d'utilité publique](../../../code-de-l-expropriation-pour-cause-d-utilite-publique/partie-reglementaire-nouvelle/livre-ier/titre-iii/chapitre-ier.md#article-r131-14)

L'enquête préalable à l'approbation des plans d'alignement des routes nationales s'effectue dans les conditions fixées aux articles R. 131-1 à R. 131-11 et R. 131-14 du code de l'expropriation pour cause d'utilité publique. Toutefois, le dossier soumis à enquête comprend outre les pièces prévues à l'article R. 131-3 dudit code, une notice explicative.

Les intéressés peuvent faire connaître leurs observations sur le projet.

### Article R*123-4
- Identifiant : LEGIARTI000030003614
- État : en vigueur depuis le 01/01/2015
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000030003614
- Renvoie à : [art. L132-1 du Code de l'expropriation pour cause d'utilité publique](../../../code-de-l-expropriation-pour-cause-d-utilite-publique/partie-legislative-nouvelle/livre-ier/titre-iii/chapitre-ii.md#article-l132-1) ; [art. R132-1 du Code de l'expropriation pour cause d'utilité publique](../../../code-de-l-expropriation-pour-cause-d-utilite-publique/partie-reglementaire-nouvelle/livre-ier/titre-iii/chapitre-ii.md#article-r132-1) ; [art. R221-1 du Code de l'expropriation pour cause d'utilité publique](../../../code-de-l-expropriation-pour-cause-d-utilite-publique/partie-reglementaire-nouvelle/livre-ii/titre-ii/chapitre-ier.md#article-r221-1)

Dans le cas où, en vue de la réalisation des alignements, il est nécessaire d'exproprier des immeubles bâtis, et quel que soit le délai écoulé depuis l'approbation du plan d'alignement, le préfet prend, sans autre enquête ni formalité, l'arrêté de cessibilité prévu aux articles L. 132-1 à L. 132-4 et R. 132-1 à R. 132-3 du code de l'expropriation pour cause d'utilité publique.

Il est ensuite procédé conformément aux dispositions des chapitres II et suivants du titre Ier du même code.

Toutefois le dossier prévu à l'article R. 221-1 du code de l'expropriation pour cause d'utilité publique est remplacé par un dossier comprenant les copies certifiées conformes :

a) De l'acte approuvant le plan d'alignement ;

b) D'un extrait du plan d'alignement se rapportant aux immeubles bâtis à exproprier ;

c) De l'arrêté de cessibilité ayant moins de six mois de date.
