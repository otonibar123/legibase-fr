# Chapitre III : Valeurs limites d'exposition

Code du travail › Partie réglementaire › Quatrième partie : Santé et sécurité au travail › Livre IV : Prévention de certains risques d'exposition › Titre IV : Prévention des risques d'exposition aux vibrations mécaniques

### Article R4443-1
- Identifiant : LEGIARTI000018530277
- État : en vigueur depuis le 01/05/2008
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000018530277
- Cité par : [art. R717-85-9 du Code rural (nouveau)](../../../../../code-rural-nouveau/partie-reglementaire/livre-vii/titre-ier/chapitre-vii.md#article-r717-85-9)

L'exposition journalière d'un travailleur aux vibrations mécaniques, rapportée à une période de référence de huit heures, ne peut dépasser les valeurs limites d'exposition suivantes :  
1° 5 m/s2 pour les vibrations transmises aux mains et aux bras ;  
2° 1,15 m/s2 pour les vibrations transmises à l'ensemble du corps.

### Article R4443-2
- Identifiant : LEGIARTI000018530275
- État : en vigueur depuis le 01/05/2008
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000018530275
- Renvoie à : [art. R4445-1 du Code du travail](chapitre-v.md#article-r4445-1)
- Cité par : [art. D4153-20 du Code du travail](../../livre-ier/titre-v/chapitre-iii.md#article-d4153-20) ; [art. R4444-5 du Code du travail](chapitre-iv.md#article-r4444-5) ; [art. R4445-1 du Code du travail](chapitre-v.md#article-r4445-1) ; [art. R717-16 du Code rural (nouveau)](../../../../../code-rural-nouveau/partie-reglementaire/livre-vii/titre-ier/chapitre-vii.md#article-r717-16)

La valeur d'exposition journalière rapportée à une période de référence de huit heures déclenchant l'action de prévention prévue à l'article R. 4445-1 et à l'article R. 4446-1 est fixée à :  
1° 2,5 m / s2 pour les vibrations transmises aux mains et aux bras ;  
2° 0,5 m / s2 pour les vibrations transmises à l'ensemble du corps.
