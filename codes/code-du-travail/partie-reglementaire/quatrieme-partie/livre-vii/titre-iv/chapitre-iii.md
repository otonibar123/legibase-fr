# Chapitre III : Infractions aux règles concernant le travail des jeunes et des femmes enceintes, venant d'accoucher ou allaitant

Code du travail › Partie réglementaire › Quatrième partie : Santé et sécurité au travail › Livre VII : Contrôle › Titre IV : Dispositions pénales

### Article R4743-1
- Identifiant : LEGIARTI000018527368
- État : en vigueur depuis le 01/05/2008
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000018527368
- Renvoie à : [art. L4152-1 du Code du travail](../../../../partie-legislative/quatrieme-partie/livre-ier/titre-v/chapitre-ii.md#article-l4152-1) ; [art. 132-11 du Code pénal](../../../../../code-penal/partie-legislative/livre-ier/titre-iii/chapitre-ii.md#article-132-11) ; [art. 132-15 du Code pénal](../../../../../code-penal/partie-legislative/livre-ier/titre-iii/chapitre-ii.md#article-132-15)

Le fait d'employer une femme enceinte, venant d'accoucher ou allaitant à des travaux interdits, en méconnaissance de l'article L. 4152-1 et des décrets pris pour son application, est puni de l'amende prévue pour les contraventions de la cinquième classe.

La récidive est réprimée conformément aux articles 132-11 et 132-15 du code pénal.

### Article R4743-2
- Identifiant : LEGIARTI000018527366
- État : en vigueur depuis le 01/05/2008
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000018527366
- Renvoie à : [art. R4152-13 du Code du travail](../../livre-ier/titre-v/chapitre-ii.md#article-r4152-13) ; [art. 132-11 du Code pénal](../../../../../code-penal/partie-legislative/livre-ier/titre-iii/chapitre-ii.md#article-132-11) ; [art. 132-15 du Code pénal](../../../../../code-penal/partie-legislative/livre-ier/titre-iii/chapitre-ii.md#article-132-15)

Le fait de méconnaître les dispositions des articles R. 4152-13 à R. 4152-28, relatives au local dédié à l'allaitement, est puni de l'amende prévue pour les contraventions de la cinquième classe, prononcée autant de fois qu'il y a de travailleurs concernés par l'infraction.  
La récidive de la contravention prévue au présent article est réprimée conformément aux articles 132-11 et 132-15 du code pénal.  
En cas de pluralité de contraventions entraînant les peines de la récidive, l'amende est appliquée autant de fois qu'il a été relevé de nouvelles infractions.

### Article R4743-3
- Identifiant : LEGIARTI000018527364
- État : en vigueur depuis le 01/05/2008
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000018527364
- Renvoie à : [art. L4153-1 du Code du travail](../../../../partie-legislative/quatrieme-partie/livre-ier/titre-v/chapitre-iii.md#article-l4153-1) ; [art. 132-11 du Code pénal](../../../../../code-penal/partie-legislative/livre-ier/titre-iii/chapitre-ii.md#article-132-11) ; [art. 132-15 du Code pénal](../../../../../code-penal/partie-legislative/livre-ier/titre-iii/chapitre-ii.md#article-132-15)

Le fait d'employer un travailleur de moins de dix-huit ans à des travaux interdits, en méconnaissance de l'article L. 4153-8 et des décrets pris pour son application, est puni de l'amende prévue pour les contraventions de la cinquième classe.

La récidive est réprimée conformément aux articles 132-11 et 132-15 du code pénal.

### Article R4743-4
- Identifiant : LEGIARTI000018527362
- État : en vigueur depuis le 01/05/2008
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000018527362
- Renvoie à : [art. L4153-9 du Code du travail](../../../../partie-legislative/quatrieme-partie/livre-ier/titre-v/chapitre-iii.md#article-l4153-9) ; [art. 132-11 du Code pénal](../../../../../code-penal/partie-legislative/livre-ier/titre-iii/chapitre-ii.md#article-132-11) ; [art. 132-15 du Code pénal](../../../../../code-penal/partie-legislative/livre-ier/titre-iii/chapitre-ii.md#article-132-15)

Le fait d'employer un travailleur de moins de dix-huit ans à des travaux mentionnés à l'article L. 4153-9, en méconnaissance des conditions énoncées à ce même article et de celles des décrets pris pour son application, est puni de l'amende prévue pour les contraventions de la cinquième classe.

La récidive est réprimée conformément aux articles 132-11 et 132-15 du code pénal.

### Article R4743-5
- Identifiant : LEGIARTI000018527360
- État : en vigueur depuis le 01/05/2008
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000018527360
- Renvoie à : [art. L4153-1 du Code du travail](../../../../partie-legislative/quatrieme-partie/livre-ier/titre-v/chapitre-iii.md#article-l4153-1) ; [art. 132-11 du Code pénal](../../../../../code-penal/partie-legislative/livre-ier/titre-iii/chapitre-ii.md#article-132-11) ; [art. 132-15 du Code pénal](../../../../../code-penal/partie-legislative/livre-ier/titre-iii/chapitre-ii.md#article-132-15)
- Cité par : [art. R4743-6 du Code du travail](chapitre-iii.md#article-r4743-6)

Le fait de méconnaître les dispositions relatives à l'âge d'admission prévues aux articles L. 4153-1 à L. 4153-5 ainsi que celles des décrets pris pour leur application, est puni de l'amende prévue pour les contraventions de la cinquième classe.

La récidive est réprimée conformément aux articles 132-11 et 132-15 du code pénal.

### Article R4743-6
- Identifiant : LEGIARTI000018527358
- État : en vigueur depuis le 01/05/2008
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000018527358
- Renvoie à : [art. R4743-5 du Code du travail](chapitre-iii.md#article-r4743-5)

L'amende prévue à l'article R. 4743-5 est appliquée autant de fois qu'il y a de personnes employées dans des conditions contraires aux prescriptions mentionnées à ce même article.  
En cas de pluralité de contraventions entraînant les peines de la récidive, l'amende est appliquée autant de fois qu'il a été relevé de nouvelles infractions.

### Article R4743-7
- Identifiant : LEGIARTI000018527356
- État : en vigueur depuis le 01/05/2008
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000018527356
- Renvoie à : [art. R4153-8 du Code du travail](../../livre-ier/titre-v/chapitre-iii.md#article-r4153-8) ; [art. 132-11 du Code pénal](../../../../../code-penal/partie-legislative/livre-ier/titre-iii/chapitre-ii.md#article-132-11) ; [art. 132-15 du Code pénal](../../../../../code-penal/partie-legislative/livre-ier/titre-iii/chapitre-ii.md#article-132-15)
- Cité par : [art. R3352-3 du Code de la santé publique](../../../../../code-de-la-sante-publique/partie-reglementaire/troisieme-partie/livre-iii/titre-v/chapitre-ii.md#article-r3352-3)

Le fait, pour un exploitant d'un débit de boissons à consommer sur place, sans avoir obtenu l'agrément prévu à l'article R. 4153-8, d'employer ou de recevoir en stage des mineurs, à l'exception du conjoint du débitant ou de ses parents ou alliés jusqu'au quatrième degré inclusivement, est puni de l'amende prévue pour les contraventions de la cinquième classe.

La récidive est réprimée conformément aux articles 132-11 et 132-15 du code pénal.
