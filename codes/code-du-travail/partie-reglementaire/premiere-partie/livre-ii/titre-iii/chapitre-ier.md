# Chapitre Ier : Dispositions générales

Code du travail › Partie réglementaire › Première partie : Les relations individuelles de travail › Livre II : Le contrat de travail › Titre III : Rupture du contrat de travail à durée indéterminée

### Article R1231-1
- Identifiant : LEGIARTI000018537730
- État : en vigueur depuis le 01/05/2008
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000018537730

Lorsque les délais prévus par les dispositions légales du présent titre expirent un samedi, un dimanche ou un jour férié ou chômé, ils sont prorogés jusqu'au premier jour ouvrable suivant.
