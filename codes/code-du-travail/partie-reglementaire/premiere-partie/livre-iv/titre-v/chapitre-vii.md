# Chapitre VII : Récusation

Code du travail › Partie réglementaire › Première partie : Les relations individuelles de travail › Livre IV : La résolution des litiges - Le conseil de prud'hommes › Titre V : Procédure devant le conseil de prud'hommes

### Article R1457-1
- Identifiant : LEGIARTI000018535948
- État : en vigueur depuis le 01/05/2008
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000018535948
- Renvoie à : [art. 341 du Code de procédure civile](../../../../../code-de-procedure-civile/livre-ier/titre-x/chapitre-ii.md#article-341)

La procédure de récusation des conseillers prud'hommes est régie par les articles 341 à 355 du code de procédure civile.

### Article R1457-2
- Identifiant : LEGIARTI000018535946
- État : en vigueur depuis le 01/05/2008
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000018535946
- Cité par : [art. R1523-5 du Code du travail](../../livre-v/titre-ii/chapitre-iii.md#article-r1523-5)

Lorsque la demande de récusation est portée devant la cour d'appel, elle est jugée par la chambre sociale.
