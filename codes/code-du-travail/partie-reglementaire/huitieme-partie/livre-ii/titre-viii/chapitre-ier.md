# Chapitre Ier : Obligation de vigilance et responsabilité du donneur d'ordre

Code du travail › Partie réglementaire › Huitième partie : Contrôle de l'application de la législation du travail › Livre II : Lutte contre le travail illégal › Titre VIII : Obligation du donneur d'ordre en matière d'application de la législation du travail

### Article R8281-1
- Identifiant : LEGIARTI000030421324
- État : en vigueur depuis le 01/05/2015
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000030421324
- Renvoie à : [art. L8281-1 du Code du travail](../../../../partie-legislative/huitieme-partie/livre-ii/titre-viii/chapitre-unique.md#article-l8281-1)
- Cité par : [art. R1262-19 du Code du travail](../../../premiere-partie/livre-ii/titre-vi/chapitre-ii.md#article-r1262-19) ; [art. R8281-4 du Code du travail](chapitre-ier.md#article-r8281-4) ; [art. R8282-1 du Code du travail](chapitre-ii.md#article-r8282-1) ; [art. R1331-6 du Code des transports](https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000046477168)

Le maître d'ouvrage ou le donneur d'ordre concerné enjoint l'employeur, dans un délai de vingt-quatre heures à compter de son information, de faire cesser immédiatement le non-respect de l'une des dispositions énumérées par l'article L. 8281-1.

### Article R8281-2
- Identifiant : LEGIARTI000030421326
- État : en vigueur depuis le 01/05/2015
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000030421326
- Cité par : [art. R8281-3 du Code du travail](chapitre-ier.md#article-r8281-3)

Dès réception de l'injonction, l'employeur informe dans un délai de quinze jours le maître d'ouvrage ou le donneur d'ordre des mesures prises pour faire cesser la situation.  

Le maître d'ouvrage ou le donneur d'ordre transmet aussitôt cette réponse à l'agent de contrôle auteur du signalement.

### Article R8281-3
- Identifiant : LEGIARTI000030421328
- État : en vigueur depuis le 01/05/2015
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000030421328
- Renvoie à : [art. R8281-2 du Code du travail](chapitre-ier.md#article-r8281-2)
- Cité par : [art. R8281-4 du Code du travail](chapitre-ier.md#article-r8281-4) ; [art. R8282-1 du Code du travail](chapitre-ii.md#article-r8282-1)

En l'absence de réponse de l'employeur à son injonction, le maître d'ouvrage ou le donneur d'ordre informe l'agent auteur du signalement dans les deux jours suivant l'expiration du délai prévu par l'article R. 8281-2.

### Article R8281-4
- Identifiant : LEGIARTI000030421330
- État : en vigueur depuis le 01/05/2015
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000030421330
- Renvoie à : [art. R8281-1 du Code du travail](chapitre-ier.md#article-r8281-1) ; [art. R8281-3 du Code du travail](chapitre-ier.md#article-r8281-3)

Les injonctions et les informations mentionnées aux articles R. 8281-1 à R. 8281-3 sont effectuées par tout moyen leur conférant date certaine.
