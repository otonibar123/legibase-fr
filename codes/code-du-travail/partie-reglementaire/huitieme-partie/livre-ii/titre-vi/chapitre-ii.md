# Chapitre II : Dispositions pénales

### Article R8262-1
- Identifiant : LEGIARTI000018520528
- État : en vigueur depuis le 01/05/2008
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000018520528
- Renvoie à : [art. L8261-1 du Code du travail](../../../../partie-legislative/huitieme-partie/livre-ii/titre-vi/chapitre-ier.md#article-l8261-1) ; [art. 132-11 du Code pénal](../../../../../code-penal/partie-legislative/livre-ier/titre-iii/chapitre-ii.md#article-132-11) ; [art. 132-15 du Code pénal](../../../../../code-penal/partie-legislative/livre-ier/titre-iii/chapitre-ii.md#article-132-15)

Le fait, pour un salarié, d'accomplir des travaux rémunérés au-delà de la durée maximale hebdomadaire du travail, telle qu'elle ressort des dispositions légales de sa profession, en méconnaissance des dispositions de l'article L. 8261-1, est puni de l'amende prévue pour les contraventions de la cinquième classe.

La récidive est réprimée conformément aux articles 132-11 et 132-15 du code pénal.

### Article R8262-2
- Identifiant : LEGIARTI000018520526
- État : en vigueur depuis le 01/05/2008
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000018520526
- Renvoie à : [art. L8261-1 du Code du travail](../../../../partie-legislative/huitieme-partie/livre-ii/titre-vi/chapitre-ier.md#article-l8261-1) ; [art. 132-11 du Code pénal](../../../../../code-penal/partie-legislative/livre-ier/titre-iii/chapitre-ii.md#article-132-11) ; [art. 132-15 du Code pénal](../../../../../code-penal/partie-legislative/livre-ier/titre-iii/chapitre-ii.md#article-132-15)

Le fait de recourir aux services d'une personne qui méconnaît les dispositions de l'article L. 8261-1 est puni de l'amende prévue pour les contraventions de la cinquième classe.

La récidive est réprimée conformément aux articles 132-11 et 132-15 du code pénal.
