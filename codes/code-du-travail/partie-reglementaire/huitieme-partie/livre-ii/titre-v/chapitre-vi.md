# Chapitre VI : Dispositions pénales

Code du travail › Partie réglementaire › Huitième partie : Contrôle de l'application de la législation du travail › Livre II : Lutte contre le travail illégal › Titre V : Emploi d'étrangers non autorisés à travailler

### Article R8256-1
- Identifiant : LEGIARTI000018520540
- État : en vigueur depuis le 01/05/2008
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000018520540
- Renvoie à : [art. L8251-1 du Code du travail](../../../../partie-legislative/huitieme-partie/livre-ii/titre-v/chapitre-ier.md#article-l8251-1) ; [art. 132-11 du Code pénal](../../../../../code-penal/partie-legislative/livre-ier/titre-iii/chapitre-ii.md#article-132-11) ; [art. 132-15 du Code pénal](../../../../../code-penal/partie-legislative/livre-ier/titre-iii/chapitre-ii.md#article-132-15)

Le fait d'engager ou de conserver à son service un étranger dans une catégorie professionnelle, une profession ou une zone géographique autres que celles mentionnées, le cas échéant, sur le titre de travail mentionné au premier alinéa de l'article L. 8251-1, en méconnaissance du second alinéa de ce même article, est puni de l'amende prévue pour les contraventions de la cinquième classe.

La récidive est réprimée conformément aux articles 132-11 et 132-15 du code pénal.
