# Chapitre II : Dispositions pénales

Code du travail › Partie réglementaire › Troisième partie : Durée du travail, salaire, intéressement, participation et épargne salariale › Livre II : Salaire et avantages divers › Titre II : Egalité de rémunération entre les femmes et les hommes

### Article R3222-1
- Identifiant : LEGIARTI000018533898
- État : en vigueur depuis le 01/05/2008
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000018533898
- Renvoie à : [art. L3221-2 du Code du travail](../../../../partie-legislative/troisieme-partie/livre-ii/titre-ii/chapitre-ier.md#article-l3221-2) ; [art. 132-11 du Code pénal](../../../../../code-penal/partie-legislative/livre-ier/titre-iii/chapitre-ii.md#article-132-11) ; [art. 132-15 du Code pénal](../../../../../code-penal/partie-legislative/livre-ier/titre-iii/chapitre-ii.md#article-132-15)

Le fait de méconnaître les dispositions relatives à l'égalité de rémunération entre les femmes et les hommes prévues aux articles L. 3221-2 à L. 3221-6, est puni de l'amende prévue pour les contraventions de la cinquième classe.

L'amende est appliquée autant de fois qu'il y a de travailleurs rémunérés dans des conditions illégales.

La récidive est réprimée conformément aux articles 132-11 et 132-15 du code pénal.

### Article R3222-2
- Identifiant : LEGIARTI000018533896
- État : en vigueur depuis le 01/05/2008
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000018533896
- Renvoie à : [art. R3221-1 du Code du travail](chapitre-ier.md#article-r3221-1)

Le fait de ne pas communiquer les éléments concourant à la détermination des rémunérations dans l'entreprise, en méconnaissance des dispositions de l'article R. 3221-1, est puni de l'amende prévue pour les contraventions de la troisième classe.

### Article R3222-3
- Identifiant : LEGIARTI000033292522
- État : en vigueur depuis le 23/10/2016
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000033292522
- Renvoie à : [art. R3221-2 du Code du travail](chapitre-ier.md#article-r3221-2)

Le fait de ne pas communiquer, dans les conditions prévues par l'article R. 3221-2, les articles relatifs à l'égalité de rémunération entre les femmes et les hommes, est puni de l'amende prévue pour les contraventions de la troisième classe.
