- Identifiant : LEGIARTI000020398260
- État : en vigueur depuis le 16/03/2009
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000020398260
- Renvoie à : [art. L3241-1 du Code du travail](../../../../partie-legislative/troisieme-partie/livre-ii/titre-iv/chapitre-ier.md#article-l3241-1) ; [art. L3242-4 du Code du travail](../../../../partie-legislative/troisieme-partie/livre-ii/titre-iv/chapitre-ii.md#article-l3242-4)

### Article R3246-2
- Identifiant : LEGIARTI000033644145
- État : en vigueur depuis le 01/01/2017
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000033644145
- Renvoie à : [art. L3243-1 du Code du travail](../../../../partie-legislative/troisieme-partie/livre-ii/titre-iv/chapitre-iii.md#article-l3243-1) ; [art. L3243-2 du Code du travail](../../../../partie-legislative/troisieme-partie/livre-ii/titre-iv/chapitre-iii.md#article-l3243-2) ; [art. L3243-4 du Code du travail](../../../../partie-legislative/troisieme-partie/livre-ii/titre-iv/chapitre-iii.md#article-l3243-4) ; [art. R3243-1 du Code du travail](chapitre-iii.md#article-r3243-1)

Le fait de méconnaître les dispositions relatives au bulletin de paie des articles L. 3243-1, L. 3243-2 et L. 3243-4 et des articles R. 3243-1 à D. 3243-8, est puni de l'amende prévue pour les contraventions de la troisième classe.

### Article R3246-3
- Identifiant : LEGIARTI000020398277
- État : en vigueur depuis le 16/03/2009
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000020398277
- Renvoie à : [art. L3244-1 du Code du travail](../../../../partie-legislative/troisieme-partie/livre-ii/titre-iv/chapitre-iv.md#article-l3244-1) ; [art. L3244-2 du Code du travail](../../../../partie-legislative/troisieme-partie/livre-ii/titre-iv/chapitre-iv.md#article-l3244-2) ; [art. R3244-2 du Code du travail](chapitre-iv.md#article-r3244-2)

Le fait de méconnaître les dispositions relatives aux pourboires des articles L. 3244-1 et L. 3244-2 et celle des décrets en Conseil d'Etat prévus à l'article R. 3244-2, est puni de l'amende prévue pour les contraventions de la troisième classe.

### Article R3246-4
- Identifiant : LEGIARTI000018533776
- État : en vigueur depuis le 01/05/2008
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000018533776

Le fait de méconnaître les dispositions légales relatives aux accessoires du salaire est puni de la peine d'amende prévue pour les contraventions de la quatrième classe.  
L'amende est prononcée autant de fois qu'il y a de salariés intéressés.
