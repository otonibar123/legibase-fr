### Article R6227-2
- Identifiant : LEGIARTI000037812814
- État : en vigueur depuis le 15/12/2018
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000037812814
- Renvoie à : [art. L3121-27 du Code du travail](../../../../partie-legislative/troisieme-partie/livre-ier/titre-ii/chapitre-ier.md#article-l3121-27) ; [art. R6222-25 du Code du travail](chapitre-ii.md#article-r6222-25) ; [art. L713-2 du Code rural (nouveau)](../../../../../code-rural-nouveau/partie-legislative/livre-vii/titre-ier/chapitre-iii.md#article-l713-2)

Le fait d'employer un apprenti à un travail effectif excédant huit heures par jour ou la durée légale hebdomadaire fixée par l'article L. 3121-27 du code du travail et par l'article L. 713-2 du code rural et de la pêche maritime, en méconnaissance des dispositions de l'article L. 6222-25, est puni de l'amende prévue pour les contraventions de la quatrième classe.

> Nota : Conformément à l'article 3 du décret n° 2018-1139 du 13 décembre 2018, ces dispositions sont applicables aux contrats conclus à partir du 1er janvier 2019.

### Article R6227-3
- Identifiant : LEGIARTI000025684810
- État : en vigueur depuis le 14/04/2012
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000025684810
- Renvoie à : [art. L6222-26 du Code du travail](../../../../partie-legislative/sixieme-partie/livre-ii/titre-ii/chapitre-ii.md#article-l6222-26) ; [art. 132-11 du Code pénal](../../../../../code-penal/partie-legislative/livre-ier/titre-iii/chapitre-ii.md#article-132-11) ; [art. 132-15 du Code pénal](../../../../../code-penal/partie-legislative/livre-ier/titre-iii/chapitre-ii.md#article-132-15)

Le fait d'employer un apprenti âgé de moins de dix-huit ans à un travail de nuit, en méconnaissance des dispositions de l'article L. 6222-26, est puni de l'amende prévue pour les contraventions de la cinquième classe.

La récidive est réprimée conformément aux articles 132-11 et 132-15 du code pénal.

### Article R6227-4
- Identifiant : LEGIARTI000025684819
- État : en vigueur depuis le 14/04/2012
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000025684819
- Renvoie à : [art. L6222-27 du Code du travail](../../../../partie-legislative/sixieme-partie/livre-ii/titre-ii/chapitre-ii.md#article-l6222-27) ; [art. 132-11 du Code pénal](../../../../../code-penal/partie-legislative/livre-ier/titre-iii/chapitre-ii.md#article-132-11) ; [art. 132-15 du Code pénal](../../../../../code-penal/partie-legislative/livre-ier/titre-iii/chapitre-ii.md#article-132-15)

Le fait de verser un salaire à l'apprenti inférieur au minimum prévu par l'article L. 6222-27, est puni de l'amende prévue pour les contraventions de la cinquième classe.

L'amende est appliquée autant de fois qu'il y a d'apprentis rémunérés dans des conditions illégales.

La récidive est réprimée conformément aux articles 132-11 et 132-15 du code pénal.

### Article R6227-5
- Identifiant : LEGIARTI000025684829
- État : en vigueur depuis le 14/04/2012
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000025684829
- Renvoie à : [art. L6222-30 du Code du travail](../../../../partie-legislative/sixieme-partie/livre-ii/titre-ii/chapitre-ii.md#article-l6222-30) ; [art. 132-11 du Code pénal](../../../../../code-penal/partie-legislative/livre-ier/titre-iii/chapitre-ii.md#article-132-11) ; [art. 132-15 du Code pénal](../../../../../code-penal/partie-legislative/livre-ier/titre-iii/chapitre-ii.md#article-132-15)

Le fait d'employer un apprenti à des travaux dangereux pour sa santé ou sa sécurité, en méconnaissance des dispositions de l'article L. 6222-30, est puni de l'amende prévue pour les contraventions de la cinquième classe.

La récidive est réprimée conformément aux articles 132-11 et 132-15 du code pénal.

### Article R6227-6
- Identifiant : LEGIARTI000025684838
- État : en vigueur depuis le 14/04/2012
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000025684838
- Renvoie à : [art. L6222-34 du Code du travail](../../../../partie-legislative/sixieme-partie/livre-ii/titre-ii/chapitre-ii.md#article-l6222-34) ; [art. 132-11 du Code pénal](../../../../../code-penal/partie-legislative/livre-ier/titre-iii/chapitre-ii.md#article-132-11) ; [art. 132-15 du Code pénal](../../../../../code-penal/partie-legislative/livre-ier/titre-iii/chapitre-ii.md#article-132-15)

Le fait de ne pas présenter l'apprenti aux épreuves du diplôme ou du titre prévu par le contrat d'apprentissage, en méconnaissance des dispositions de l'article L. 6222-34, est puni de l'amende prévue pour les contraventions de la cinquième classe.

La récidive est réprimée conformément aux articles 132-11 et 132-15 du code pénal.

### Article R6227-7
- Identifiant : LEGIARTI000025684847
- État : en vigueur depuis le 14/04/2012
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000025684847
- Renvoie à : [art. L6222-35 du Code du travail](../../../../partie-legislative/sixieme-partie/livre-ii/titre-ii/chapitre-ii.md#article-l6222-35) ; [art. 132-11 du Code pénal](../../../../../code-penal/partie-legislative/livre-ier/titre-iii/chapitre-ii.md#article-132-11) ; [art. 132-15 du Code pénal](../../../../../code-penal/partie-legislative/livre-ier/titre-iii/chapitre-ii.md#article-132-15)

Le fait de ne pas accorder un congé supplémentaire de cinq jours à l'apprenti pour lui permettre de préparer les épreuves dans un centre de formation d'apprentis, ou de ne pas maintenir le salaire de l'apprenti pendant ce congé en méconnaissance des dispositions de l'article L. 6222-35, est puni de l'amende prévue pour les contraventions de la cinquième classe.

La récidive est réprimée conformément aux articles 132-11 et 132-15 du code pénal.
