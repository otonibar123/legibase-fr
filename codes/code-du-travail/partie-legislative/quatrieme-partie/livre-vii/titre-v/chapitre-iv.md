# Chapitre IV : Manquements aux règles concernant les repérages avant travaux

Code du travail › Partie législative › Quatrième partie : Santé et sécurité au travail › Livre VII : Contrôle › Titre V : Amendes administratives

### Article L4754-1
- Identifiant : LEGIARTI000033013789
- État : en vigueur depuis le 10/08/2016
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000033013789
- Renvoie à : [art. L4412-2 du Code du travail](../../livre-iv/titre-ier/chapitre-ii-bis.md#article-l4412-2)
- Cité par : [art. R8115-9 du Code du travail](../../../../partie-reglementaire/huitieme-partie/livre-ier/titre-ier/chapitre-v.md#article-r8115-9) ; [art. R8115-10 du Code du travail](../../../../partie-reglementaire/huitieme-partie/livre-ier/titre-ier/chapitre-v.md#article-r8115-10)

Le fait pour le donneur d'ordre, le maître d'ouvrage ou le propriétaire de ne pas se conformer aux obligations prévues à l'article L. 4412-2 et aux dispositions réglementaires prises pour son application est passible d'une amende maximale de 9 000 €.
