# Chapitre II : Rôle des collectivités territoriales.

Code du travail › Partie législative › Cinquième partie : L'emploi › Livre III : Service public de l'emploi et placement › Titre II : Placement

### Article L5322-1
- Identifiant : LEGIARTI000018766928
- État : en vigueur depuis le 01/05/2008
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000018766928
- Renvoie à : [art. L5312-1 du Code du travail](../titre-ier/chapitre-ii.md#article-l5312-1) ; [art. L5312-3 du Code du travail](../titre-ier/chapitre-ii.md#article-l5312-3)
- Cité par : [art. L5311-3 du Code du travail](../titre-ier/chapitre-ier.md#article-l5311-3)

Dans les localités où il n'existe pas de bureau de l'institution mentionnée à l'article L. 5312-1 ou de bureau des organismes ayant conclu une convention avec l'institution mentionnée à l'article L. 5312-1 en application des dispositions de l'article L. 5312-3, les maires sont chargés de recevoir et de consigner les déclarations des demandeurs d'emploi et de les transmettre à ces organismes ou, en l'absence de convention, à l'institution mentionnée à l'article L. 5312-1.

### Article L5322-2
- Identifiant : LEGIARTI000018766925
- État : en vigueur depuis le 01/05/2008
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000018766925
- Renvoie à : [art. L5312-1 du Code du travail](../titre-ier/chapitre-ii.md#article-l5312-1)
- Cité par : [art. L5311-3 du Code du travail](../titre-ier/chapitre-ier.md#article-l5311-3) ; [art. R5312-3 du Code du travail](../../../../partie-reglementaire/cinquieme-partie/livre-iii/titre-ier/chapitre-ii.md#article-r5312-3) ; [art. R5312-42-1 du Code du travail](../../../../partie-reglementaire/cinquieme-partie/livre-iii/titre-ier/chapitre-ii.md#article-r5312-42-1) ; [art. R5322-5 du Code du travail](../../../../partie-reglementaire/cinquieme-partie/livre-iii/titre-ii/chapitre-ii.md#article-r5322-5)

Les communes peuvent recevoir des offres d'emploi et réaliser des opérations de placement en faveur de leurs administrés à la recherche d'un emploi, après avoir conclu à cet effet une convention avec l'Etat et l'institution mentionnée à l'article L. 5312-1.

### Article L5322-3
- Identifiant : LEGIARTI000006903784
- État : en vigueur depuis le 01/05/2008
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006903784
- Cité par : [art. L5322-4 du Code du travail](chapitre-ii.md#article-l5322-4) ; [art. R5322-4 du Code du travail](../../../../partie-reglementaire/cinquieme-partie/livre-iii/titre-ii/chapitre-ii.md#article-r5322-4)

A leur demande, les maires, pour les besoins du placement ou pour la détermination des avantages sociaux auxquels peuvent prétendre les intéressés, ont communication de la liste des demandeurs d'emploi domiciliés dans leur commune.

### Article L5322-4
- Identifiant : LEGIARTI000006903785
- État : en vigueur depuis le 01/05/2008
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006903785
- Renvoie à : [art. L5322-3 du Code du travail](chapitre-ii.md#article-l5322-3)

Des décrets en Conseil d'Etat déterminent les conditions d'application du présent chapitre, notamment les conditions de transmission aux maires de la liste des demandeurs d'emploi inscrits sur leur commune, en application de l'article L. 5322-3.
