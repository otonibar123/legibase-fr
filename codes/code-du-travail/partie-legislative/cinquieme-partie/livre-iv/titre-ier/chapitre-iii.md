# Chapitre III : Dispositions pénales.

Code du travail › Partie législative › Cinquième partie : L'emploi › Livre IV : Le demandeur d'emploi › Titre Ier : Droits et obligations du demandeur d'emploi

### Article L5413-1
- Identifiant : LEGIARTI000037388572
- État : en vigueur depuis le 01/01/2019
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000037388572
- Renvoie à : [art. L5411-1 du Code du travail](chapitre-ier.md#article-l5411-1) ; art. 441-6 du Code pénal
- Cité par : [Ordonnance n°2016-160 du 18 février 2016, art. 1](https://www.legifrance.gouv.fr/loda/article_lc/LEGIARTI000035903404)

Le fait d'établir de fausses déclarations ou de fournir de fausses informations pour être ou demeurer inscrit sur la liste des demandeurs d'emploi mentionnée à l'article L. 5411-1 est puni des peines prévues à l'article 441-6 du code pénal.
