# Chapitre VIII : Dispositions pénales.

Code du travail › Partie législative › Première partie : Les relations individuelles de travail › Livre II : Le contrat de travail › Titre III : Rupture du contrat de travail à durée indéterminée

### Article L1238-1
- Identifiant : LEGIARTI000006901186
- État : en vigueur depuis le 01/05/2008
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006901186
- Renvoie à : [art. L1232-8 du Code du travail](chapitre-ii.md#article-l1232-8) ; [art. L1232-12 du Code du travail](chapitre-ii.md#article-l1232-12) ; [art. L1232-14 du Code du travail](chapitre-ii.md#article-l1232-14)

Le fait de porter ou de tenter de porter atteinte à l'exercice régulier des fonctions de conseiller du salarié, notamment par la méconnaissance des articles L. 1232-8 à L. 1232-12 et L. 1232-14, est puni d'un emprisonnement d'un an et d'une amende de 3 750 euros.

### Article L1238-2
- Identifiant : LEGIARTI000035652862
- État : en vigueur depuis le 01/01/2018
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000035652862
- Renvoie à : [art. L1233-29 du Code du travail](chapitre-iii.md#article-l1233-29) ; [art. L1233-30 du Code du travail](chapitre-iii.md#article-l1233-30) ; [art. L1233-34 du Code du travail](chapitre-iii.md#article-l1233-34) ; [art. L1233-35 du Code du travail](chapitre-iii.md#article-l1233-35)

Le fait de procéder à un licenciement sans accomplir les consultations du comité social et économique prévues aux articles L. 1233-29, L. 1233-30, L. 1233-34 et L. 1233-35, est puni d'une amende de 3 750 euros, prononcée autant de fois qu'il y a de salariés concernés par l'infraction.

### Article L1238-3
- Identifiant : LEGIARTI000006901188
- État : en vigueur depuis le 01/05/2008
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006901188
- Renvoie à : [art. L1233-39 du Code du travail](chapitre-iii.md#article-l1233-39)

Le fait de ne pas respecter le délai d'envoi des lettres de licenciement prévu à l'article L. 1233-39 est puni d'une amende de 3 750 euros, prononcée autant de fois qu'il y a de salariés concernés par l'infraction.

### Article L1238-4
- Identifiant : LEGIARTI000006901189
- État : en vigueur depuis le 01/05/2008
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006901189
- Renvoie à : [art. L1233-46 du Code du travail](chapitre-iii.md#article-l1233-46)

Le fait de procéder à un licenciement sans le notifier à l'autorité administrative dans les conditions prévues à l'article L. 1233-46 est puni d'une amende de 3 750 euros, prononcée autant de fois qu'il y a de salariés concernés par l'infraction.

### Article L1238-5
- Identifiant : LEGIARTI000006901190
- État : en vigueur depuis le 01/05/2008
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006901190
- Renvoie à : [art. L1233-58 du Code du travail](chapitre-iii.md#article-l1233-58) ; [art. L1233-60 du Code du travail](chapitre-iii.md#article-l1233-60)

En cas de redressement ou de liquidation judiciaire, le fait pour l'employeur, l'administrateur ou le liquidateur de ne pas respecter les dispositions des articles L. 1233-58 et L. 1233-60 est puni d'une amende de 3 750 euros, prononcée autant de fois qu'il y a de salariés concernés par l'infraction.
