L451-1 du Code de l'action sociale et des familles](../../../../../code-de-l-action-sociale-et-des-familles/partie-legislative/livre-iv/titre-v/chapitre-ier.md#article-l451-1) ; [art. ## Section 2 : Règlement intérieur et obligations des organismes de formation sollicitant des fonds publics

### Article L6352-3
- Identifiant : LEGIARTI000037386220
- État : en vigueur depuis le 01/01/2019
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000037386220
- Cité par : [art. R212-10-11 du Code du sport](../../../../../code-du-sport/partie-reglementaire-decrets/livre-ii/titre-ier/chapitre-ii.md#article-r212-10-11) ; [art. R212-10-20-1 du Code du sport](../../../../../code-du-sport/partie-reglementaire-decrets/livre-ii/titre-ier/chapitre-ii.md#article-r212-10-20-1) ; [art. L6352-4 du Code du travail](chapitre-ii.md#article-l6352-4) ; [art. R6316-1 du Code du travail](../../../../partie-reglementaire/sixieme-partie/livre-iii/titre-ier/chapitre-vi.md#article-r6316-1) ; [Décret n°2024-427 du 10 mai 2024](https://www.legifrance.gouv.fr/loda/id/LEGITEXT000049527964)

Tout organisme de formation établit un règlement intérieur applicable aux stagiaires et aux apprentis. Ce règlement constitue un document écrit qui détermine les principales mesures applicables en matière de santé, de sécurité dans l'établissement et de discipline ainsi que les modalités de représentation des stagiaires et apprentis.

### Article L6352-4
- Identifiant : LEGIARTI000054336971
- État : en vigueur depuis le 27/06/2026
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000054336971
- Renvoie à : [art. L6316-1 du Code du travail](../titre-ier/chapitre-vi.md#article-l6316-1) ; [art. L6352-3 du Code du travail](chapitre-ii.md#article-l6352-3)
- Cité par : [art. L6362-3 du Code du travail](../titre-vi/chapitre-ii.md#article-l6362-3) ; [art. R6352-9 du Code du travail](../../../../partie-reglementaire/sixieme-partie/livre-iii/titre-v/chapitre-ii.md#article-r6352-9) ; [art. L6355-9 du Code du travail](https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006904431)

Lorsqu'il sollicite des fonds auprès des financeurs mentionnés à l'article L. 6316-1, l'organisme de formation assure le traitement égal de tous les stagiaires et apprentis. Il veille au respect de la liberté d'expression et de conscience ainsi qu'à la neutralité des enseignements dispensés. Ces obligations sont inscrites dans le règlement intérieur mentionné à l'article L. 6352-3.

- Identifiant : LEGIARTI000006904403
- État : en vigueur depuis le 01/05/2008
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006904403

### Article L6352-7
- Identifiant : LEGIARTI000037386214
- État : en vigueur depuis le 01/01/2019
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000037386214

Les organismes de formation à activités multiples suivent d'une façon distincte en comptabilité l'activité exercée au titre d'une part, de la formation professionnelle continue et, d'autre part, de l'apprentissage.

### Article L6352-9
- Identifiant : LEGIARTI000006904406
- État : en vigueur depuis le 01/05/2008
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006904406
- Renvoie à : [art. L251-12 du Code de commerce](../../../../../code-de-commerce/partie-legislative/livre-ii/titre-v/chapitre-ier.md#article-l251-12)
- Cité par : [art. R6352-21 du Code du travail](../../../../partie-reglementaire/sixieme-partie/livre-iii/titre-v/chapitre-ii.md#article-r6352-21)

Le contrôle des comptes des dispensateurs de formation de droit privé constitués en groupement d'intérêt économique est exercé par un commissaire aux comptes, dans les conditions fixées par l'article L. 251-12 du code de commerce lorsque leur chiffre d'affaires annuel est supérieur à un montant déterminé par décret en Conseil d'Etat.

## Section 4 : Bilan pédagogique et financier.

### Article L6352-11
- Identifiant : LEGIARTI000037386206
- État : en vigueur depuis le 01/01/2019
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000037386206
- Renvoie à : [art. L6313-1 du Code du travail](../titre-ier/chapitre-iii.md#article-l6313-1)
- Cité par : [art. Annexe II-2-1 du Code du sport](../../../../../code-du-sport/annexes/annexes-partie-reglementaire-arretes/annexes-ii.md#article-annexe-ii-2-1) ; [art. L6323-9-1 du Code du travail](../titre-ii/chapitre-iii.md#article-l6323-9-1) ; [art. L6351-6 du Code du travail](chapitre-ier.md#article-l6351-6) ; [art. L6351-7-1 du Code du travail](chapitre-ier.md#article-l6351-7-1) ; [art. R6351-9 du Code du travail](../../../../partie-reglementaire/sixieme-partie/livre-iii/titre-v/chapitre-ier.md#article-r6351-9) ; [art. R6351-13 du Code du travail](../../../../partie-reglementaire/sixieme-partie/livre-iii/titre-v/chapitre-ier.md#article-r6351-13) ; [art. R6351-14 du Code du travail](../../../../partie-reglementaire/sixieme-partie/livre-iii/titre-v/chapitre-ier.md#article-r6351-14) ; [art. R6351-17 du Code du travail](../../../../partie-reglementaire/sixieme-partie/livre-iii/titre-v/chapitre-ier.md#article-r6351-17) ; [art. R6352-22 du Code du travail](../../../../partie-reglementaire/sixieme-partie/livre-iii/titre-v/chapitre-ii.md#article-r6352-22) ; [art. 202 A du Code général des impôts, annexe II](../../../../../code-general-des-impots-annexe-ii/livre-premier/premiere-partie/titre-ii/chapitre-premier.md#article-202-a) ; [Arrêté du 6 juin 2019, art. 1 bis](https://www.legifrance.gouv.fr/loda/article_lc/LEGIARTI000055045101)

Une personne qui réalise des actions entrant dans le champ de la formation professionnelle défini à l'article L. 6313-1 adresse chaque année à l'autorité administrative un document retraçant l'emploi des sommes reçues et dressant un bilan pédagogique et financier de leur activité.

Sur demande des inspections compétentes, le bilan, le compte de résultat et l'annexe du dernier exercice clos sont transmis par l'organisme de formation.

Un décret en Conseil d'Etat détermine les conditions d'application du présent article.

## Section 5 : Publicité.

### Article L6352-12
- Identifiant : LEGIARTI000006904409
- État : en vigueur depuis le 01/05/2008
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006904409

Lorsque la publicité réalisée par un organisme de formation fait mention de la déclaration d'activité, elle doit l'être sous la seule forme : "Enregistrée sous le numéro... Cet enregistrement ne vaut pas agrément de l'Etat."

### Article L6352-13
- Identifiant : LEGIARTI000054336997
- État : en vigueur depuis le 27/06/2026
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000054336997

La publicité réalisée par un organisme de formation ne doit comporter aucune mention de nature à induire en erreur sur :

1° Les conditions d'accès aux formations proposées ;  

2° Leur contenu ;  

3° Leurs modalités ;  

4° Leurs sanctions ;  

5° Leurs modalités de financement ;  

6° La situation de l'organisme au regard de l'habilitation accordée par le ministère ou l'organisme certificateur en vue de préparer à l'obtention d'une certification professionnelle, d'une certification ou d'une habilitation et d'évaluer les candidats inscrits aux sessions d'examen.
