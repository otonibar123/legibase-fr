# Chapitre Ier : Garanties.

Code du travail › Partie législative › Sixième partie : La formation professionnelle tout au long de la vie › Livre IV : Validation des acquis de l'expérience › Titre II : Mise en oeuvre de la validation des acquis de l'expérience

### Article L6421-1
- Identifiant : LEGIARTI000006904470
- État : en vigueur depuis le 01/05/2008
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006904470
- Cité par : [art. D6323-14-3-3 du Code du travail](../../../../partie-reglementaire/sixieme-partie/livre-iii/titre-ii/chapitre-iii.md#article-d6323-14-3-3) ; [art. R6422-12 du Code du travail](../../../../partie-reglementaire/sixieme-partie/livre-iv/titre-ii/chapitre-ii.md#article-r6422-12)

La validation des acquis de l'expérience ne peut être réalisée qu'avec le consentement du travailleur.

### Article L6421-2
- Identifiant : LEGIARTI000006904471
- État : en vigueur depuis le 01/05/2008
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006904471

Le refus d'un salarié de consentir à une action de validation des acquis de l'expérience ne constitue ni une faute ni un motif de licenciement.

### Article L6421-3
- Identifiant : LEGIARTI000006904472
- État : en vigueur depuis le 01/05/2008
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006904472
- Renvoie à : [art. L6411-1 du Code du travail](../titre-ier/chapitre-ier.md#article-l6411-1)
- Cité par : [art. R6412-7 du Code du travail](../../../../partie-reglementaire/sixieme-partie/livre-iv/titre-ier/chapitre-ii.md#article-r6412-7)

Les informations demandées au bénéficiaire d'une action de validation des acquis de l'expérience présentent un lien direct et nécessaire avec l'objet de la validation tel qu'il est défini à l'article L. 6411-1.

### Article L6421-4
- Identifiant : LEGIARTI000006904473
- État : en vigueur depuis le 01/05/2008
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006904473
- Renvoie à : [art. 226-13 du Code pénal](https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006417944)

Les personnes dépositaires d'informations communiquées par le candidat dans le cadre de sa demande de validation sont soumises aux dispositions des articles 226-13 et 226-14 du code pénal.
