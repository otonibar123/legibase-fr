# Chapitre IV : Pourboires.

Code du travail › Partie législative › Troisième partie : Durée du travail, salaire, intéressement, participation et épargne salariale › Livre II : Salaire et avantages divers › Titre IV : Paiement du salaire

### Article L3244-1
- Identifiant : LEGIARTI000006902867
- État : en vigueur depuis le 01/05/2008
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006902867
- Cité par : [art. L3244-2 du Code du travail](chapitre-iv.md#article-l3244-2) ; [art. R3246-3 du Code du travail](../../../../partie-reglementaire/troisieme-partie/livre-ii/titre-iv/chapitre-vi.md#article-r3246-3) ; [LOI n°2021-1900 du 30 décembre 2021, art. 5](https://www.legifrance.gouv.fr/loda/article_lc/LEGIARTI000053542657)

Dans tous les établissements commerciaux où existe la pratique du pourboire, toutes les perceptions faites " pour le service " par l'employeur sous forme de pourcentage obligatoirement ajouté aux notes des clients ou autrement, ainsi que toutes sommes remises volontairement par les clients pour le service entre les mains de l'employeur, ou centralisées par lui, sont intégralement versées au personnel en contact avec la clientèle et à qui celle-ci avait coutume de les remettre directement.

### Article L3244-2
- Identifiant : LEGIARTI000006902868
- État : en vigueur depuis le 01/05/2008
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006902868
- Renvoie à : [art. L3244-1 du Code du travail](chapitre-iv.md#article-l3244-1)
- Cité par : [art. R3246-3 du Code du travail](../../../../partie-reglementaire/troisieme-partie/livre-ii/titre-iv/chapitre-vi.md#article-r3246-3)

Les sommes mentionnées à l'article L. 3244-1 s'ajoutent au salaire fixe, sauf dans le cas où un salaire minimum a été garanti par l'employeur.
