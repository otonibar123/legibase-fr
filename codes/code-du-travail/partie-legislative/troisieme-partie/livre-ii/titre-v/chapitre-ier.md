# Chapitre Ier : Retenues.

Code du travail › Partie législative › Troisième partie : Durée du travail, salaire, intéressement, participation et épargne salariale › Livre II : Salaire et avantages divers › Titre V : Protection du salaire

### Article L3251-1
- Identifiant : LEGIARTI000006902873
- État : en vigueur depuis le 01/05/2008
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006902873
- Cité par : [art. L3251-2 du Code du travail](chapitre-ier.md#article-l3251-2) ; [art. R7421-2 du Code du travail](../../../../partie-reglementaire/septieme-partie/livre-iv/titre-ii/chapitre-ier.md#article-r7421-2) ; [art. L192-29 du Code minier (nouveau)](../../../../../code-minier-nouveau/partie-legislative/livre-ier/titre-ix/chapitre-ii.md#article-l192-29)

L'employeur ne peut opérer une retenue de salaire pour compenser des sommes qui lui seraient dues par un salarié pour fournitures diverses, quelle qu'en soit la nature.

### Article L3251-2
- Identifiant : LEGIARTI000006902874
- État : en vigueur depuis le 01/05/2008
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006902874
- Renvoie à : [art. L3251-1 du Code du travail](chapitre-ier.md#article-l3251-1)
- Cité par : [art. L3251-3 du Code du travail](chapitre-ier.md#article-l3251-3) ; [art. R7421-2 du Code du travail](../../../../partie-reglementaire/septieme-partie/livre-iv/titre-ii/chapitre-ier.md#article-r7421-2)

Par dérogation aux dispositions de l'article L. 3251-1, une compensation entre le montant des salaires et les sommes qui seraient dues à l'employeur peut être opérée dans les cas de fournitures suivants :  

1° Outils et instruments nécessaires au travail ;  

2° Matières ou matériaux dont le salarié a la charge et l'usage ;  

3° Sommes avancées pour l'acquisition de ces mêmes objets.

### Article L3251-3
- Identifiant : LEGIARTI000006902875
- État : en vigueur depuis le 01/05/2008
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006902875
- Renvoie à : [art. L3251-2 du Code du travail](chapitre-ier.md#article-l3251-2)
- Cité par : [art. L3348-1 du Code du travail](../../livre-iii/titre-iv/chapitre-viii.md#article-l3348-1) ; [Loi n°78-763 du 19 juillet 1978, art. 6](https://www.legifrance.gouv.fr/loda/article_lc/LEGIARTI000029321317)

En dehors des cas prévus au 3° de l'article L. 3251-2, l'employeur ne peut opérer de retenue de salaire pour les avances en espèces qu'il a faites, que s'il s'agit de retenues successives ne dépassant pas le dixième du montant des salaires exigibles.  

La retenue opérée à ce titre ne se confond pas avec la partie saisissable ou cessible.  

Les acomptes sur un travail en cours ne sont pas considérés comme des avances.

### Article L3251-4
- Identifiant : LEGIARTI000032043018
- État : en vigueur depuis le 01/10/2016
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000032043018
- Renvoie à : [art. 1240 du Code civil](../../../../../code-civil/livre-iii/titre-iii/sous-titre-ii/chapitre-ier.md#article-1240) ; [art. 1382 du Code civil](../../../../../code-civil/livre-iii/titre-iv-bis/chapitre-iii.md#article-1382)
- Cité par : [art. R3255-1 du Code du travail](../../../../partie-reglementaire/troisieme-partie/livre-ii/titre-v/chapitre-v.md#article-r3255-1)

Il est interdit à l'employeur, sous réserve des dispositions de l'article 1240 du code civil, d'imposer aux salariés des versements d'argent ou d'opérer des retenues d'argent sous la dénomination de frais ou sous toute autre dénomination pour quelque objet que ce soit, à l'occasion de l'exercice normal de leur travail dans les secteurs suivants :  

1° Hôtels, cafés, restaurants et établissements similaires ;  

2° Entreprises de spectacle, cercles et casinos ;  

3° Entreprises de transport.
