# Chapitre Ier : Champ d'application.

Code du travail › Partie législative › Troisième partie : Durée du travail, salaire, intéressement, participation et épargne salariale › Livre III : Dividende du travail : intéressement, participation et épargne salariale › Titre III : Plans d'épargne salariale

### Article L3331-1
- Identifiant : LEGIARTI000038613177
- État : en vigueur depuis le 24/05/2019
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000038613177
- Renvoie à : [art. L130-1 du Code de la sécurité sociale](https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000038498675)
- Cité par : [art. L3332-2 du Code du travail](chapitre-ii.md#article-l3332-2) ; [art. 82 du Code général des impôts, annexe 2](https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000020519331)

Les dispositions du présent titre sont applicables aux employeurs de droit privé ainsi qu'à leurs salariés.

Lorsque, dans le présent titre, il est fait référence à l'effectif salarié, cet effectif et le franchissement du seuil sont déterminés selon les modalités prévues à l'article L. 130-1 du code de la sécurité sociale.
