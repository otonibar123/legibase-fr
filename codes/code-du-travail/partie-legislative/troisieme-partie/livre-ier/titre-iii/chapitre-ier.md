## Section 2 : Champ de la négociation collective

### Article L3131-2
- Identifiant : LEGIARTI000033020914
- État : en vigueur depuis le 10/08/2016
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000033020914
- Renvoie à : [art. L3131-1 du Code du travail](chapitre-ier.md#article-l3131-1)
- Cité par : [art. D3131-4 du Code du travail](../../../../partie-reglementaire/troisieme-partie/livre-ier/titre-iii/chapitre-ier.md#article-d3131-4) ; [art. D3131-5 du Code du travail](../../../../partie-reglementaire/troisieme-partie/livre-ier/titre-iii/chapitre-ier.md#article-d3131-5) ; [art. L3131-1 du Code du travail](chapitre-ier.md#article-l3131-1) ; [art. R3135-1 du Code du travail](../../../../partie-reglementaire/troisieme-partie/livre-ier/titre-iii/chapitre-v.md#article-r3135-1) ; [art. L1321-4 du Code des transports](https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000023085564) ; [Décret n°2000-118 du 14 février 2000, art. 31](https://www.legifrance.gouv.fr/loda/article_lc/LEGIARTI000043395417)

Une convention ou un accord d'entreprise ou d'établissement ou, à défaut, une convention ou un accord de branche peut déroger à la durée minimale de repos quotidien prévue à l'article L. 3131-1, dans des conditions déterminées par décret, notamment pour des activités caractérisées par la nécessité d'assurer une continuité du service ou par des périodes d'intervention fractionnées.

### Article L3131-3
- Identifiant : LEGIARTI000033008114
- État : en vigueur depuis le 10/08/2016
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000033008114
