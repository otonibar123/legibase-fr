# Chapitre VI : Assurances de responsabilité civile relative à une opération spatiale

Code des assurances › Partie réglementaire › Livre Ier : Le contrat. › Titre VII : Les contrats d'assurances maritime, aérienne et aéronautique, fluviale et lacustre, sur marchandises transportées par tous modes et de responsabilité civile spatiale

### Article R176-1
- Identifiant : LEGIARTI000026149685
- État : en vigueur depuis le 07/07/2012
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000026149685
- Renvoie à : [art. R175-1 du Code des assurances](chapitre-v.md#article-r175-1)

Les contrats d'assurance ayant pour objet de garantir la responsabilité civile relative à une opération spatiale sont régis par les dispositions des articles R. 175-1 à R. 175-5.
