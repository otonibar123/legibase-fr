# Titre VII : Dispositions applicables dans les îles Wallis et Futuna

Code des assurances › Partie législative › Livre II : Assurances obligatoires

### Article L271-1
- Identifiant : LEGIARTI000017868407
- État : en vigueur depuis le 23/12/2007
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000017868407
- Renvoie à : [art. L211-26 du Code des assurances](titre-ier/chapitre-ier.md#article-l211-26) ; [art. L212-1 du Code des assurances](titre-ier/chapitre-ii.md#article-l212-1) ; [Loi n°91-716 du 26 juillet 1991](https://www.legifrance.gouv.fr/loda/id/JORFTEXT000000355163)

Le troisième alinéa de l'article L. 211-26, les articles L. 212-1 à L. 212-3 sont applicables dans les îles Wallis et Futuna dans leur rédaction en vigueur lors de la promulgation de la loi n° 91-716 du 26 juillet 1991 précitée.
