### Article L151-2
- Identifiant : LEGIARTI000006524459
- État : en vigueur depuis le 22/06/2000
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006524459
- Renvoie à : [art. L442-6 du Code de l'éducation](../../../deuxieme-partie/livre-iv/titre-iv/chapitre-ii.md#article-l442-6)

Les collectivités territoriales de la République concourent à la liberté de l'enseignement dans les conditions prévues par les articles L. 442-6 et L. 442-7.

### Article L151-3
- Identifiant : LEGIARTI000006524460
- État : en vigueur depuis le 22/06/2000
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006524460
- Cité par : [art. L161-1 du Code de l'éducation](../titre-vi/chapitre-ier.md#article-l161-1) ; [art. L161-2 du Code de l'éducation](../titre-vi/chapitre-ier.md#article-l161-2) ; [art. L163-1 du Code de l'éducation](../titre-vi/chapitre-iii.md#article-l163-1) ; [art. L163-2 du Code de l'éducation](../titre-vi/chapitre-iii.md#article-l163-2) ; [art. L164-1 du Code de l'éducation](../titre-vi/chapitre-iv.md#article-l164-1) ; [art. L164-2 du Code de l'éducation](../titre-vi/chapitre-iv.md#article-l164-2)

Les établissements d'enseignement du premier et du second degré peuvent être publics ou privés.  

Les établissements publics sont fondés et entretenus par l'Etat, les régions, les départements ou les communes.  

Les établissements privés sont fondés et entretenus par des particuliers ou des associations.

### Article L151-4
- Identifiant : LEGIARTI000006524461
- État : en vigueur depuis le 22/06/2000
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006524461
- Cité par : [art. L234-6 du Code de l'éducation](../../livre-ii/titre-iii/chapitre-iv.md#article-l234-6)

Les établissements d'enseignement général du second degré privés peuvent obtenir des communes, des départements, des régions ou de l'Etat des locaux et une subvention, sans que cette subvention puisse excéder le dixième des dépenses annuelles de l'établissement. Le conseil académique de l'éducation nationale donne son avis préalable sur l'opportunité de ces subventions.

### Article L151-5
- Identifiant : LEGIARTI000006524462
- État : en vigueur depuis le 22/06/2000
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006524462

Les établissements d'enseignement technique sont publics ou privés.
