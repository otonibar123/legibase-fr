# Chapitre II : La gratuité de l'enseignement scolaire public.

Code de l'éducation › Partie législative › Première partie : Dispositions générales et communes › Livre Ier : Principes généraux de l'éducation › Titre III : L'obligation scolaire, la gratuité et l'accueil des élèves des écoles maternelles et élémentaires

### Article L132-1
- Identifiant : LEGIARTI000038901897
- État : en vigueur depuis le 02/09/2019
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000038901897
- Renvoie à : [art. L131-1 du Code de l'éducation](chapitre-ier.md#article-l131-1)
- Cité par : [art. L161-1 du Code de l'éducation](../titre-vi/chapitre-ier.md#article-l161-1) ; [art. L162-1 du Code de l'éducation](../titre-vi/chapitre-ii.md#article-l162-1) ; [art. L163-1 du Code de l'éducation](../titre-vi/chapitre-iii.md#article-l163-1) ; [art. L164-1 du Code de l'éducation](../titre-vi/chapitre-iv.md#article-l164-1) ; [art. R426-2 du Code de l'éducation](../../../../partie-reglementaire/livre-iv/titre-ii/chapitre-vi.md#article-r426-2)

L'enseignement public dispensé dans les écoles maternelles et élémentaires est gratuit.

> Nota : Conformément aux dispositions de l'article 63 de la loi n° 2019-791 du 26 juillet 2019, ces dispositions entrent en vigueur à la rentrée scolaire 2019.

### Article L132-2
- Identifiant : LEGIARTI000006524449
- État : en vigueur depuis le 22/06/2000
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006524449
- Cité par : [art. L163-1 du Code de l'éducation](../titre-vi/chapitre-iii.md#article-l163-1) ; [art. L164-1 du Code de l'éducation](../titre-vi/chapitre-iv.md#article-l164-1)

L'enseignement est gratuit pour les élèves des lycées et collèges publics qui donnent l'enseignement du second degré, ainsi que pour les élèves des classes préparatoires aux grandes écoles et à l'enseignement supérieur des établissements d'enseignement public du second degré.
