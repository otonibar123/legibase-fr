# Chapitre Ier : Dispositions communes.

Code de l'éducation › Partie législative › Troisième partie : Les enseignements supérieurs et la recherche › Livre VI : L'organisation des enseignements supérieurs et de la recherche › Titre IV : Les formations technologiques

### Article L641-1
- Identifiant : LEGIARTI000006525270
- État : en vigueur depuis le 22/06/2000
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006525270
- Cité par : [art. L681-1 du Code de l'éducation](../titre-viii/chapitre-ier.md#article-l681-1) ; [art. L683-1 du Code de l'éducation](../titre-viii/chapitre-iii.md#article-l683-1) ; [art. L684-1 du Code de l'éducation](../titre-viii/chapitre-iv.md#article-l684-1)

Au plus haut niveau de l'enseignement et de la recherche, les disciplines technologiques sont consacrées par des diplômes délivrés dans le cadre du présent livre.

### Article L641-2
- Identifiant : LEGIARTI000046774846
- État : en vigueur depuis le 23/12/2022
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000046774846
- Renvoie à : [art. L335-5 du Code de l'éducation](../../../deuxieme-partie/livre-iii/titre-iii/chapitre-v.md#article-l335-5) ; [art. L6113-1 du Code du travail](../../../../../code-du-travail/partie-legislative/sixieme-partie/livre-ier/titre-ier/chapitre-iii.md#article-l6113-1)
- Cité par : [art. R352-8 du Code général de la fonction publique](../../../../../code-general-de-la-fonction-publique/partie-reglementaire/livre-iii/titre-v/chapitre-ii.md#article-r352-8)

Les dispositions du I de l'article L. 335-5 et celles de l'article L. 6113-1 du code du travail sont applicables aux formations technologiques supérieures.

### Article L641-3
- Identifiant : LEGIARTI000006525273
- État : en vigueur depuis le 22/06/2000
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006525273
- Renvoie à : [art. L335-13 du Code de l'éducation](../../../deuxieme-partie/livre-iii/titre-iii/chapitre-v.md#article-l335-13)
- Cité par : [art. D612-32-2 du Code de l'éducation](../../../../partie-reglementaire/livre-vi/titre-ier/chapitre-ii-bis.md#article-d612-32-2) ; [art. D612-34 du Code de l'éducation](../../../../partie-reglementaire/livre-vi/titre-ier/chapitre-ii-bis.md#article-d612-34) ; [Décret n°2021-405 du 7 avril 2021](https://www.legifrance.gouv.fr/loda/id/LEGITEXT000043340092)

Les écoles techniques autorisées à délivrer le diplôme d'ingénieur, les écoles supérieures de commerce et les écoles techniques privées reconnues de même niveau par décision du ministre chargé de l'enseignement supérieur ne sont pas soumises aux dispositions des articles L. 335-13 à L. 335-16.
