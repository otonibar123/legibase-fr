# Chapitre VI : Les autres formations de santé.

Code de l'éducation › Partie législative › Troisième partie : Les enseignements supérieurs et la recherche › Livre VI : L'organisation des enseignements supérieurs et de la recherche › Titre III : Les formations de santé

### Article L636-1
- Identifiant : LEGIARTI000029258990
- État : en vigueur depuis le 19/07/2014
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000029258990

Les études supérieures préparant aux autres professions de santé sont organisées conformément aux dispositions prévues par le code de la santé publique et par le présent code.
