# Chapitre VIII : L'enseignement à l'Ecole nationale de l'aviation civile

Code de l'éducation › Partie réglementaire › Livre VI : L'organisation des enseignements supérieurs › Titre VII : Les formations dans les autres établissements d'enseignement supérieur

### Article D678-1
- Identifiant : LEGIARTI000031200378
- État : en vigueur depuis le 24/09/2015
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000031200378
- Renvoie à : [art. D612-32-2 du Code de l'éducation](../titre-ier/chapitre-ii-bis.md#article-d612-32-2)

Le diplôme d'élève pilote de ligne délivré par l'Ecole nationale de l'aviation civile et mentionné au 7° de l'article D. 612-32-2 fait l'objet d'une évaluation nationale périodique.
