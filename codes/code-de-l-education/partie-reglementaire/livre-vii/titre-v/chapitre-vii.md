# Chapitre VII : L'Ecole nationale supérieure maritime

Code de l'éducation › Partie réglementaire › Livre VII : Les établissements d'enseignement supérieur › Titre V : Les établissements d'enseignement supérieur spécialisés

### Article D757-1
- Identifiant : LEGIARTI000027867341
- État : en vigueur depuis le 21/08/2013
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000027867341
- Renvoie à : [art. D717-6 du Code de l'éducation](../titre-ier/chapitre-vii.md#article-d717-6)

L'Ecole nationale supérieure maritime est un établissement public à caractère scientifique, culturel et professionnel, constitué sous la forme d'un grand établissement, mentionné à l'article D. 717-6.
