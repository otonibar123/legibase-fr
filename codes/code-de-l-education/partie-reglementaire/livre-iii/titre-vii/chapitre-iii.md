# Chapitre III : Saint-Martin

Code de l'éducation › Partie réglementaire › Livre III : L'organisation des enseignements scolaires. › Titre VII : Dispositions relatives à l'outre-mer

### Article R373-1
- Identifiant : LEGIARTI000045001236
- État : en vigueur depuis le 01/01/2022
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000045001236
- Renvoie à : [art. R334-35 du Code de l'éducation](../titre-iii/chapitre-iv.md#article-r334-35) ; [art. R337-15 du Code de l'éducation](../titre-iii/chapitre-vii.md#article-r337-15) ; [art. R337-112 du Code de l'éducation](../titre-iii/chapitre-vii.md#article-r337-112)

Les dispositions du présent livre s'appliquent de plein droit à Saint-Martin sous réserve des adaptations prévues au présent chapitre.

### Article D373-2
- Identifiant : LEGIARTI000045041309
- État : en vigueur depuis le 01/01/2022
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000045041309
- Renvoie à : [art. D332-16 du Code de l'éducation](../titre-iii/chapitre-ii.md#article-d332-16) ; [art. D334-1 du Code de l'éducation](../titre-iii/chapitre-iv.md#article-d334-1) ; [art. D337-1 du Code de l'éducation](../titre-iii/chapitre-vii.md#article-d337-1) ; [art. D338-43 du Code de l'éducation](../titre-iii/chapitre-viii.md#article-d338-43)
- Cité par : [Décret n°2020-671 du 3 juin 2020, art. 1](https://www.legifrance.gouv.fr/loda/article_lc/LEGIARTI000041953465)

A moins qu'il en soit disposé autrement, la référence au directeur académique des services de l'éducation nationale est remplacée, à Saint-Martin, par la référence au vice-recteur, chef du service de l'éducation nationale de Saint-Barthélemy et de Saint-Martin.

### Article D373-3
- Identifiant : LEGIARTI000045012776
- État : en vigueur depuis le 01/01/2022
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000045012776

Pour l'application à Saint-Martin de l'article D. 332-19, les premier et deuxième alinéas sont remplacés par l'alinéa suivant :  

" Le diplôme national du brevet est attribué par un jury présidé par le recteur de la région académique de Guadeloupe. "

### Article D373-4
- Identifiant : LEGIARTI000045012778
- État : en vigueur depuis le 01/01/2022
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000045012778

Pour l'application à Saint-Martin des articles D. 332-25 et D. 332-26, les mots : " le recteur d'académie " sont remplacés par les mots : " le recteur de la région académique de Guadeloupe ".
