# Chapitre III : Infractions aux règles de défrichement

Code forestier (nouveau) › Partie réglementaire › LIVRE III : BOIS ET FORÊTS DES PARTICULIERS › TITRE VI : DISPOSITIONS PÉNALES

### Article R363-1
- Identifiant : LEGIARTI000026129437
- État : en vigueur depuis le 01/07/2012
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000026129437
- Renvoie à : [art. L341-4 du Code forestier (nouveau)](../../../partie-legislative/livre-iii/titre-iv/chapitre-ier.md#article-l341-4)

Le fait pour le demandeur de ne pas procéder, dans les conditions prévues à l'article L. 341-4, à l'affichage régulier, sur le terrain, de l'autorisation de défrichement est puni de l'amende prévue pour les contraventions de la 3e classe.
