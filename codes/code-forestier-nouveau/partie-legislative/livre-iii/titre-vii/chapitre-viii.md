# Chapitre VIII : Saint-Pierre-et-Miquelon

Code forestier (nouveau) › Partie législative › LIVRE III : BOIS ET FORÊTS DES PARTICULIERS › TITRE VII : DISPOSITIONS PARTICULIÈRES À L'OUTRE-MER

### Article L378-1
- Identifiant : LEGIARTI000025247512
- État : en vigueur depuis le 01/07/2012
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000025247512
- Renvoie à : [art. L362-2 du Code forestier (nouveau)](../titre-vi/chapitre-ii.md#article-l362-2) ; [art. L362-3 du Code forestier (nouveau)](../titre-vi/chapitre-ii.md#article-l362-3)

Ne sont pas applicables à Saint-Pierre-et-Miquelon :

1° Les dispositions du chapitre II du titre Ier ;

2° Les dispositions du chapitre Ier du titre II ;

3° L'article L. 362-2.

Les dispositions de l'article L. 362-3 ne sont applicables qu'en ce qui concerne les infractions aux dispositions de l'article L. 362-1.
