## Section 1 : Obstacle à fonctions

### Article L163-1
- Identifiant : LEGIARTI000025246299
- État : en vigueur depuis le 01/07/2012
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000025246299
- Renvoie à : [art. L161-4 du Code forestier (nouveau)](chapitre-ier.md#article-l161-4) ; [art. 131-35 du Code pénal](../../../../code-penal/partie-legislative/livre-ier/titre-iii/chapitre-ier.md#article-131-35) ; [art. 131-39 du Code pénal](../../../../code-penal/partie-legislative/livre-ier/titre-iii/chapitre-ier.md#article-131-39)

L161-25 du Code forestier (nouveau)](https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000052848494) ; [LOI n° 2014-1170 du 13 octobre 2014, art. 76](https://www.legifrance.gouv.fr/loda/article_lc/LEGIARTI000029575247)

Le fait de faire obstacle ou d'entraver l'exercice des fonctions des agents mentionnés aux articles L. 161-4 et L. 161-5 est puni de six mois d'emprisonnement et de 15 000 euros d'amende.

Les personnes coupables de cette infraction encourent également la peine complémentaire de l'affichage ou de la diffusion de la décision prononcée, dans les conditions prévues par l'article 131-35 du code pénal pour les personnes physiques et par le 9° de l'article 131-39 du même code pour les personnes morales.

## Section 2 : Infractions relatives aux coupes

### Article L163-2
- Identifiant : LEGIARTI000025246304
- État : en vigueur depuis le 01/07/2012
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000025246304
- Renvoie à : [art. L124-6 du Code forestier (nouveau)](../titre-ii/chapitre-iv.md#article-l124-6)

Le fait, pour les propriétaires, de ne pas respecter les dispositions prévues à l'article L. 124-6 est puni d'une amende de 1 200 euros par hectare exploité.

Est passible de l'amende prévue à l'alinéa précédent le vendeur mentionné au dernier alinéa de cet article qui entrave, par son refus sans fondement légitime, l'exécution dans le délai fixé des travaux de reconstitution.

## Section 3 : Défense des forêts contre l'incendie

### Article L163-3
- Identifiant : LEGIARTI000025246308
- État : en vigueur depuis le 01/07/2012
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000025246308
- Cité par : [art. R174-11 du Code forestier (nouveau)](../../../partie-reglementaire/livre-ier/titre-vii/chapitre-iv.md#article-r174-11)

Le fait de provoquer volontairement un incendie dans les bois et forêts est réprimé dans les conditions prévues par le code pénal.

### Article L163-4
- Identifiant : LEGIARTI000047810905
- État : en vigueur depuis le 12/07/2023
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000047810905
- Renvoie à : [art. L3512-1 du Code de la santé publique](../../../../code-de-la-sante-publique/partie-legislative/troisieme-partie/livre-v/titre-ier/chapitre-ii.md#article-l3512-1) ; [art. L3514-1 du Code de la santé publique](../../../../code-de-la-sante-publique/partie-legislative/troisieme-partie/livre-v/titre-ier/chapitre-iv.md#article-l3514-1) ; [art. 322-5 du Code pénal](../../../../code-penal/partie-legislative/livre-iii/titre-ii/chapitre-ii.md#article-322-5) ; [art. 322-17 du Code pénal](../../../../code-penal/partie-legislative/livre-iii/titre-ii/chapitre-ii.md#article-322-17) ; [art. 322-18 du Code pénal](../../../../code-penal/partie-legislative/livre-iii/titre-ii/chapitre-ii.md#article-322-18)
- Cité par : [art. L122-8 du Code des assurances](../../../../code-des-assurances/partie-legislative/livre-ier/titre-ii/chapitre-ii.md#article-l122-8)

Le fait de provoquer involontairement l'incendie des bois et forêts appartenant à autrui, par des feux allumés à moins de 200 mètres de ces terrains, par des feux allumés ou laissés sans précautions suffisantes, par des pièces d'artifice allumées ou tirées, par l'abandon de déchets issus de produits à fumer définis aux articles L. 3512-1 et L. 3514-1 du code de la santé publique ou par tout engin ou appareil générant des matières inflammables ou de fortes chaleurs, est sanctionné conformément aux dispositions des articles 322-5, 322-15, 322-17 et 322-18 du code pénal.

Le fait, pour la personne qui vient de causer un incendie dans les conditions mentionnées au présent article, de ne pas intervenir aussitôt pour arrêter le sinistre et, si son action était insuffisante, de ne pas avertir immédiatement une autorité administrative ou de police, entraîne l'application du deuxième alinéa de l'article 322-5 du code pénal.

Le tribunal peut, en outre, ordonner, aux frais du condamné, la publication intégrale ou par extraits de sa décision ou la diffusion d'un message dont il fixe explicitement les termes, informant le public des motifs et du contenu de sa décision, dans un ou plusieurs journaux qu'il désigne.

## Section 4 : Infractions commises en forêt d'autrui

### Article L163-7
- Identifiant : LEGIARTI000025246322
- État : en vigueur depuis le 01/07/2012
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000025246322
- Renvoie à : [art. 311-3 du Code pénal](../../../../code-penal/partie-legislative/livre-iii/titre-ier/chapitre-ier.md#article-311-3) ; [art. 311-13 du Code pénal](../../../../code-penal/partie-legislative/livre-iii/titre-ier/chapitre-ier.md#article-311-13) ; [art. 311-16 du Code pénal](../../../../code-penal/partie-legislative/livre-iii/titre-ier/chapitre-ier.md#article-311-16)
- Cité par : [art. L172-5 du Code forestier (nouveau)](../titre-vii/chapitre-ii.md#article-l172-5) ; [art. L261-5 du Code forestier (nouveau)](../../livre-ii/titre-vi/chapitre-ier.md#article-l261-5) ; [art. R171-2 du Code forestier (nouveau)](../../../partie-reglementaire/livre-ier/titre-vii/chapitre-ier.md#article-r171-2) ; [art. R173-3 du Code forestier (nouveau)](../../../partie-reglementaire/livre-ier/titre-vii/chapitre-iii.md#article-r173-3) ; [art. R176-2 du Code forestier (nouveau)](../../../partie-reglementaire/livre-ier/titre-vii/chapitre-vi.md#article-r176-2) ; [art. R177-2 du Code forestier (nouveau)](../../../partie-reglementaire/livre-ier/titre-vii/chapitre-vii.md#article-r177-2)

La coupe ou l'enlèvement d'arbres ayant au moins 20 centimètres de circonférence est puni conformément aux dispositions des articles 311-3, 311-4, 311-13, 311-14 et 311-16 du code pénal.

La circonférence est mesurée à 1,30 mètre du sol. Si les arbres ont été enlevés et façonnés, elle est mesurée sur la souche. Si la souche a été également enlevée, la circonférence est calculée dans la proportion d'un cinquième en sus de la dimension totale des quatre faces de l'arbre équarri. Lorsque l'arbre et la souche ont disparu, la grosseur de l'arbre est appréciée par le juge.

Le fait d'enlever des chablis et des bois coupés illégalement est puni des mêmes peines que l'abattage sur pied.

### Article L163-8
- Identifiant : LEGIARTI000025246325
- État : en vigueur depuis le 01/07/2012
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000025246325
- Cité par : [art. L172-6 du Code forestier (nouveau)](../titre-vii/chapitre-ii.md#article-l172-6) ; [art. L175-15 du Code forestier (nouveau)](../titre-vii/chapitre-v.md#article-l175-15)

Le fait d'avoir, dans les bois et forêts, éhoupé, écorcé ou mutilé des arbres, ou d'en avoir coupé les principales branches, ou d'avoir enlevé de l'écorce de liège, est puni comme l'abattage sur pied.

### Article L163-10
- Identifiant : LEGIARTI000025246329
- État : en vigueur depuis le 01/07/2012
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000025246329

- Cité par : [art. L174-13 du Code forestier (nouveau)](../titre-vii/chapitre-iv.md#article-l174-13) ; [art. R261-8 du Code forestier (nouveau)](../../../partie-reglementaire/livre-ii/titre-vi/chapitre-ier.md#article-r261-8)

Le fait, sans l'autorisation du propriétaire du terrain, de procéder à l'extraction ou l'enlèvement d'un volume supérieur à 2 mètres cubes de pierres, sable, minerai, terre, gazon ou mousses, tourbe, bruyère, genêts, herbes, feuilles vertes ou mortes, engrais est puni conformément aux dispositions des articles 311-3, 311-4, 311-13, 311-14 et 311-16 du code pénal.

### Article L163-11
- Identifiant : LEGIARTI000025246332
- État : en vigueur depuis le 01/07/2012
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000025246332

Le fait, sans l'autorisation du propriétaire du terrain, de prélever des truffes, quelle qu'en soit la quantité, ou un volume supérieur à 10 litres d'autres champignons, fruits ou semences des bois et forêts est puni conformément aux dispositions des articles 311-3, 311-4, 311-13, 311-14 et 311-16 du code pénal.

## Section 5 : Rôle de protection des forêts

- Identifiant : LEGIARTI000025246337
- État : en vigueur depuis le 01/07/2012

## Section 8 : Qualification professionnelle

### Article L163-18
- Identifiant : LEGIARTI000025246363

- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000025246363
