# Chapitre II : Dispositions relatives aux peines

Code forestier (nouveau) › Partie législative › LIVRE Ier : DISPOSITIONS COMMUNES À TOUS LES BOIS ET FORÊTS › TITRE VI : DISPOSITIONS PÉNALES

### Article L162-1
- Identifiant : LEGIARTI000025246283
- État : en vigueur depuis le 01/07/2012
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000025246283
- Cité par : [art. R162-3 du Code forestier (nouveau)](../../../partie-reglementaire/livre-ier/titre-vi/chapitre-ii.md#article-r162-3)

Les peines encourues sont doublées lorsque les infractions sont commises la nuit.

### Article L162-2
- Identifiant : LEGIARTI000025246285
- État : en vigueur depuis le 01/07/2012
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000025246285
- Renvoie à : [art. 132-66 du Code pénal](../../../../code-penal/partie-legislative/livre-ier/titre-iii/chapitre-ii.md#article-132-66)
- Cité par : [art. L122-8 du Code des assurances](../../../../code-des-assurances/partie-legislative/livre-ier/titre-ii/chapitre-ii.md#article-l122-8)

Le tribunal peut ajourner le prononcé de la peine dans les conditions prévues aux articles 132-66 à 132-70 du code pénal.

### Article L162-4
- Identifiant : LEGIARTI000025246292
- État : en vigueur depuis le 01/07/2012
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000025246292
- Renvoie à : [art. 131-8-1 du Code pénal](../../../../code-penal/partie-legislative/livre-ier/titre-iii/chapitre-ier.md#article-131-8-1) ; [art. 131-15-1 du Code pénal](../../../../code-penal/partie-legislative/livre-ier/titre-iii/chapitre-ier.md#article-131-15-1) ; [art. 131-39-1 du Code pénal](../../../../code-penal/partie-legislative/livre-ier/titre-iii/chapitre-ier.md#article-131-39-1) ; [art. 131-44-1 du Code pénal](../../../../code-penal/partie-legislative/livre-ier/titre-iii/chapitre-ier.md#article-131-44-1)

Les dispositions des articles 131-8-1, 131-15-1, 131-39-1 et 131-44-1 du code pénal relatives à la peine de sanction-réparation sont applicables aux délits prévus par le présent code ainsi qu'aux contraventions forestières de la 5e classe.

Le procureur de la République délègue le directeur régional de l'administration chargée des forêts pour constater l'exécution de la réparation.
