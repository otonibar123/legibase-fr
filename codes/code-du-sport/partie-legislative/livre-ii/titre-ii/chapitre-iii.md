# Chapitre III : Autres dispositions applicables aux sportifs

Code du sport › Partie législative › LIVRE II : ACTEURS DU SPORT › TITRE II : SPORTIFS

### Article L223-1
- Identifiant : LEGIARTI000006547607
- État : en vigueur depuis le 24/10/2006
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006547607
- Renvoie à : [art. L131-14 du Code du sport](../../livre-ier/titre-iii/chapitre-ier.md#article-l131-14)
- Cité par : [art. L212-13 du Code du sport](../titre-ier/chapitre-ii.md#article-l212-13) ; [art. 92 du Code général des impôts](../../../../code-general-des-impots/livre-premier/premiere-partie/titre-premier/chapitre-premier.md#article-92) ; [art. L311-3 du Code de la sécurité sociale](https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000053151645) ; [art. L212-9 du Code du sport](https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000052851060)

Les arbitres et juges exercent leur mission arbitrale en toute indépendance et impartialité, dans le respect des règlements édictés par la fédération sportive mentionnée à l'article L. 131-14, compétente pour la discipline et auprès de laquelle ils sont licenciés. Cette fédération assure le contrôle de l'exercice de cette mission selon les règles et procédures préalablement définies conformément à ses statuts.

### Article L223-2
- Identifiant : LEGIARTI000006547608
- État : en vigueur depuis le 24/10/2006
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006547608
- Renvoie à : [art. 221-4 du Code pénal](../../../../code-penal/partie-legislative/livre-ii/titre-ii/chapitre-ier.md#article-221-4) ; [art. 222-3 du Code pénal](../../../../code-penal/partie-legislative/livre-ii/titre-ii/chapitre-ii.md#article-222-3) ; [art. 222-8 du Code pénal](../../../../code-penal/partie-legislative/livre-ii/titre-ii/chapitre-ii.md#article-222-8) ; [art. 222-10 du Code pénal](../../../../code-penal/partie-legislative/livre-ii/titre-ii/chapitre-ii.md#article-222-10) ; [art. 222-12 du Code pénal](../../../../code-penal/partie-legislative/livre-ii/titre-ii/chapitre-ii.md#article-222-12) ; [art. 222-13 du Code pénal](../../../../code-penal/partie-legislative/livre-ii/titre-ii/chapitre-ii.md#article-222-13) ; [art. 433-3 du Code pénal](../../../../code-penal/partie-legislative/livre-iv/titre-iii/chapitre-iii.md#article-433-3)

Les arbitres et juges sont considérés comme chargés d'une mission de service public au sens des articles 221-4, 222-3, 222-8, 222-10, 222-12, 222-13 et 433-3 du code pénal et les atteintes dont ils peuvent être les victimes dans l'exercice ou à l'occasion de l'exercice de leur mission sont réprimées par les peines aggravées prévues par ces articles.

### Article L223-3
- Identifiant : LEGIARTI000034117176
- État : en vigueur depuis le 03/03/2017
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000034117176
- Renvoie à : [art. L222-2-2 du Code du sport](chapitre-ii.md#article-l222-2-2) ; [art. L1221-1 du Code du travail](../../../../code-du-travail/partie-legislative/premiere-partie/livre-ii/titre-ii/chapitre-ier.md#article-l1221-1) ; [art. L1221-3 du Code du travail](../../../../code-du-travail/partie-legislative/premiere-partie/livre-ii/titre-ii/chapitre-ier.md#article-l1221-3)

Sauf dans le cas prévu au second alinéa de l'article L. 222-2-2 du présent code, les arbitres et juges ne peuvent être regardés, dans l'accomplissement de leur mission, comme liés à la fédération par un lien de subordination caractéristique du contrat de travail au sens des articles L. 1221-1 et L. 1221-3 du code du travail.
