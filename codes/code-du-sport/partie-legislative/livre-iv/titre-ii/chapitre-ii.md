# Chapitre II : Dispositions particulières à Saint-Pierre-et-Miquelon

Code du sport › Partie législative › LIVRE IV : DISPOSITIONS DIVERSES › TITRE II : DISPOSITIONS APPLICABLES À L'OUTRE-MER

### Article L422-1
- Identifiant : LEGIARTI000006547765
- État : en vigueur depuis le 25/05/2006
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006547765
- Renvoie à : [art. L333-5 du Code du sport](../../livre-iii/titre-iii/chapitre-iii.md#article-l333-5)

Les articles L. 112-1, L. 112-2 et L. 333-5 du présent code ne sont pas applicables à Saint-Pierre-et-Miquelon.

### Article L422-2
- Identifiant : LEGIARTI000006547766
- État : en vigueur depuis le 25/05/2006
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006547766

Les références à des dispositions non applicables dans la collectivité sont remplacées par les références aux dispositions ayant le même objet qui y sont applicables.

### Article L422-3
- Identifiant : LEGIARTI000006547767
- État : en vigueur depuis le 25/05/2006
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006547767

Pour l'application du présent code à Saint-Pierre-et-Miquelon, le mot "département" est remplacé par le mot : "collectivité".
