# Chapitre II : Dispositions relatives à Saint-Pierre-et-Miquelon.

Code du tourisme › Partie réglementaire › LIVRE Ier : ORGANISATION GÉNÉRALE DU TOURISME. › TITRE VI : DISPOSITIONS PARTICULIÈRES À CERTAINES COLLECTIVITÉS D'OUTRE-MER.

### Article R162-1
- Identifiant : LEGIARTI000006812789
- État : en vigueur depuis le 07/10/2006
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006812789

Pour l'application du présent livre :

1° Les mots : " région " ou " département " sont remplacés par les mots : " collectivité territoriale " ;

2° Les mots : " préfet de région " ou " préfet de département " sont remplacés par le mot : " préfet ".

### Article R162-2
- Identifiant : LEGIARTI000021581644
- État : en vigueur depuis le 28/12/2009
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000021581644
- Cité par : [art. R242-2 du Code du tourisme](../../livre-ii/titre-iv/chapitre-ii.md#article-r242-2) ; [art. R362-3 du Code du tourisme](../../livre-iii/titre-vi/chapitre-ii.md#article-r362-3)

Les références faites, par des dispositions du présent livre applicables à Saint-Pierre-et-Miquelon, à des dispositions qui n'y sont pas applicables sont remplacées par les références aux dispositions ayant le même objet applicables localement.
