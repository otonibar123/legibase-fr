### Article L421-3
- Identifiant : LEGIARTI000006813631
- État : en vigueur depuis le 15/04/2006
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006813631
- Renvoie à : [art. 199 decies E du Code général des impôts](../../../../code-general-des-impots/livre-premier/premiere-partie/titre-premier/chapitre-premier.md#article-199-decies-e) ; [art. 199 decies G du Code général des impôts](../../../../code-general-des-impots/livre-premier/premiere-partie/titre-premier/chapitre-premier.md#article-199-decies-g)
- Cité par : [art. D421-2 du Code du tourisme](../../../partie-reglementaire/livre-iv/titre-ii/chapitre-ier.md#article-d421-2)

Les règles applicables aux réductions d'impôt accordées au titre de l'acquisition et, le cas échéant, de la réhabilitation de certains logements faisant partie d'une résidence de tourisme classée sont fixées par les articles 199 decies E, 199 decies EA et 199 decies G du code général des impôts.

### Article L421-3-1
- Identifiant : LEGIARTI000006813632
- État : en vigueur depuis le 15/04/2006
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006813632
- Renvoie à : [art. 199 decies F du Code général des impôts](https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006303245)
- Cité par : [art. D421-3 du Code du tourisme](../../../partie-reglementaire/livre-iv/titre-ii/chapitre-ier.md#article-d421-3)

Les règles applicables aux réductions d'impôt accordées au titre des travaux réalisés dans certains logements faisant partie d'une résidence de tourisme classée ou d'un village résidentiel de tourisme classé ou destinés à la location en qualité de meublés de tourisme sont fixées par l'article 199 decies F du code général des impôts.
