# Chapitre VI : Règles particulières à la passation de certains contrats de concession

Code de la commande publique › Partie législative › TROISIÈME PARTIE : CONCESSIONS › Livre Ier : DISPOSITIONS GÉNÉRALES › Titre II : PROCÉDURE DE PASSATION

### Article L3126-1
- Identifiant : LEGIARTI000037704997
- État : en vigueur depuis le 01/04/2019
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000037704997
- Cité par : [art. Annexe préliminaire du Code de la commande publique](../../../../annexe.md#article-annexe-préliminaire) ; [art. L3126-2 du Code de la commande publique](chapitre-vi.md#article-l3126-2)

Les règles de passation particulières à certains contrats à raison de leur objet ou selon que leur valeur estimée hors taxe est inférieure ou non au seuil européen qui figure dans l'avis annexé au présent code sont fixées par décret en Conseil d'Etat.

### Article L3126-2
- Identifiant : LEGIARTI000037704999
- État : en vigueur depuis le 01/04/2019
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000037704999
- Renvoie à : [art. L3122-2 du Code de la commande publique](chapitre-ii.md#article-l3122-2) ; [art. L3126-1 du Code de la commande publique](chapitre-vi.md#article-l3126-1)
- Cité par : [art. L3371-1 du Code de la commande publique](https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000052393989)

Par dérogation aux dispositions de l'article L. 3122-2, l'autorité concédante n'est pas tenue de consigner les étapes de la procédure de passation des contrats de concession mentionnées à l'article L. 3126-1.
