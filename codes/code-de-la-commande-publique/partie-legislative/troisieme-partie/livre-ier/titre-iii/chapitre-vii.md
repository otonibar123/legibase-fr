# Chapitre VII : Règlement alternatif des différends

Code de la commande publique › Partie législative › TROISIÈME PARTIE : CONCESSIONS › Livre Ier : DISPOSITIONS GÉNÉRALES › Titre III : EXÉCUTION DU CONTRAT DE CONCESSION

## Section 1 : Conciliation et médiation

### Article L3137-1
- Identifiant : LEGIARTI000037705107
- État : en vigueur depuis le 01/04/2019
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000037705107
- Renvoie à : [Code des relations entre le public et l'administration, Chapitre II : Conciliation et médiation dans un](https://www.legifrance.gouv.fr/codes/article_lc/LEGISCTA000031367867) ; [Code des relations entre le public et l'administration, Chapitre Ier : Conciliation et médiation dans u](https://www.legifrance.gouv.fr/codes/article_lc/LEGISCTA000031367861)
- Cité par : [art. L3361-1 du Code de la commande publique](https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000052394049) ; [art. L3371-1 du Code de la commande publique](https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000052393989) ; [art. L3381-1 du Code de la commande publique](https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000052393965)

Les parties à un contrat administratif peuvent recourir à un tiers conciliateur ou médiateur dans les conditions fixées par les chapitres Ier et II du titre II du livre IV du code des relations entre le public et l'administration.

### Article L3137-2
- Identifiant : LEGIARTI000037705109
- État : en vigueur depuis le 01/04/2019
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000037705109
- Renvoie à : [Code de procédure civile, Chapitre II : La conciliation menée par un conc](https://www.legifrance.gouv.fr/codes/article_lc/LEGISCTA000025181356) ; [Code de procédure civile, Chapitre Ier : La conciliation](https://www.legifrance.gouv.fr/codes/article_lc/LEGISCTA000030350222)

Les parties à un contrat de concession de droit privé peuvent recourir à un tiers conciliateur ou médiateur dans les conditions fixées par les dispositions du chapitre Ier du titre VI du livre Ier et du chapitre II du titre Ier du livre V du code de procédure civile.

## Section 2 : Transaction

- Identifiant : LEGIARTI000037705113
- État : en vigueur depuis le 01/04/2019
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000037705113
- Renvoie à : [art. 2044 du Code civil](../../../../../code-civil/livre-iii/titre-xv.md#article-2044)
- Cité par : [art. L3361-1 du Code de la commande publique](https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000052394049) ; [art. L3361-2 du Code de la commande publique](https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000054140869) ; [art. Les parties à un contrat de concession peuvent recourir à une transaction ainsi que le prévoit l'article 2044 du code civil.

## Section 3 : Arbitrage

### Article L3137-4
- Identifiant : LEGIARTI000037705117
- État : en vigueur depuis le 01/04/2019
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000037705117
- Renvoie à : [art. 2060 du Code civil](../../../../../code-civil/livre-iii/titre-xvi.md#article-2060) ; [art. L311-6 du Code de justice administrative](../../../../../code-de-justice-administrative/partie-legislative/livre-iii/titre-ier/chapitre-ier.md#article-l311-6)
- Cité par : [art. L3361-2 du Code de la commande publique](https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000054140869) ; [art. L3371-1 du Code de la commande publique](https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000052393989) ; [art. L3371-2 du Code de la commande publique](https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000054140830) ; [art. L3381-1 du Code de la commande publique](https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000052393965)

Ainsi qu'en dispose le premier alinéa de l'article 2060 du code civil, les autorités concédantes qui sont des personnes morales de droit public ne peuvent recourir à l'arbitrage, sauf dans les cas prévus par la loi, notamment ceux mentionnés par l'article L. 311-6 du code de justice administrative.

### Article L3137-5
- Identifiant : LEGIARTI000037705119
- État : en vigueur depuis le 01/04/2019
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000037705119
- Renvoie à : [Code de procédure civile, Livre IV : L'arbitrage](https://www.legifrance.gouv.fr/codes/article_lc/LEGISCTA000006089134)

Le recours à l'arbitrage pour le règlement des litiges opposant des personnes privées dans l'exécution des contrats de concession est possible dans les conditions définies par le livre IV du code de procédure civile.
