# Chapitre II : Règles propres aux contrats de concession portant sur le service public de transport de voyageurs par chemin de fer

### Article L3222-1
- Identifiant : LEGIARTI000037808633
- État : en vigueur depuis le 01/04/2019
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000037808633
- Renvoie à : [art. L3200-1 du Code de la commande publique](../articles-directs.md#article-l3200-1) ; [art. L3212-4 du Code de la commande publique](../titre-ier/chapitre-ii.md#article-l3212-4) ; [art. L2121-17-1 du Code des transports](../../../../../code-des-transports/partie-legislative/deuxieme-partie/livre-ier/titre-ii/chapitre-ier-bis.md#article-l2121-17-1)

Par dérogation à l'article L. 3200-1, les contrats de concession mentionnés au 11° de l'article L. 3212-4 sont régis, pour leur passation et leur exécution, par les dispositions de l'article L. 2121-17-1 du code des transports.
