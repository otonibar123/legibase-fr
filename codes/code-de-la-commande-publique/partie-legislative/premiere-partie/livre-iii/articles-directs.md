### Article L1300-1
- Identifiant : LEGIARTI000037703330
- État : en vigueur depuis le 01/04/2019
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000037703330
- Cité par : [art. L1451-1 du Code de la commande publique](../livre-iv/titre-v/chapitre-unique.md#article-l1451-1) ; [art. L1461-1 du Code de la commande publique](../livre-iv/titre-vi/chapitre-unique.md#article-l1461-1) ; [art. L1471-1 du Code de la commande publique](../livre-iv/titre-vii/chapitre-unique.md#article-l1471-1) ; [art. L1481-1 du Code de la commande publique](../livre-iv/titre-viii/chapitre-unique.md#article-l1481-1)

Le choix de conclure un contrat destiné à satisfaire des besoins ne relevant qu'en partie du présent code ou relevant de plusieurs de ses parties ne peut avoir pour but de le soustraire aux règles définies par celui-ci.  
Ce contrat mixte est soumis aux dispositions du présent livre.
