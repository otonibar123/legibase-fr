# Chapitre IV : Dispositions diverses.

Code des pensions de retraite des marins français du commerce, de pêche ou de plaisance › Partie réglementaire - Décrets en Conseil d'Etat › Titre Ier : Pensions de retraite des marins.

### Article R20
- Identifiant : LEGIARTI000006792004
- État : en vigueur depuis le 31/03/1968
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006792004

Pour l'application de l'article L. 29, les modes de preuve de la disparition du marin sont fixés par arrêté du ministre chargé de la marine marchande.

### Article R21
- Identifiant : LEGIARTI000006792006
- État : en vigueur depuis le 24/03/2006
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006792006
- Renvoie à : [art. 203 du Code civil](../../../code-civil/livre-ier/titre-v/chapitre-v.md#article-203) ; [art. 205 du Code civil](../../../code-civil/livre-ier/titre-v/chapitre-v.md#article-205) ; [art. 206 du Code civil](../../../code-civil/livre-ier/titre-v/chapitre-v.md#article-206) ; [art. 207 du Code civil](../../../code-civil/livre-ier/titre-v/chapitre-v.md#article-207) ; [art. 214 du Code civil](../../../code-civil/livre-ier/titre-v/chapitre-vi.md#article-214) ; [art. 2331 du Code civil](../../../code-civil/livre-iv/titre-ii/sous-titre-ii/chapitre-ier.md#article-2331)

Les pensions sur la caisse de retraites des marins ne sont saisissables que dans les conditions et limites suivantes :  

1° Jusqu'à concurrence du cinquième, en cas de créances de l'Etat, de l'Etablissement national des invalides de la marine, ou des créances privilégiées de l'article 2331 du Code civil ;  

2° Jusqu'à concurrence du tiers dans le cas des dettes alimentaires prévues par les articles 203, 205, 206, 207 et 214 du Code civil.

### Article R22
- Identifiant : LEGIARTI000006792007
- État : en vigueur depuis le 31/03/1968
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006792007

Les pourvois contre les décisions accordant ou rejetant une pension doivent être introduits dans le délai de trois mois à compter de la notification.  

Le fait de toucher des arrérages échus ne prive pas les intéressés du droit d'introduire ledit recours dans le délai indiqué à l'alinéa précédent.
