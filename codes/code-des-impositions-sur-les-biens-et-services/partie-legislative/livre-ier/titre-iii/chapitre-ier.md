# Chapitre Ier : RÈGLES D'ARRONDIS

Code des impositions sur les biens et services › PARTIE LÉGISLATIVE › Livre Ier : DISPOSITIONS GÉNÉRALES › Titre III : MONTANT DE L'IMPÔT

### Article L131-1
- Identifiant : LEGIARTI000044604185
- État : en vigueur depuis le 01/01/2022
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000044604185
- Renvoie à : [art. 1649 undecies du Code général des impôts](../../../../code-general-des-impots/livre-premier/troisieme-partie/titre-premier/chapitre-vi.md#article-1649-undecies)

Les bases des impositions, lorsqu'elles sont des valeurs exprimées en euros, sont arrondies dans les conditions prévues à l'article 1649 undecies du code général des impôts.

### Article L131-2
- Identifiant : LEGIARTI000044604183
- État : en vigueur depuis le 01/01/2022
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000044604183
- Cité par : [art. L421-17 du Code des impositions sur les biens et services](../../livre-iv/titre-ii/chapitre-ier.md#article-l421-17) ; [Arrêté du 13 décembre 2022, art. 2-1](https://www.legifrance.gouv.fr/loda/article_lc/LEGIARTI000050864678) ; [art. L221-27 du Code des impositions sur les biens et services](https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000054525220)

Lorsque des éléments relatifs au montant de l'imposition, autres que les bases des impositions qui sont des valeurs en euros, sont arrondis, il est recouru à la valeur la plus proche, la moitié étant comptabilisée pour une unité.
