# Chapitre Ier : Travaux d'extrême urgence intéressant la défense nationale

Code de l'expropriation pour cause d'utilité publique › Partie réglementaire nouvelle › LIVRE V : PROCÉDURES SPÉCIALES › TITRE II : PROCÉDURE DE PRISE DE POSSESSION ANTICIPÉE

### Article R521-1
- Identifiant : LEGIARTI000029971540
- État : en vigueur depuis le 01/01/2015
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000029971540
- Renvoie à : [art. L521-1 du Code de l'expropriation pour cause d'utilité publique](../../../partie-legislative-nouvelle/livre-v/titre-ii/chapitre-ier.md#article-l521-1)

En vue de l'autorisation prévue à l'article L. 521-1, le ministre compétent soumet au Conseil d'Etat un projet de décret motivé et accompagné d'un plan indiquant les communes où sont situés les terrains que le maître de l'ouvrage se propose d'occuper et la description générale des ouvrages projetés.

### Article R521-2
- Identifiant : LEGIARTI000029971542
- État : en vigueur depuis le 01/01/2015
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000029971542
- Renvoie à : [art. L521-1 du Code de l'expropriation pour cause d'utilité publique](../../../partie-legislative-nouvelle/livre-v/titre-ii/chapitre-ier.md#article-l521-1)

Dans les vingt-quatre heures suivant la réception du décret prévu à l'article L. 521-1, le préfet de département territorialement compétent prend les arrêtés nécessaires.

### Article R521-3
- Identifiant : LEGIARTI000029971544
- État : en vigueur depuis le 01/01/2015
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000029971544
- Renvoie à : [art. L521-3 du Code de l'expropriation pour cause d'utilité publique](../../../partie-legislative-nouvelle/livre-v/titre-ii/chapitre-ier.md#article-l521-3)

L'évaluation prévue à l'article L. 521-3 est effectuée par le directeur départemental ou, le cas échéant, régional des finances publiques.
