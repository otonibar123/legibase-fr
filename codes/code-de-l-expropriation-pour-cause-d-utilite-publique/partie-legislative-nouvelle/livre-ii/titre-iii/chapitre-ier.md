### Article L231-1
- Identifiant : LEGIARTI000029733714
- État : en vigueur depuis le 01/01/2015
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000029733714
- Cité par : [art. L331-3 du Code de l'expropriation pour cause d'utilité publique](../../livre-iii/titre-iii/chapitre-unique.md#article-l331-3) ; [art. R231-1 du Code de l'expropriation pour cause d'utilité publique](../../../partie-reglementaire-nouvelle/livre-ii/titre-iii/chapitre-ier.md#article-r231-1) ; [art. L314-6 du Code de l'urbanisme](../../../../code-de-l-urbanisme/partie-legislative/livre-iii/titre-ier/chapitre-iv.md#article-l314-6)

Dans le délai d'un mois, soit du paiement de l'indemnité ou, en cas d'obstacle au paiement, de sa consignation, soit de l'acceptation ou de la validation de l'offre d'un local de remplacement, les détenteurs sont tenus de quitter les lieux. Passé ce délai qui ne peut, en aucun cas, être modifié, même par autorité de justice, il peut être procédé à l'expulsion des occupants.
