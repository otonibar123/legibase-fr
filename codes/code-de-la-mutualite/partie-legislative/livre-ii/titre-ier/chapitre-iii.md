# Chapitre III : Peines.

Code de la mutualité › Partie législative › Livre II : Mutuelles et unions pratiquant des opérations d'assurance, de réassurance et de capitalisation. › Titre Ier : Règles de fonctionnement applicables aux mutuelles et unions pratiquant des opérations d'assurance et de capitalisation et aux mutuelles et unions de retraite professionnelle supplémentaire.

### Article L213-1
- Identifiant : LEGIARTI000030438590
- État : en vigueur depuis le 01/01/2016
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000030438590
- Renvoie à : [art. L111-1 du Code de la mutualité](../../livre-ier/chapitre-ier.md#article-l111-1) ; [art. L211-8 du Code de la mutualité](chapitre-ier.md#article-l211-8) ; [art. L212-6 du Code de la mutualité](chapitre-ii.md#article-l212-6)
- Cité par : [art. L213-3 du Code de la mutualité](chapitre-iii.md#article-l213-3)

Est puni de trois ans d'emprisonnement et de 45 000 euros d'amende le fait, pour tout président, administrateur ou dirigeant d'une mutuelle ou union régie par les dispositions du présent livre, de pratiquer une des opérations mentionnées au 1° du I de l'article L. 111-1 sans avoir obtenu l'agrément prévu à l'article L. 211-8.

### Article L213-2
- Identifiant : LEGIARTI000030438618
- État : en vigueur depuis le 01/01/2016
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000030438618
- Renvoie à : [art. L111-1 du Code de la mutualité](../../livre-ier/chapitre-ier.md#article-l111-1) ; [art. L211-7 du Code de la mutualité](chapitre-ier.md#article-l211-7)
- Cité par : [art. L213-3 du Code de la mutualité](chapitre-iii.md#article-l213-3)

Les dispositions l'article L. 213-1 visant le président, les administrateurs ou les dirigeants d'une mutuelle ou union régie par le présent livre sont applicables à toute personne qui, directement ou par personne interposée, aura, en fait, exercé la direction, l'administration ou la gestion desdits organismes sous couvert ou au lieu et place de leurs représentants légaux.

### Article L213-3
- Identifiant : LEGIARTI000030438612
- État : en vigueur depuis le 01/01/2016
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000030438612
- Renvoie à : [art. L213-1 du Code de la mutualité](chapitre-iii.md#article-l213-1) ; [art. L213-2 du Code de la mutualité](chapitre-iii.md#article-l213-2) ; [art. 131-26 du Code pénal](../../../../code-penal/partie-legislative/livre-ier/titre-iii/chapitre-ier.md#article-131-26) ; [art. 131-27 du Code pénal](../../../../code-penal/partie-legislative/livre-ier/titre-iii/chapitre-ier.md#article-131-27) ; [art. 131-35 du Code pénal](../../../../code-penal/partie-legislative/livre-ier/titre-iii/chapitre-ier.md#article-131-35)

Les personnes physiques coupables de l'un des délits prévus au présent livre encourent également les peines complémentaires suivantes :  

1° L'interdiction des droits civiques, civils et de famille, suivant les modalités prévues par l'article 131-26 du code pénal ;  

2° L'interdiction, suivant les modalités prévues par l'article 131-27 du code pénal, d'exercer une fonction publique ou d'exercer l'activité professionnelle ou sociale dans l'exercice ou à l'occasion de l'exercice de laquelle l'infraction a été commise, pour une durée de cinq ans au plus ;  

3° L'affichage ou la diffusion de la décision prononcée dans les conditions prévues par l'article 131-35 du code pénal.

### Article L213-4
- Identifiant : LEGIARTI000030438604
- État : en vigueur depuis le 01/01/2016
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000030438604
- Renvoie à : [art. 121-2 du Code pénal](../../../../code-penal/partie-legislative/livre-ier/titre-ii/chapitre-ier.md#article-121-2) ; [art. 131-26 du Code pénal](../../../../code-penal/partie-legislative/livre-ier/titre-iii/chapitre-ier.md#article-131-26) ; [art. 131-27 du Code pénal](../../../../code-penal/partie-legislative/livre-ier/titre-iii/chapitre-ier.md#article-131-27) ; [art. 131-35 du Code pénal](../../../../code-penal/partie-legislative/livre-ier/titre-iii/chapitre-ier.md#article-131-35) ; [art. 131-38 du Code pénal](../../../../code-penal/partie-legislative/livre-ier/titre-iii/chapitre-ier.md#article-131-38) ; [art. 131-39 du Code pénal](../../../../code-penal/partie-legislative/livre-ier/titre-iii/chapitre-ier.md#article-131-39)

Les personnes morales déclarées responsables pénalement, dans les conditions prévues par l'article 121-2 du code pénal, des infractions définies dans le présent livre encourent, outre l'amende suivant les modalités prévues par l'article 131-38 du code pénal, les peines prévues par l'article 131-39 du même code.

L'interdiction mentionnée au 2° de l'article 131-39 du code pénal porte sur l'activité dans l'exercice ou à l'occasion de l'exercice de laquelle l'infraction a été commise.
