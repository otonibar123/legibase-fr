# Titre III : Le Conseil d'Etat juge de cassation

Code de justice administrative › Partie législative › Livre III : La compétence

### Article L331-1
- Identifiant : LEGIARTI000006449320
- État : en vigueur depuis le 01/01/2001
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006449320

Le Conseil d'Etat est seul compétent pour statuer sur les recours en cassation dirigés contre les décisions rendues en dernier ressort par toutes les juridictions administratives.
