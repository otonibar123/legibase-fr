# Chapitre II : Attributions administratives

Code de justice administrative › Partie législative › Livre II : Les tribunaux administratifs et les cours administratives d'appel › Titre Ier : Attributions

### Article L212-1
- Identifiant : LEGIARTI000006449216
- État : en vigueur depuis le 01/01/2001
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006449216

Outre leurs attributions juridictionnelles, les tribunaux administratifs et les cours administratives d'appel exercent des fonctions consultatives.

### Article L212-2
- Identifiant : LEGIARTI000006449217
- État : en vigueur depuis le 01/01/2001
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006449217
- Cité par : [art. L311-5 du Code de justice administrative](../../livre-iii/titre-ier/chapitre-ier.md#article-l311-5)

Les tribunaux administratifs se prononcent sur l'exercice, par les contribuables, des actions appartenant à certaines collectivités territoriales et à leurs établissements publics, dans les conditions fixées par le code général des collectivités territoriales.
