# Chapitre II : Procédure d'admission

Code de justice administrative › Partie législative › Livre VIII : Les voies de recours › Titre II : Le recours en cassation

### Article L822-1
- Identifiant : LEGIARTI000006449407
- État : en vigueur depuis le 01/01/2001
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006449407
- Cité par : [art. R611-7 du Code de justice administrative](../../../partie-reglementaire-decrets-en-conseil-d-etat/livre-vi/titre-ier/chapitre-ier.md#article-r611-7)

Le pourvoi en cassation devant le Conseil d'Etat fait l'objet d'une procédure préalable d'admission. L'admission est refusée par décision juridictionnelle si le pourvoi est irrecevable ou n'est fondé sur aucun moyen sérieux.
