# Titre Ier : L'appel

Code de justice administrative › Partie législative › Livre VIII : Les voies de recours

### Article L811-1
- Identifiant : LEGIARTI000006449404
- État : en vigueur depuis le 01/01/2001
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006449404
- Renvoie à : [Code de justice administrative, Livre III : La compétence](https://www.legifrance.gouv.fr/codes/article_lc/LEGISCTA000006118211)

Dans le cas où un jugement rendu en premier ressort est susceptible d'appel, celui-ci est porté devant la juridiction d'appel compétente en vertu des dispositions du livre III.
