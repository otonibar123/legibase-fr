# Chapitre III : Dispositions applicables au Conseil d'Etat

Code de justice administrative › Partie réglementaire - Décrets en Conseil d'Etat › Livre VII : Le jugement › Titre III : La tenue de l'audience et le délibéré

### Article R733-1
- Identifiant : LEGIARTI000042535277
- État : en vigueur depuis le 20/11/2020
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000042535277
- Cité par : [art. R712-1 du Code de justice administrative](../titre-ier/chapitre-ii.md#article-r712-1) ; [Décret n°2020-1404 du 18 novembre 2020](https://www.legifrance.gouv.fr/loda/id/LEGITEXT000042533691)

Après le rapport, le rapporteur public prononce ses conclusions.  

Les avocats au Conseil d'Etat représentant les parties peuvent présenter des observations orales après le prononcé des conclusions du rapporteur public.

### Article R733-2
- Identifiant : LEGIARTI000006450204
- État : en vigueur depuis le 01/09/2006
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006450204
- Cité par : [art. R712-1 du Code de justice administrative](../titre-ier/chapitre-ii.md#article-r712-1) ; [art. R773-23 du Code de justice administrative](../titre-vii/chapitre-iii-bis.md#article-r773-23)

La décision est délibérée hors la présence des parties.

### Article R733-3
- Identifiant : LEGIARTI000020102430
- État : en vigueur depuis le 01/02/2009
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000020102430
- Cité par : [art. R712-1 du Code de justice administrative](../titre-ier/chapitre-ii.md#article-r712-1) ; [art. R773-23 du Code de justice administrative](../titre-vii/chapitre-iii-bis.md#article-r773-23)

Sauf demande contraire d'une partie, le rapporteur public assiste au délibéré. Il n'y prend pas part.  

La demande prévue à l'alinéa précédent est présentée par écrit. Elle peut l'être à tout moment de la procédure avant le délibéré.
