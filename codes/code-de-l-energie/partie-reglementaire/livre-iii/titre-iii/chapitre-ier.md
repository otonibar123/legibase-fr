# Chapitre Ier : Le choix d'un fournisseur

Code de l'énergie › Partie réglementaire › LIVRE III : LES DISPOSITIONS RELATIVES À L'ÉLECTRICITÉ › TITRE III : LA COMMERCIALISATION

### Article R331-1
- Identifiant : LEGIARTI000031748673
- État : en vigueur depuis le 01/01/2016
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000031748673
- Renvoie à : [art. R123-220 du Code de commerce](../../../../code-de-commerce/partie-reglementaire/livre-ier/titre-ii/chapitre-iii.md#article-r123-220) ; [art. L331-2 du Code de l'énergie](../../../partie-legislative/livre-iii/titre-iii/chapitre-ier.md#article-l331-2)

Pour l'application de l'article L. 331-2, le site de consommation d'électricité est constitué par l'établissement, identifié par son numéro d'identité au répertoire prévu à l'article R. 123-220 du code de commerce ou, à défaut, pour les sites qui sont dépourvus d'un tel numéro, par le lieu de consommation d'électricité.
