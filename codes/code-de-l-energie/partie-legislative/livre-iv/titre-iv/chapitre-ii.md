# Chapitre II : Les contrats de vente

Code de l'énergie › Partie législative › LIVRE IV : LES DISPOSITIONS RELATIVES AU GAZ › TITRE IV : LA COMMERCIALISATION

### Article L442-1
- Identifiant : LEGIARTI000035132799
- État : en vigueur depuis le 01/07/2016
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000035132799
- Renvoie à : [art. L224-1 du Code de la consommation](../../../../code-de-la-consommation/partie-legislative-nouvelle/livre-ii/titre-ii/chapitre-iv.md#article-l224-1)
- Cité par : [art. L442-3 du Code de l'énergie](chapitre-ii.md#article-l442-3)

Les dispositions des articles L. 224-1 à L. 224-16 du code de la consommation sont applicables aux contrats conclus entre les fournisseurs de gaz naturel et les consommateurs ou les non-professionnels pour une consommation de gaz naturel inférieure à 30 000 kilowattheures par an, ainsi qu'aux offres correspondantes.

### Article L442-3
- Identifiant : LEGIARTI000035133086
- État : en vigueur depuis le 01/07/2016
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000035133086
- Renvoie à : [art. L442-1 du Code de l'énergie](chapitre-ii.md#article-l442-1) ; [art. L224-8 du Code de la consommation](../../../../code-de-la-consommation/partie-legislative-nouvelle/livre-ii/titre-ii/chapitre-iv.md#article-l224-8)

Dans les conditions fixées par l'article L. 224-8 du code de la consommation, les personnes mentionnées à l'article L. 442-1 ont la possibilité de conclure un contrat unique portant sur la fourniture et la distribution de gaz naturel.
