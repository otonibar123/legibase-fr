# Chapitre II : Les dispositions particulières à la production hydroélectrique

Code de l'énergie › Partie législative › LIVRE III : LES DISPOSITIONS RELATIVES A L'ÉLECTRICITÉ › TITRE IER : LA PRODUCTION

### Article L312-1
- Identifiant : LEGIARTI000023986382
- État : en vigueur depuis le 01/06/2011
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000023986382

La production hydroélectrique est régie par les dispositions du livre V en tant qu'elles concernent l'hydroélectricité.

### Article L312-2
- Identifiant : LEGIARTI000023986384
- État : en vigueur depuis le 01/06/2011
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000023986384
- Renvoie à : [art. L311-5 du Code de l'énergie](chapitre-ier.md#article-l311-5)

Les titres administratifs délivrés en application du livre V valent autorisation au sens de l'article L. 311-5.
