# TITRE IV : LE STOCKAGE

Code de l'énergie › Partie législative › LIVRE VIII : LES DISPOSITIONS RELATIVES À L'HYDROGÈNE

### Article L841-1
- Identifiant : LEGIARTI000043154213
- État : en vigueur depuis le 19/02/2021
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000043154213

Les dispositions relatives au stockage de l'hydrogène, lorsqu'il est effectué dans des installations de stockage de gaz combustible et de gaz naturel, figurent aux titres Ier et III du livre II du code minier.
