# Chapitre unique : L'astreinte

Code des procédures civiles d'exécution › Partie réglementaire › LIVRE Ier : DISPOSITIONS GÉNÉRALES › TITRE III : LA PRÉVENTION DES DIFFICULTÉS D'EXÉCUTION

### Article R131-1
- Identifiant : LEGIARTI000025938380
- État : en vigueur depuis le 01/06/2012
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000025938380

L'astreinte prend effet à la date fixée par le juge, laquelle ne peut pas être antérieure au jour où la décision portant obligation est devenue exécutoire.  
Toutefois, elle peut prendre effet dès le jour de son prononcé si elle assortit une décision qui est déjà exécutoire.

### Article R131-2
- Identifiant : LEGIARTI000034757131
- État : en vigueur depuis le 01/09/2017
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000034757131
- Renvoie à : [art. L131-3 du Code des procédures civiles d'exécution](../../../partie-legislative/livre-ier/titre-iii/chapitre-unique.md#article-l131-3)
- Cité par : [art. R641-1 du Code des procédures civiles d'exécution](https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000055004608)

Pour l'application de l'article L. 131-3, l'incompétence est relevée d'office par le juge saisi d'une demande en liquidation d'astreinte.

Si ce n'est lorsqu'elle émane d'une cour d'appel, la décision du juge peut faire l'objet d'un appel formé dans les conditions prévues par le code de procédure civile.

### Article R131-3
- Identifiant : LEGIARTI000025938384
- État : en vigueur depuis le 01/06/2012
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000025938384

Aucune astreinte ne peut donner lieu à une mesure d'exécution forcée avant sa liquidation.  
La décision qui ordonne une astreinte non encore liquidée permet de prendre une mesure conservatoire pour une somme provisoirement évaluée par le juge compétent pour la liquidation.

### Article R131-4
- Identifiant : LEGIARTI000025938386
- État : en vigueur depuis le 01/06/2012
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000025938386

La décision du juge est exécutoire de plein droit par provision.
