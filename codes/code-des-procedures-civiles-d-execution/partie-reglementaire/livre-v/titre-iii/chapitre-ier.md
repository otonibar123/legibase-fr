# Chapitre Ier : Dispositions générales

Code des procédures civiles d'exécution › Partie réglementaire › LIVRE V : LES MESURES CONSERVATOIRES › TITRE III : LES SÛRETÉS JUDICIAIRES

### Article R531-1
- Identifiant : LEGIARTI000025939518
- État : en vigueur depuis le 01/06/2012
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000025939518
- Cité par : [art. Annexe 4-7 du Code de commerce](../../../../code-de-commerce/annexes-de-la-partie-reglementaire.md#article-annexe-4-7) ; [art. R444-71 du Code de commerce](../../../../code-de-commerce/partie-reglementaire/livre-iv/titre-iv-bis/section-3/sous-section-4.md#article-r444-71) ; [art. R641-10 du Code des procédures civiles d'exécution](../../livre-vi/titre-iv/chapitre-unique.md#article-r641-10)

Sur présentation de l'autorisation du juge ou du titre en vertu duquel la loi permet qu'une mesure conservatoire soit pratiquée, une sûreté peut être prise sur un immeuble, un fonds de commerce, des parts sociales ou des valeurs mobilières appartenant au débiteur.
