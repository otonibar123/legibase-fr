# Chapitre II : Le procès-verbal d'expulsion

Code des procédures civiles d'exécution › Partie réglementaire › LIVRE IV : L'EXPULSION › TITRE III : LES OPÉRATIONS D'EXPULSION

### Article R432-1
- Identifiant : LEGIARTI000025939333
- État : en vigueur depuis le 01/06/2012
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000025939333
- Cité par : [art. Annexe 4-7 du Code de commerce](../../../../code-de-commerce/annexes-de-la-partie-reglementaire.md#article-annexe-4-7) ; [art. R451-2 du Code des procédures civiles d'exécution](../titre-v/chapitre-unique.md#article-r451-2)

L'huissier de justice dresse un procès-verbal des opérations d'expulsion qui contient, à peine de nullité :  
1° La description des opérations auxquelles il a été procédé et l'identité des personnes dont le concours a été nécessaire ;  
2° La désignation de la juridiction compétente pour statuer sur les contestations relatives aux opérations d'expulsion.  
Le procès-verbal est signé par toutes les personnes mentionnées au 1°. En cas de refus de signer, il en est fait mention.

### Article R432-2
- Identifiant : LEGIARTI000025939335
- État : en vigueur depuis le 01/06/2012
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000025939335
- Cité par : [art. A444-13 du Code de commerce](../../../../code-de-commerce/partie-arretes/livre-iv/titre-iv-bis/chapitre-ier.md#article-a444-13) ; [art. R451-2 du Code des procédures civiles d'exécution](../titre-v/chapitre-unique.md#article-r451-2)

Le procès-verbal d'expulsion est remis ou signifié à la personne expulsée.
