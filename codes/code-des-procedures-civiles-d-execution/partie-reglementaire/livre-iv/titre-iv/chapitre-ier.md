# Chapitre Ier : La réinstallation de la personne expulsée

Code des procédures civiles d'exécution › Partie réglementaire › LIVRE IV : L'EXPULSION › TITRE IV : LES DIFFICULTÉS D'EXÉCUTION

### Article R441-1
- Identifiant : LEGIARTI000025939361
- État : en vigueur depuis le 01/06/2012
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000025939361
- Renvoie à : [art. R412-2 du Code des procédures civiles d'exécution](../titre-ier/chapitre-ii.md#article-r412-2)
- Cité par : [art. R451-4 du Code des procédures civiles d'exécution](../titre-v/chapitre-unique.md#article-r451-4)

La réinstallation sans titre de la personne expulsée dans les mêmes locaux est constitutive d'une voie de fait.  
Le commandement d'avoir à libérer les locaux signifié auparavant continue de produire ses effets ; l'article R. 412-2 n'est pas applicable.
