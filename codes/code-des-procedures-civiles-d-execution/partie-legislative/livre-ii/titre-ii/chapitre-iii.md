# Chapitre III : Les mesures d'exécution sur les véhicules terrestres à moteur

Code des procédures civiles d'exécution › Partie législative › LIVRE II : LES PROCÉDURES D'EXÉCUTION MOBILIÈRE › TITRE II : LA SAISIE DES BIENS CORPORELS

## Section 1 : La saisie par déclaration auprès de l'autorité administrative

### Article L223-1
- Identifiant : LEGIARTI000025025880
- État : en vigueur depuis le 01/06/2012
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000025025880
- Cité par : [art. R223-2 du Code des procédures civiles d'exécution](../../../partie-reglementaire/livre-ii/titre-ii/chapitre-iii.md#article-r223-2)

L'huissier de justice chargé de l'exécution d'un titre exécutoire peut faire une déclaration aux fins de saisie d'un véhicule terrestre à moteur auprès de l'autorité administrative compétente.  
La notification de cette déclaration au débiteur produit tous les effets d'une saisie.  
Les conditions d'application du présent article sont fixées par décret en Conseil d'Etat.

## Section 2 : La saisie par immobilisation du véhicule

### Article L223-2
- Identifiant : LEGIARTI000025025884
- État : en vigueur depuis le 01/06/2012
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000025025884
- Cité par : [art. R221-19 du Code des procédures civiles d'exécution](../../../partie-reglementaire/livre-ii/titre-ii/chapitre-ier.md#article-r221-19) ; [art. R221-28 du Code des procédures civiles d'exécution](../../../partie-reglementaire/livre-ii/titre-ii/chapitre-ier.md#article-r221-28) ; [art. R222-1 du Code des procédures civiles d'exécution](../../../partie-reglementaire/livre-ii/titre-ii/chapitre-ii.md#article-r222-1) ; [art. R222-16 du Code des procédures civiles d'exécution](../../../partie-reglementaire/livre-ii/titre-ii/chapitre-ii.md#article-r222-16) ; [art. R223-6 du Code des procédures civiles d'exécution](../../../partie-reglementaire/livre-ii/titre-ii/chapitre-iii.md#article-r223-6)

L'huissier de justice chargé de l'exécution muni d'un titre exécutoire peut saisir le véhicule du débiteur en l'immobilisant, en quelque lieu qu'il se trouve, par tout moyen n'entraînant aucune détérioration du véhicule. Le débiteur peut demander au juge la levée de l'immobilisation du véhicule.
