# Chapitre Ier : Dispositions générales

Code des procédures civiles d'exécution › Partie législative › LIVRE III : LA SAISIE IMMOBILIÈRE › TITRE III : LA DISTRIBUTION DU PRIX

### Article L331-1
- Identifiant : LEGIARTI000044072843
- État : en vigueur depuis le 01/01/2022
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000044072843
- Renvoie à : [art. 2374 du Code civil](../../../../code-civil/livre-iv/titre-ii/sous-titre-ii/chapitre-iv.md#article-2374) ; [art. 2375 du Code civil](../../../../code-civil/livre-iv/titre-ii/sous-titre-iii/articles-directs.md#article-2375) ; [art. 2377 du Code civil](../../../../code-civil/livre-iv/titre-ii/sous-titre-iii/chapitre-ier.md#article-2377) ; [art. 2402 du Code civil](../../../../code-civil/livre-iv/titre-ii/sous-titre-iii/chapitre-iii.md#article-2402)
- Cité par : [art. R331-4 du Code des procédures civiles d'exécution](../../../partie-reglementaire/livre-iii/titre-iii/chapitre-ier.md#article-r331-4) ; [art. R332-1 du Code des procédures civiles d'exécution](../../../partie-reglementaire/livre-iii/titre-iii/chapitre-ii.md#article-r332-1) ; [art. R332-2 du Code des procédures civiles d'exécution](../../../partie-reglementaire/livre-iii/titre-iii/chapitre-ii.md#article-r332-2)

Seuls sont admis à faire valoir leurs droits sur le prix de la vente le créancier poursuivant, les créanciers inscrits sur l'immeuble saisi à la date de la publication du commandement de payer valant saisie, les créanciers inscrits sur l'immeuble avant la publication du titre de vente et qui sont intervenus dans la procédure, les créanciers énumérés à l'article 2377 et au 3° de l'article 2402 du code civil ainsi que les créanciers titulaires d'une sûreté publiée sur les immeubles par destination saisis avant la publication du titre de vente.

> Nota : Conformément au I de l’article 37 de l’ordonnance n° 2021-1192 du 15 septembre 2021, ces dispositions entreront en vigueur le 1er janvier 2022.

### Article L331-2
- Identifiant : LEGIARTI000025026004
- État : en vigueur depuis le 01/06/2012
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000025026004
- Cité par : [art. R322-7 du Code des procédures civiles d'exécution](../../../partie-reglementaire/livre-iii/titre-ii/chapitre-ii.md#article-r322-7) ; [art. R331-4 du Code des procédures civiles d'exécution](../../../partie-reglementaire/livre-iii/titre-iii/chapitre-ier.md#article-r331-4) ; [art. R332-2 du Code des procédures civiles d'exécution](../../../partie-reglementaire/livre-iii/titre-iii/chapitre-ii.md#article-r332-2)

Les créanciers sommés de déclarer leur créance et qui ont omis de le faire sont déchus du bénéfice de leur sûreté pour la distribution du prix de vente de l'immeuble.
