# Chapitre II : La publicité provisoire

Code des procédures civiles d'exécution › Partie législative › LIVRE V : LES MESURES CONSERVATOIRES › TITRE III : LES SÛRETÉS JUDICIAIRES

### Article L532-1
- Identifiant : LEGIARTI000025026160
- État : en vigueur depuis le 01/06/2012
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000025026160

Les sûretés judiciaires sont opposables aux tiers du jour de l'accomplissement des formalités de publicité prescrites par décret en Conseil d'Etat.
