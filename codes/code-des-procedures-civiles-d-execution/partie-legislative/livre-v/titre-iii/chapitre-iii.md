# Chapitre III : La publicité définitive

Code des procédures civiles d'exécution › Partie législative › LIVRE V : LES MESURES CONSERVATOIRES › TITRE III : LES SÛRETÉS JUDICIAIRES

### Article L533-1
- Identifiant : LEGIARTI000025026164
- État : en vigueur depuis le 01/06/2012
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000025026164

La publicité provisoire cesse de produire effet si, dans un délai fixé par décret, elle n'a pas été confirmée par une publicité définitive.
