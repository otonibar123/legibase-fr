# Chapitre Ier : Dispositions générales

Code des procédures civiles d'exécution › Partie législative › LIVRE V : LES MESURES CONSERVATOIRES › TITRE III : LES SÛRETÉS JUDICIAIRES

### Article L531-1
- Identifiant : LEGIARTI000025026154
- État : en vigueur depuis le 01/06/2012
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000025026154
- Cité par : [art. R444-71 du Code de commerce](../../../../code-de-commerce/partie-reglementaire/livre-iv/titre-iv-bis/section-3/sous-section-4.md#article-r444-71) ; [art. L641-9 du Code des procédures civiles d'exécution](../../livre-vi/titre-iv/chapitre-unique.md#article-l641-9)

Une sûreté judiciaire peut être constituée à titre conservatoire sur les immeubles, les fonds de commerce, les actions, parts sociales et valeurs mobilières.

### Article L531-2
- Identifiant : LEGIARTI000025026156
- État : en vigueur depuis le 01/06/2012
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000025026156

Les biens grevés d'une sûreté judiciaire demeurent aliénables. Le prix en est payé et distribué dans les conditions fixées par décret en Conseil d'Etat.  
Toutefois, en cas de vente de valeurs mobilières inscrites sur un compte tenu et géré par un intermédiaire habilité, le prix peut être utilisé pour acquérir d'autres valeurs qui sont alors subrogées aux valeurs vendues.
