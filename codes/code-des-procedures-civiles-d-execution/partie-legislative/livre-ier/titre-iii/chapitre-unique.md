# Chapitre unique : L'astreinte

Code des procédures civiles d'exécution › Partie législative › LIVRE Ier : DISPOSITIONS GÉNÉRALES › TITRE III : LA PRÉVENTION DES DIFFICULTÉS D'EXÉCUTION

### Article L131-1
- Identifiant : LEGIARTI000025025717
- État : en vigueur depuis le 01/06/2012
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000025025717

Tout juge peut, même d'office, ordonner une astreinte pour assurer l'exécution de sa décision.  
Le juge de l'exécution peut assortir d'une astreinte une décision rendue par un autre juge si les circonstances en font apparaître la nécessité.

### Article L131-2
- Identifiant : LEGIARTI000025025719
- État : en vigueur depuis le 01/06/2012
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000025025719
- Cité par : [art. 373-2-6 du Code civil](../../../../code-civil/livre-ier/titre-ix/chapitre-ier.md#article-373-2-6) ; [art. L421-1 du Code des procédures civiles d'exécution](../../livre-iv/titre-ii/chapitre-unique.md#article-l421-1) ; [art. L421-2 du Code des procédures civiles d'exécution](../../livre-iv/titre-ii/chapitre-unique.md#article-l421-2)

L'astreinte est indépendante des dommages-intérêts.  
L'astreinte est provisoire ou définitive. L'astreinte est considérée comme provisoire, à moins que le juge n'ait précisé son caractère définitif.  
Une astreinte définitive ne peut être ordonnée qu'après le prononcé d'une astreinte provisoire et pour une durée que le juge détermine. Si l'une de ces conditions n'a pas été respectée, l'astreinte est liquidée comme une astreinte provisoire.

### Article L131-3
- Identifiant : LEGIARTI000025025722
- État : en vigueur depuis le 01/06/2012
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000025025722
- Cité par : [art. R131-2 du Code des procédures civiles d'exécution](../../../partie-reglementaire/livre-ier/titre-iii/chapitre-unique.md#article-r131-2)

L'astreinte, même définitive, est liquidée par le juge de l'exécution, sauf si le juge qui l'a ordonnée reste saisi de l'affaire ou s'en est expressément réservé le pouvoir.

### Article L131-4
- Identifiant : LEGIARTI000025025724
- État : en vigueur depuis le 01/06/2012
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000025025724

Le montant de l'astreinte provisoire est liquidé en tenant compte du comportement de celui à qui l'injonction a été adressée et des difficultés qu'il a rencontrées pour l'exécuter.  
Le taux de l'astreinte définitive ne peut jamais être modifié lors de sa liquidation.  
L'astreinte provisoire ou définitive est supprimée en tout ou partie s'il est établi que l'inexécution ou le retard dans l'exécution de l'injonction du juge provient, en tout ou partie, d'une cause étrangère.
