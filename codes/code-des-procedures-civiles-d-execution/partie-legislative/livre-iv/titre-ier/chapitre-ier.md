# Chapitre Ier : Dispositions générales

Code des procédures civiles d'exécution › Partie législative › LIVRE IV : L'EXPULSION › TITRE Ier : LES CONDITIONS DE L'EXPULSION

### Article L411-1
- Identifiant : LEGIARTI000028808273
- État : en vigueur depuis le 27/03/2014
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000028808273
- Cité par : [art. L451-1 du Code des procédures civiles d'exécution](../titre-v/chapitre-unique.md#article-l451-1) ; [art. R412-2 du Code des procédures civiles d'exécution](../../../partie-reglementaire/livre-iv/titre-ier/chapitre-ii.md#article-r412-2) ; [art. R451-1 du Code des procédures civiles d'exécution](../../../partie-reglementaire/livre-iv/titre-v/chapitre-unique.md#article-r451-1)

Sauf disposition spéciale, l'expulsion d'un immeuble ou d'un lieu habité ne peut être poursuivie qu'en vertu d'une décision de justice ou d'un procès-verbal de conciliation exécutoire et après signification d'un commandement d'avoir à libérer les locaux.
