# Chapitre V : Dispositions pénales.

Code rural (nouveau) › Partie législative › Livre V : Organismes professionnels agricoles › Titre III : Sociétés d'intérêt collectif agricole

### Article L535-1
- Identifiant : LEGIARTI000006584357
- État : en vigueur depuis le 30/09/1990
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006584357
- Renvoie à : [art. L529-3 du Code rural (nouveau)](../titre-ii/chapitre-ix.md#article-l529-3)

Les dispositions de l'article L. 529-3 sont applicables aux directeurs de sociétés d'intérêt collectif agricole.

### Article L535-2
- Identifiant : LEGIARTI000006584359
- État : en vigueur depuis le 30/09/1990
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006584359
- Renvoie à : [art. L529-4 du Code rural (nouveau)](../titre-ii/chapitre-ix.md#article-l529-4)

### Article L535-4
- Identifiant : LEGIARTI000006584361
- État : en vigueur depuis le 30/09/1990
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006584361
- Renvoie à : [art. L529-1 du Code rural (nouveau)](../titre-ii/chapitre-ix.md#article-l529-1)

### Article L535-5
- Identifiant : LEGIARTI000006584362
- État : en vigueur depuis le 06/01/1991
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006584362
- Renvoie à : [art. L529-2 du Code rural (nouveau)](../titre-ii/chapitre-ix.md#article-l529-2) ; [art. L534-1 du Code rural (nouveau)](chapitre-iv.md#article-l534-1)

Est puni de la peine prévue au premier alinéa de l'article L. 529-2 le président ou le directeur de la société d'intérêt collectif agricole qui contrevient aux dispositions de l'article L. 534-1.
