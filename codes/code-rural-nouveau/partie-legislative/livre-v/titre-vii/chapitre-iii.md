# Chapitre III : Saint-Martin

Code rural (nouveau) › Partie législative › Livre V : Organismes professionnels agricoles › Titre VII : Dispositions relatives à l'outre-mer

### Article L573-1
- Identifiant : LEGIARTI000032344151
- État : en vigueur depuis le 01/07/2016
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000032344151

Les dispositions du présent livre s'appliquent à Saint-Martin sous réserve des exceptions et adaptations prévues au présent chapitre.

### Article L573-2
- Identifiant : LEGIARTI000032344158
- État : en vigueur depuis le 01/07/2016
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000032344158
- Renvoie à : [art. L960-2 du Code de commerce](../../../../code-de-commerce/partie-legislative/livre-ix/titre-vi.md#article-l960-2)
- Cité par : [art. R953-3 du Code rural (nouveau)](../../../partie-reglementaire/livre-ix/titre-v/chapitre-iii.md#article-r953-3)

Pour l'application du présent code à Saint-Martin, les missions consultatives dévolues aux chambres d'agriculture sont exercées par la chambre consulaire interprofessionnelle de Saint-Martin. Des missions autres que consultatives peuvent lui être confiées par l'Etat dans les conditions fixées à l'article L. 960-2 du code de commerce.
