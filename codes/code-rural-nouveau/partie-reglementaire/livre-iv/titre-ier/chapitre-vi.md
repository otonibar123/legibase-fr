# Chapitre VI : Dispositions particulières au baux à long terme.

### Article R416-1
- Identifiant : LEGIARTI000006592142
- État : en vigueur depuis le 01/12/1982
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006592142
- Renvoie à : [art. L416-1 du Code rural (nouveau)](../../../partie-legislative/livre-iv/titre-ier/chapitre-vi.md#article-l416-1) ; [art. L416-3 du Code rural (nouveau)](../../../partie-legislative/livre-iv/titre-ier/chapitre-vi.md#article-l416-3)

L'avis prévu à l'alinéa 4 de l'article L. 416-1 doit être donné par acte extrajudiciaire.  

La décision de l'une des parties prévue à l'article L. 416-3 doit être portée à la connaissance de l'autre partie par acte extrajudiciaire.

### Article R416-2
- Identifiant : LEGIARTI000006592143
- État : en vigueur depuis le 01/12/1982
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006592143
- Renvoie à : [art. R411-1 du Code rural (nouveau)](chapitre-ier.md#article-r411-1)
