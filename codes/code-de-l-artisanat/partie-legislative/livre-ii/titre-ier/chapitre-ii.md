# Chapitre II : Artisan d'art

Code de l'artisanat › Partie législative › Livre II : PERSONNES RELEVANT DU SECTEUR DES MÉTIERS ET DE L'ARTISANAT › Titre Ier : QUALITÉ D'ARTISAN

### Article L212-1
- Identifiant : LEGIARTI000047362420
- État : en vigueur depuis le 01/07/2023
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000047362420
- Renvoie à : [art. L211-1 du Code de l'artisanat](chapitre-ier.md#article-l211-1) ; [art. L212-2 du Code de l'artisanat](chapitre-ii.md#article-l212-2)
- Cité par : [art. L123-46 du Code de commerce](../../../../code-de-commerce/partie-legislative/livre-ier/titre-ii/chapitre-iii.md#article-l123-46) ; [art. L241-2 du Code de l'artisanat](../titre-iv/chapitre-ier.md#article-l241-2)

Peuvent se prévaloir de la qualité d'artisan d'art les personnes mentionnées à l'article L. 211-1 exerçant une activité figurant sur la liste des métiers d'art prévue à l'article L. 212-2.

> Nota : Conformément à l’article 6 de l’ordonnance n° 2023-208 du 28 mars 2023, ces dispositions entrent en vigueur le 1er juillet 2023.

### Article L212-2
- Identifiant : LEGIARTI000047362422
- État : en vigueur depuis le 01/07/2023
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000047362422
- Renvoie à : [art. L211-1 du Code de l'artisanat](chapitre-ier.md#article-l211-1)
- Cité par : [art. L212-1 du Code de l'artisanat](chapitre-ii.md#article-l212-1) ; [art. R212-1 du Code de l'artisanat](../../../partie-reglementaire/livre-ii/titre-ier/chapitre-ii.md#article-r212-1) ; [art. R215-5 du Code de l'artisanat](../../../partie-reglementaire/livre-ii/titre-ier/chapitre-v.md#article-r215-5) ; [art. R221-4 du Code de l'artisanat](../../../partie-reglementaire/livre-ii/titre-ii/chapitre-ier.md#article-r221-4) ; [art. R221-6 du Code de l'artisanat](../../../partie-reglementaire/livre-ii/titre-ii/chapitre-ier.md#article-r221-6)

Relèvent des métiers d'art les personnes physiques, ainsi que les dirigeants sociaux des personnes morales, ayant ou non la qualité d'artisan mentionnée à l'article L. 211-1, qui exercent, à titre principal ou secondaire une activité indépendante de production, de création, de transformation ou de reconstitution, de réparation et de restauration du patrimoine, caractérisée par la maîtrise de gestes et de techniques en vue du travail de la matière et nécessitant un apport artistique.  
La liste des métiers d'art est fixée par arrêté conjoint des ministres chargés de l'artisanat et de la culture.

> Nota : Conformément à l’article 6 de l’ordonnance n° 2023-208 du 28 mars 2023, ces dispositions entrent en vigueur le 1er juillet 2023.

### Article L212-3
- Identifiant : LEGIARTI000047362424
- État : en vigueur depuis le 01/07/2023
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000047362424
- Renvoie à : [art. 244 quater O du Code général des impôts](../../../../code-general-des-impots/livre-premier/premiere-partie/titre-premier/chapitre-iv.md#article-244-quater-o)
- Cité par : [art. L521-7 du Code de l'artisanat](../../livre-v/titre-ii/chapitre-ier.md#article-l521-7) ; [art. L522-7 du Code de l'artisanat](../../livre-v/titre-ii/chapitre-ii.md#article-l522-7) ; [art. L523-6 du Code de l'artisanat](../../livre-v/titre-ii/chapitre-iii.md#article-l523-6)

Les entreprises du secteur des métiers et de l'artisanat exerçant une activité relevant d'un métier d'art peuvent bénéficier du crédit d'impôt en faveur des métiers d'art dans les conditions prévues par l'article 244 quater O du code général des impôts.

> Nota : Conformément à l’article 6 de l’ordonnance n° 2023-208 du 28 mars 2023, ces dispositions entrent en vigueur le 1er juillet 2023.
