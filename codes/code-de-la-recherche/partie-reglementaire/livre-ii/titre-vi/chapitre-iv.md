# Chapitre IV : DISPOSITIONS RELATIVES À SAINT-PIERRE ET MIQUELON

Code de la recherche › Partie réglementaire › Livre II : L'EXERCICE DES ACTIVITÉS DE RECHERCHE › Titre VI : DISPOSITIONS RELATIVES À L'OUTRE-MER

### Article R264-1
- Identifiant : LEGIARTI000048770218
- État : en vigueur depuis le 01/01/2024
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000048770218
- Renvoie à : [art. R254-1 du Code de la recherche](../titre-v/chapitre-iv.md#article-r254-1)

Pour l'application à Saint-Pierre-et-Miquelon de l'article R. 254-1, après les mots : " code du patrimoine ", sont ajoutés les mots : ", sous réserve des dispositions de l'article R. 720-4 du même code ".

### Article R264-2
- Identifiant : LEGIARTI000048770220
- État : en vigueur depuis le 01/01/2024
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000048770220
- Renvoie à : [art. R254-2 du Code de la recherche](../titre-v/chapitre-iv.md#article-r254-2)

Pour l'application à Saint-Pierre-et-Miquelon de l'article R. 254-2, après les mots : " code du patrimoine ", sont ajoutés les mots : ", sous réserve des dispositions des articles R. 720-5 et R. 720-8 du même code ".
