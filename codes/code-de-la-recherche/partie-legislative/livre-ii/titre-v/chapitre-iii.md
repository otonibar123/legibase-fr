# Chapitre III : Utilisation en recherche de certains produits chimiques.

Code de la recherche › Partie législative › LIVRE II : L'EXERCICE DES ACTIVITÉS DE RECHERCHE › TITRE V : AUTRES DOMAINES DE RECHERCHE

### Article L253-2
- Identifiant : LEGIARTI000031559446
- État : en vigueur depuis le 04/12/2015
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000031559446
- Renvoie à : [art. L522-2 du Code de l'environnement](../../../../code-de-l-environnement/partie-legislative/livre-v/titre-ii/chapitre-ii.md#article-l522-2)

Les modalités d'utilisation dans la recherche de produits biocides sont fixées par les articles L. 522-1 et L. 522-9 du code de l'environnement.
