# Chapitre Ier : La génétique.

Code de la recherche › Partie législative › LIVRE II : L'EXERCICE DES ACTIVITÉS DE RECHERCHE › TITRE II : LA RECHERCHE EN MÉDECINE ET BIOLOGIE HUMAINE

### Article L221-1
- Identifiant : LEGIARTI000044588917
- État : en vigueur depuis le 01/01/2022
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000044588917
- Renvoie à : [art. 16-10 du Code civil](../../../../code-civil/livre-ier/titre-ier/chapitre-iii.md#article-16-10) ; [art. L1131-1 du Code de la santé publique](../../../../code-de-la-sante-publique/partie-legislative/premiere-partie/livre-ier/titre-iii/chapitre-ier.md#article-l1131-1) ; [art. L1131-3 du Code de la santé publique](../../../../code-de-la-sante-publique/partie-legislative/premiere-partie/livre-ier/titre-iii/chapitre-ier.md#article-l1131-3) ; [art. L1131-4 du Code de la santé publique](../../../../code-de-la-sante-publique/partie-legislative/premiere-partie/livre-ier/titre-iii/chapitre-ier.md#article-l1131-4)

L'examen des caractéristiques génétiques d'une personne ou son identification par empreintes génétiques à des fins de recherche sont effectués dans les conditions fixées par les dispositions des articles 16-10 à 16-13 du code civil et des articles L. 1131-1, L. 1131-1-1, L. 1131-3 et L. 1131-4 du code de la santé publique.

> Nota : Conformément à l'article 10 de l'ordonnance n° 2021-1747 du 22 décembre 2021, ces dispositions entrent en vigueur le 1er janvier 2022.

### Article L221-2
- Identifiant : LEGIARTI000019911604
- État : en vigueur depuis le 13/12/2008
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000019911604
- Renvoie à : [art. 226-26 du Code pénal](../../../../code-penal/partie-legislative/livre-ii/titre-ii/chapitre-vi.md#article-226-26) ; [art. 226-27 du Code pénal](../../../../code-penal/partie-legislative/livre-ii/titre-ii/chapitre-vi.md#article-226-27) ; [art. 226-28 du Code pénal](../../../../code-penal/partie-legislative/livre-ii/titre-ii/chapitre-vi.md#article-226-28) ; [art. 226-29 du Code pénal](../../../../code-penal/partie-legislative/livre-ii/titre-ii/chapitre-vi.md#article-226-29) ; [art. 226-30 du Code pénal](../../../../code-penal/partie-legislative/livre-ii/titre-ii/chapitre-vi.md#article-226-30)

Les manquements aux obligations relatives à l'examen des caractéristiques génétiques d'une personne ou son identification par empreintes génétiques à des fins de recherche sont sanctionnés dans les conditions prévues par les dispositions des articles 226-26, 226-27, 226-28, 226-29 et 226-30 du code pénal.

### Article L221-3
- Identifiant : LEGIARTI000006524188
- État : en vigueur depuis le 16/06/2004
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006524188
- Renvoie à : [art. L1131-4 du Code de la santé publique](../../../../code-de-la-sante-publique/partie-legislative/premiere-partie/livre-ier/titre-iii/chapitre-ier.md#article-l1131-4)

Les collections d'échantillons biologiques humains ayant pour fin la recherche génétique sont constituées dans les conditions fixées par les dispositions de l'article L. 1131-4 du code de la santé publique.
