# Chapitre VI : Sanctions.

Code de la recherche › Partie législative › LIVRE II : L'EXERCICE DES ACTIVITÉS DE RECHERCHE › TITRE III : L'EXPÉRIMENTATION ANIMALE

### Article L236-1
- Identifiant : LEGIARTI000006524201
- État : en vigueur depuis le 16/06/2004
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000006524201
- Renvoie à : [art. 521-1 du Code pénal](../../../../code-penal/partie-legislative/livre-v/titre-ii/chapitre-ier.md#article-521-1)

Les manquements aux obligations relatives à l'exercice de l'expérimentation animale sont sanctionnés dans les conditions prévues par les dispositions des articles 521-1 et 521-2 du code pénal.
