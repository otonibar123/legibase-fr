# Chapitre II : L'autorisation de recherches

Code minier (nouveau) › PARTIE LÉGISLATIVE › LIVRE III : RÉGIME LÉGAL DES CARRIÈRES › TITRE II : LA RECHERCHE DANS LES ZONES SPÉCIALES DE CARRIÈRES

### Article L322-1
- Identifiant : LEGIARTI000023505652
- État : en vigueur depuis le 01/03/2011
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000023505652
- Renvoie à : [art. L153-3 du Code minier (nouveau)](../../livre-ier/titre-v/chapitre-iii.md#article-l153-3) ; [art. L321-1 du Code minier (nouveau)](chapitre-ier.md#article-l321-1)
- Cité par : [art. R341-1 du Code forestier (nouveau)](../../../../code-forestier-nouveau/partie-reglementaire/livre-iii/titre-iv/chapitre-ier.md#article-r341-1) ; [art. L322-3 du Code minier (nouveau)](chapitre-ii.md#article-l322-3) ; [art. L322-6 du Code minier (nouveau)](chapitre-ii.md#article-l322-6)

Dans les zones instituées en application de l'article L. 321-1, peuvent être accordées des autorisations de recherches à défaut du consentement du propriétaire du sol. Le titulaire d'une telle autorisation bénéficie des droits prévus par les dispositions des articles L. 153-3 à L. 153-10.

### Article L322-2
- Identifiant : LEGIARTI000023505654
- État : en vigueur depuis le 01/03/2011
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000023505654
- Renvoie à : [art. L321-1 du Code minier (nouveau)](chapitre-ier.md#article-l321-1) ; [art. L512-1 du Code minier (nouveau)](../../livre-v/titre-unique/chapitre-ii.md#article-l512-1)
- Cité par : [art. L334-6 du Code minier (nouveau)](../titre-iii/chapitre-iv.md#article-l334-6)

A l'intérieur des zones définies en application de l'article L. 321-1 du présent code, il ne peut être accordé d'autorisation de recherches sur des terrains qui, à la date de la demande d'autorisation, sont régulièrement exploités par le propriétaire ou ses ayants droit ou qui, s'ils ne sont pas exploités à cette même date, ont fait l'objet d'une demande encore en cours d'instruction présentée en application des articles L. 512-1 ou L. 512-7 du code de l'environnement ou d'une autorisation d'exploiter datant de moins de deux ans.

### Article L322-3
- Identifiant : LEGIARTI000023505657
- État : en vigueur depuis le 01/03/2011
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000023505657
- Renvoie à : [art. L515-4-1 du Code de l'environnement](../../../../code-de-l-environnement/partie-legislative/livre-v/titre-ier/chapitre-v.md#article-l515-4-1) ; [art. L322-1 du Code minier (nouveau)](chapitre-ii.md#article-l322-1)
- Cité par : [art. L322-4 du Code minier (nouveau)](chapitre-ii.md#article-l322-4)

Une autorisation de recherches de carrières délivrée en application de l'article L. 322-1 peut être retirée en cas d'inactivité persistante ou d'infractions graves aux prescriptions des titres IV et V du présent livre ainsi que des articles L. 515-4-1 et L. 515-4-2 du code de l'environnement.

### Article L322-4
- Identifiant : LEGIARTI000023505660
- État : en vigueur depuis le 01/03/2011
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000023505660
- Renvoie à : [art. L322-3 du Code minier (nouveau)](chapitre-ii.md#article-l322-3)

La décision de retrait prévue à l'article L. 322-3 est prononcée par l'autorité administrative.

### Article L322-5
- Identifiant : LEGIARTI000023505662
- État : en vigueur depuis le 01/03/2011
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000023505662
- Renvoie à : [art. L173-7 du Code minier (nouveau)](../../livre-ier/titre-vii/chapitre-iii.md#article-l173-7)

L'article L. 173-7 est applicable au titulaire déchu.

### Article L322-6
- Identifiant : LEGIARTI000023505664
- État : en vigueur depuis le 01/03/2011
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000023505664
- Renvoie à : [art. L322-1 du Code minier (nouveau)](chapitre-ii.md#article-l322-1)
- Cité par : [art. L334-6 du Code minier (nouveau)](../titre-iii/chapitre-iv.md#article-l334-6)

Les autorisations de recherche prévues à l'article L. 322-1 sont accordées pour une durée initiale maximale de trois ans. Elles peuvent faire l'objet de prolongations successives d'une même durée.

### Article L322-7
- Identifiant : LEGIARTI000023505666
- État : en vigueur depuis le 01/03/2011
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000023505666

Les renonciations, totales ou partielles, aux droits de recherches ne deviennent définitives qu'après avoir été acceptées par l'autorité administrative.

### Article L322-8
- Identifiant : LEGIARTI000023505668
- État : en vigueur depuis le 01/03/2011
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000023505668

Des décrets en Conseil d'Etat déterminent les mesures d'application des dispositions du présent chapitre.
