### Article L411-2
- Identifiant : LEGIARTI000023505814
- État : en vigueur depuis le 01/03/2011
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000023505814
- Renvoie à : [art. L214-3 du Code de l'environnement](../../../../code-de-l-environnement/partie-legislative/livre-ii/titre-ier/chapitre-iv.md#article-l214-3) ; [art. L411-1 du Code minier (nouveau)](https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000023505812)

Les demandes d'autorisations et les déclarations prévues par l'article L. 214-3 du code de l'environnement valent déclaration au titre de l'article L. 411-1 du présent code.

### Article L411-3
- Identifiant : LEGIARTI000023505817
- État : en vigueur depuis le 01/03/2011
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000023505817
- Cité par : [art. L412-2 du Code minier (nouveau)](chapitre-ii.md#article-l412-2) ; [art. L413-1 du Code minier (nouveau)](chapitre-iii.md#article-l413-1) ; [art. L512-5 du Code minier (nouveau)](../../livre-v/titre-unique/chapitre-ii.md#article-l512-5)

Tout levé de mesures géophysiques, toute campagne de prospection géochimique ou d'études de minéraux lourds doivent faire l'objet d'une déclaration préalable auprès de l'autorité administrative compétente.
