# Chapitre II : Obligations faites aux exploitants

Code minier (nouveau) › PARTIE LÉGISLATIVE › LIVRE IER : LE RÉGIME LÉGAL DES MINES › TITRE VII : SURVEILLANCE ADMINISTRATIVE ET POLICE DES MINES

### Article L172-1
- Identifiant : LEGIARTI000023505020
- État : en vigueur depuis le 01/03/2011
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000023505020
- Cité par : [art. L272-1 du Code minier (nouveau)](../../livre-ii/titre-vii/chapitre-ii.md#article-l272-1) ; [Décret n°2006-649 du 2 juin 2006, art. 35](https://www.legifrance.gouv.fr/loda/article_lc/LEGIARTI000046662262) ; [Décret n°2006-649 du 2 juin 2006, art. 36](https://www.legifrance.gouv.fr/loda/article_lc/LEGIARTI000046662255)

En vue de permettre la surveillance prévue au chapitre Ier du présent titre, pendant la durée de l'exploitation, les titulaires de concession adressent chaque année à l'autorité administrative un rapport relatif à ses incidences sur l'occupation des sols et sur les caractéristiques essentielles du milieu environnant. Ce rapport est communiqué aux collectivités territoriales concernées. Ses caractéristiques sont définies par voie réglementaire.

### Article L172-2
- Identifiant : LEGIARTI000023505037
- État : en vigueur depuis le 01/03/2011
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000023505037
- Cité par : [art. L173-1 du Code minier (nouveau)](chapitre-iii.md#article-l173-1) ; [art. L272-1 du Code minier (nouveau)](../../livre-ii/titre-vii/chapitre-ii.md#article-l272-1) ; [art. L512-5 du Code minier (nouveau)](../../livre-v/titre-unique/chapitre-ii.md#article-l512-5) ; [art. L611-16 du Code minier (nouveau)](../../livre-vi/titre-ier/chapitre-ier.md#article-l611-16)

Lorsqu'une concession appartient à plusieurs personnes ou à une société, les indivisaires ou la société doivent pourvoir, par une convention spéciale, à ce que les travaux d'exploitation soient soumis à une direction unique et soient coordonnés dans un intérêt commun.

Ils sont pareillement tenus de désigner un mandataire pour recevoir toutes notifications et significations et, en général, pour les représenter vis-à-vis de l'administration, tant en demande qu'en défense. A la demande de l'autorité administrative, ils doivent justifier de l'accomplissement de ces obligations.
