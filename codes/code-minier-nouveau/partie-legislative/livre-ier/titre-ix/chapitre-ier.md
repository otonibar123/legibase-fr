# Chapitre Ier : Temps de travail

Code minier (nouveau) › PARTIE LÉGISLATIVE › LIVRE IER : LE RÉGIME LÉGAL DES MINES › TITRE IX : AUTRES DISPOSITIONS SOCIALES

### Article L191-1
- Identifiant : LEGIARTI000023505236
- État : en vigueur depuis le 01/03/2011
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000023505236
- Renvoie à : [art. L3121-1 du Code du travail](../../../../code-du-travail/partie-legislative/troisieme-partie/livre-ier/titre-ii/chapitre-ier.md#article-l3121-1)
- Cité par : [art. L191-2 du Code minier (nouveau)](chapitre-ier.md#article-l191-2)

Dans les exploitations souterraines de mines, la durée de présence de chaque travailleur dans la mine ne peut excéder trente-huit heures quarante minutes par semaine.

Par dérogation aux dispositions des articles L. 3121-1 et suivants du code du travail, le temps de présence dans les exploitations souterraines de mines est considéré comme temps de travail effectif.

### Article L191-2
- Identifiant : LEGIARTI000033021537
- État : en vigueur depuis le 10/08/2016
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000033021537
- Renvoie à : [art. L3121-67 du Code du travail](../../../../code-du-travail/partie-legislative/troisieme-partie/livre-ier/titre-ii/chapitre-ier.md#article-l3121-67) ; [art. L191-1 du Code minier (nouveau)](chapitre-ier.md#article-l191-1)

Un décret en Conseil d'Etat, dans les conditions prévues à l'article L. 3121-67 du code du travail, détermine les modalités d'application de l'article L. 191-1, notamment le mode de calcul de la durée de présence.
