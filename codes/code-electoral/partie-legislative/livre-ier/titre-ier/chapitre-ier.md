### Article L2
- Identifiant : LEGIARTI000006353016

- Cité par : [art. L713-3 du Code de commerce](../../../../code-de-commerce/partie-legislative/livre-vii/titre-ier/chapitre-iii.md#article-l713-3) ; [art. L723-4 du Code de commerce](../../../../code-de-commerce/partie-legislative/livre-vii/titre-ii/chapitre-iii.md#article-l723-4) ; [art.
