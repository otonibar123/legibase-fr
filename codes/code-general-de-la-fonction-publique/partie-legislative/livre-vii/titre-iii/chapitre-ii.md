# Chapitre II : Prestations d'action sociale

Code général de la fonction publique › PARTIE LÉGISLATIVE › Livre VII : RÉMUNÉRATION ET ACTION SOCIALE › Titre III : ACTION SOCIALE

## Section 1 : Chèques emploi-service

### Article L732-1
- Identifiant : LEGIARTI000044424685
- État : en vigueur depuis le 01/03/2022
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000044424685
- Renvoie à : [art. L1271-12 du Code du travail](../../../../code-du-travail/partie-legislative/premiere-partie/livre-ii/titre-vii/chapitre-ier.md#article-l1271-12)
- Cité par : [art. L742-4 du Code général de la fonction publique](../titre-iv/chapitre-ii.md#article-l742-4) ; [Arrêté du 22 décembre 2023](https://www.legifrance.gouv.fr/loda/id/LEGITEXT000048720795)

L'agent public peut bénéficier du chèque emploi-service universel dans les conditions fixées à l'article L. 1271-12 du code du travail.

## Section 2 : Titres-restaurant

### Article L732-2
- Identifiant : LEGIARTI000044424681
- État : en vigueur depuis le 01/03/2022
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000044424681
- Renvoie à : [Code du travail, Chapitre II : Titres-restaurant](https://www.legifrance.gouv.fr/codes/article_lc/LEGISCTA000006178037)
- Cité par : [art. L742-4 du Code général de la fonction publique](../titre-iv/chapitre-ii.md#article-l742-4)

Lorsque son employeur public ne peut le faire bénéficier d'un dispositif de restauration collective compatible avec le lieu d'exercice de ses fonctions, des titres-restaurants peuvent être attribués à l'agent public dans les conditions prévues par le chapitre II du titre VI du livre II de la troisième partie du code du travail.

## Section 3 : Aides aux vacances

### Article L732-3
- Identifiant : LEGIARTI000044424677
- État : en vigueur depuis le 01/03/2022
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000044424677
- Renvoie à : [art. L411-18 du Code du tourisme](../../../../code-du-tourisme/partie-legislative/livre-iv/titre-ier/chapitre-1er.md#article-l411-18) ; [art. L411-19 du Code du tourisme](../../../../code-du-tourisme/partie-legislative/livre-iv/titre-ier/chapitre-1er.md#article-l411-19)

Les aides aux vacances peuvent être attribuées à l'agent public sous forme de chèques-vacances versés dans les conditions définies aux articles L. 411-18 et L. 411-19 du code du tourisme.
