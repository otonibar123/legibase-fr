# Chapitre VI : Saint-Barthélemy et Saint-Martin

### Article L1426-1
- Identifiant : LEGIARTI000022022300
- État : en vigueur depuis le 27/03/2010
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000022022300
- Renvoie à : [art. L1421-1 du Code de la santé publique](chapitre-ier.md#article-l1421-1) ; [art. L5313-1 du Code de la santé publique](../../../cinquieme-partie/livre-iii/titre-ier/chapitre-iii.md#article-l5313-1)
- Cité par : [art. L1418-2 du Code de la santé publique](../titre-ier/chapitre-viii.md#article-l1418-2) ; [art. L1421-2 du Code de la santé publique](chapitre-ier.md#article-l1421-2) ; [art. L5414-2 du Code de la santé publique](../../../cinquieme-partie/livre-iv/titre-ier/chapitre-iv.md#article-l5414-2)

Sauf disposition contraire, le représentant de l'Etat à Saint-Barthélemy et le représentant de l'Etat à Saint-Martin exercent les attributions dévolues par le présent code au représentant de l'Etat dans le département ou la région.

### Article L1426-2
- Identifiant : LEGIARTI000036511319
- État : en vigueur depuis le 19/01/2018
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000036511319

Pour l'application du présent code aux collectivités de Saint-Barthélemy et de Saint-Martin, la référence au conseil départemental ou aux conseils départementaux est remplacée, sauf dispositions contraires, par la référence aux conseils territoriaux ou au conseil territorial.
