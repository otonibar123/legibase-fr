# Titre VI : Produits de santé contenant des substances à l'état nanoparticulaire

Code de la santé publique › Partie législative › Cinquième partie : Produits de santé › Livre Ier : Produits pharmaceutiques

### Article L5161-1
- Identifiant : LEGIARTI000045405772
- État : en vigueur depuis le 25/03/2022
- Source : https://www.legifrance.gouv.fr/codes/article_lc/LEGIARTI000045405772

Les articles L. 523-1 à L. 523-3 du code de l'environnement s'appliquent aux substances entrant dans la composition des produits mentionnés à l'article L. 5311-1 du présent code ainsi qu'aux médicaments vétérinaires mentionnés à l'article L. 5141-2.
